ホロドリ編成お助けツールの使い方

『hololive Dreams』（ホロドリ）の編成を全探索して、ユニットスコアの高い順に並べるツールです。登録から結果の読み方までの手順をまとめています。表示される値はすべて非公式の試算値です。

編成シミュレーターを開く

1. アカウントの状態を登録する

「アカウント」で自分の状態を登録します。ここで登録した内容が探索と試算の両方に使われ、ブラウザの中だけに保存されます。

  • ホロメンボード — ホロメンごとの赤・青・黄・緑の解放マスと、コネクトに入れたホロメン。
  • 所持カード — 持っている★5カードと、その開花段階。
  • イベントメモリー・メンバー強化ボーナス — それぞれの％。

スクリーンショットから作った JSON は、メニューの「設定」→「データの取り込み」から貼り付けられます。登録済みの内容は「データの出力」で 1 つの JSON にまとまります。

2. リーダーとメンバーの枠を指定する

「リーダー」「メンバー」で、固定したい枠だけをカードで埋めます。空けた枠が探索の対象です。すべて空のままでも探索できます。

3. 曲を指定する

「曲」で曲を指定すると次の 2 つが試算に入ります。指定しなくても探索できます。

  • 黄ボードの楽曲スコアボーナス（登録した全ホロメン分の合計。上限 10.0%）
  • 赤ボードの歌唱者条件（リーダーのホロメンがその曲の歌唱者に含まれるとき）

4. 条件を決めて全探索する

「ベスト編成をさがす」で、条件を満たす編成をすべて数え上げ、ユニットスコアの高い順に並べます。「オプション」で切り替えられるのは次の項目です。

  • 所持カードから探す — 外すと未所持を含む全カードが対象になります。
  • リーダーから除外・メンバーから除外 — 個別に候補から外します。
  • ボード状況を考慮する・開花状況を考慮する — 外すと開花最大・ホロメンボード全解放として試算します（全カードから探すときも同じです）。
  • 衣装スキル発動に限る・パッシブ全員発動に限る — 発動条件を満たす編成だけに絞ります。

5. 結果を読む

結果は順位ごとに 1 行で並び、押すと詳細が開きます。

  • ユニットスコアと、「詳細」を開いたときの総合力・スコアボーナスの内訳
  • リーダーとメンバー5人、メンバー別の P / T / S
  • ★ でお気に入りに登録（メニューの「お気に入り」から見られます）
  • 「発動頻度の最適化」 — 青ボードの発動頻度マスを何個開けるかを、アクティブスキルの期待値で見る別の試算です

内訳の項目の意味と計算のしかたはユニットスコア計算と内訳にまとめています。

注意点

  • 非公式ツールで、表示される値は試算値です。実際のゲーム内の値と異なる場合があります。
  • 登録した内容はブラウザの localStorage にだけ保存され、サーバーへは送られません。ブラウザのデータを消すと消えます。
  • スコアボーナスの試算には、現在も確認できていない部分が残っています（ユニットスコア計算と内訳）。
