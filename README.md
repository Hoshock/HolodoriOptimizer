# ホロドリ編成お助けツール (HolodoriOptimizer)

『hololive Dreams』(ホロドリ)のパーティ編成を最適化する**非公式ファンツール**。サイト上の表示名は「ホロドリ編成お助けツール」。条件(手持ち・除外・固定・曲)を与えると、ユニットスコア(試算値)が最大になるリーダー+メンバー 5 人の組み合わせを探索し、上位候補を提示します。

> **免責**: 本ツールはファンによる非公式ツールであり、カバー株式会社・株式会社 QualiArts とは一切関係ありません。ゲーム内の名称等の権利はすべて各権利者に帰属します。スコアは試算値であり、実際のゲーム内の値と異なる場合があります（総合力とユニット編成画面の「ユニットスコア」を再現するモデルで、青ホロメンボードとスコアサポートの反映には仮説を含みます。実際に曲をプレイしたときのライブスコアは計算していません）。権利者からの要請があれば速やかに公開を停止します。

## 機能

- 全★5 カード・楽曲・スキルのデータベース(テキストのみ・手入力)
- ユニット編成の最適化: リーダー・メンバーは指定してもおまかせでも可。ユニットスコア(試算値)で順位づけし、上位 10 件を 1 件ずつ左右に送って提示(タップで内訳)
- アカウントの登録(Step 0): ホロメン(ホロメンボード)・メンバー(持っているカードと開花段階)・ユニット(お気に入り編成)をここで登録する(ブラウザ内にのみ保存)
- お気に入りユニット: 結果パネルの右上の星から、表示中の編成を 1〜10 の番号へ登録する(登録済みの番号は上書きの確認つき。星をもう一度押すと解除)。Step 0 の「ユニット」で登録した編成を左右に送って見られる。保存するのはカードの組み合わせだけで、スコアは開いたときの登録状態(開花・ボード・メモリー・強化ボーナス・曲)で計算し直す
- 探索対象の絞り込み: 一部メンバーを固定する。さがすステップのオプション(既定は畳んである)で、所持カードから探すか(既定 ON)、リーダーから除外・メンバーから除外(それぞれ候補から外すカード。ボタン内に枚数。指定したリーダー・固定したメンバーには効かない)、ボード状況・開花状況を考慮するか、衣装スキル・パッシブが発動する編成だけに絞るかを選べる(設定はブラウザ内にのみ保存。除外は保存しない)
- 総合力の試算: ゲームのユニット編成画面の「総合力」と同じ 6 項目(メンバーパラメータ・衣装スキル・ホロメンボード効果・パッシブスキル・メモリー効果・メンバー強化ボーナス)を、ボード前の本体値を基準に別々に求めて加算する(2026-09-08 の実機観測に基づくモデル。結果の詳細に内訳とメンバー別の値を表示)。メモリーの「ユニットパラメータ +X%」とメンバー強化ボーナス +X% は Step 0 で入力する。ゲーム画面の「スコアボーナス」4 項目(アクティブスキル・ホロメンボード効果・パッシブスキル・スペシャルスキル)と「ユニットスコア」(総合力 × (1 + スコアボーナス) × 係数)は、曲を選ばない 200 秒の仮想タイムラインで発動確率を重みづけするモデルで試算し、結果の値と順位づけはこのユニットスコア × (1 + 黄の楽曲スコアボーナス) × (1 + イベントスコアボーナス)で行う(各欄は 0.1% 単位の切り上げで整数化する。実機 20 ケースでスコアボーナス合計 −0.8〜+2.3 ポイント、ユニットスコア −0.4%〜+1.0%。項目ごとは アクティブ **20 ケース全一致** / SP −0.4〜+0.6 / ボード −1.5〜+2.9 / パッシブ −1.6〜+0.8 ポイントで、青ボードとスコアサポートの反映が未解明の部分。探索は上限値で候補を絞ってから正確に評価する近似で、真の上位が落ちないことは小規模の厳密探索と突き合わせて検証している)
- 開花(凸)の反映: 持っているカードはカードごとに開花段階(0〜5)を登録でき(変更は Step 0 のみ。メンバーピッカーには段階のアイコンだけ出る)、「開花状況を考慮する」が ON のとき段階に応じた試算に反映される(考慮しないとき — 全カードからさがすときも — は全カードを開花最大として試算する。2凸のパラメータ +10% は実測値。スキルの段階別の実数値が未確認の間は仮定倍率による概算)
- ホロメンボードの反映: ホロメンごとに、ゲーム内と同じ配置のボードで解放したマスを登録できる(左右の配置はホロメンごとの固定データで自動、経路のまとめて解放、すべて解放/解除、マスの効果を読む「説明」モード)。赤・青・黄・緑の 4 色。ボードはカードでなくホロメンの状態として持ち、持っているカードで「ボード状況を考慮する」が ON のときに効く(考慮しないとき — 全カードからさがすときも — は全ホロメンの 4 色すべてを全解放した状態として試算する。将来に向けた探索は育てきった前提で比べる — 2026-09-08 ユーザー判断)。青はそのホロメンのカードのパラメータと表示スコアボーナスのアクティブ発動の試算に、緑は登録した全ホロメン分の合計が全カードに(全員向けの P/T/S UP と、所属向けの全パラメータ UP — 1 枚あたり +900 が上限)効く。黄(本人のソロ / 本人を含むユニット / 全体楽曲のスコアボーナスとホロワークの報酬)は、曲を指定したときにその曲に乗る全ホロメン分の合計(上限 10.0%)をユニットスコア(試算)に掛ける(掛け方はゲーム内の式が未確認のため仮定。ホロワークの報酬は表示のみ)。赤(リーダー用)はそのホロメンをリーダーにした編成のメンバー 5 人に効き、全員の P/T/S の固定値と割合を総合力に足し、「全員のスコアサポート効果」は表示スコアボーナスのホロメンボード効果欄に反映する(スコアサポートの内部式は未解明で、仮説モデルによる試算)。歌唱者条件は曲を指定し、リーダーのホロメンがその曲の歌唱者に含まれるとき。ライフ・ホロメンスキル・ライブ報酬はスコアの試算には使わず表示のみ(63 マスは左 / 上 / 右の 3 エリアに分けて表示し、枝が画面の外へ続く位置の出口をタップして移動)。いずれもマスの表記値の合計で試算し、コネクトマスによる増幅は含まない
- 曲を指定した最適化（曲名・ホロメン名の検索、所属・オリジナル/カバーで絞り込み、曲長・レベルで並べ替え）。曲を指定すると黄ホロメンボードの楽曲スコアボーナスとイベントスコアボーナスが順位づけの値に掛かる。**曲の長さ・譜面は試算に使っていない**（実際のライブ中のスコアは未実装 — 下の「将来」）
- ヘッダ右上のメニュー(ハンバーガー → 右のサイドバー): カード一覧(★5 全カードのパラメータ・スキル・開花段階ごとの強化内容の詳細)、曲一覧(歌唱・種別・演奏時間・難易度別の Lv とノーツ数)、仮想ガチャ、ソースコード(GitHub)、絶対おかゆんモードの ON / OFF。データにない項目(コネクト効果の内容・作詞作曲編曲など)は「未確認」と表示
- 仮想ガチャシミュレーション(ピックアップガチャ、仮想ダイヤと課金相当額の表示。実際の課金・排出とは無関係の遊び機能で、状態はブラウザ内にのみ保存)
- (準備中)イベント対応: 現在・過去の全イベント(開催期間・対象カード・課題曲)をデータとして持ち、編成のイベント Pt / バッジ獲得ボーナス(メンバー + ホロメン + 開花。リーダー枠は対象外)を計算できる。獲得ボーナスが最大の編成をさがす画面は設計を見直し中
- (将来)実ライブスコアの最適化: 実際に曲をプレイしたときのスコア(譜面・コンボ・SP の発動位置・アクティブの重なりなど)の計算は**未実装**で、現在の順位づけはユニット編成画面の「ユニットスコア」の再現値で行っている。ライブスコアの式が実機で解明できたら、表示ユニットスコアとは別のエンジンとして追加する([ADR-006](docs/adr/006-actual-live-score-separate-engine.md))
- (将来)ホロメンボード補正の残り(コネクトマスの増幅)
