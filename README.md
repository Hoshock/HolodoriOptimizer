# ホロドリ編成お助けツール (HolodoriOptimizer)

『hololive Dreams』(ホロドリ)のパーティ編成を最適化する**非公式ファンツール**。サイト上の表示名は「ホロドリ編成お助けツール」。条件(手持ち・除外・固定・曲)を与えると、総合期待スコア(試算値)が最大になるリーダー+メンバー 5 人の組み合わせを探索し、上位候補を提示します。

> **免責**: 本ツールはファンによる非公式ツールであり、カバー株式会社・株式会社 QualiArts とは一切関係ありません。ゲーム内の名称等の権利はすべて各権利者に帰属します。スコアはコミュニティの解析に基づく試算値であり、実際のゲーム内の値と異なる場合があります。権利者からの要請があれば速やかに公開を停止します。

## 機能

- 全★5 カード・楽曲・スキルのデータベース(テキストのみ・手入力)
- ユニット編成の最適化: リーダー・メンバーは指定してもおまかせでも可。アクティブ・SP スキルの期待値を含む総合期待スコア(試算値)で順位づけし、上位 n 件を内訳つきで提示
- 探索対象の絞り込み: 持っているカードだけを対象にする / カードを除外する / 一部メンバーを固定する(所持カードの登録はブラウザ内にのみ保存)
- 開花(凸)の反映: 持っているカードはカードごとに開花段階(0〜5)を登録でき、段階に応じた試算に反映される(段階別の実数値が未確認の間は仮定倍率による概算)
- 曲を指定した最適化(曲の長さがスキル期待値に反映される。未指定なら代表的な曲条件)
- 仮想ガチャシミュレーション(ピックアップガチャ、仮想ダイヤと課金相当額の表示。実際の課金・排出とは無関係の遊び機能で、状態はブラウザ内にのみ保存)
- (将来)ホロメンボード補正
