# ホロドリ編成お助けツール (HolodoriOptimizer)

『hololive Dreams』(ホロドリ)のパーティ編成を最適化する**非公式ファンツール**。サイト上の表示名は「ホロドリ編成お助けツール」。条件(手持ち・除外・固定・曲)を与えると、総合期待スコア(試算値)が最大になるリーダー+メンバー 5 人の組み合わせを探索し、上位候補を提示します。

> **免責**: 本ツールはファンによる非公式ツールであり、カバー株式会社・株式会社 QualiArts とは一切関係ありません。ゲーム内の名称等の権利はすべて各権利者に帰属します。スコアはコミュニティの解析に基づく試算値であり、実際のゲーム内の値と異なる場合があります。権利者からの要請があれば速やかに公開を停止します。

## 機能

- 全★5 カード・楽曲・スキルのデータベース(テキストのみ・手入力)
- ユニット編成の最適化: リーダー・メンバーは指定してもおまかせでも可。アクティブ・SP スキルの期待値を含む総合期待スコア(試算値)で順位づけし、上位 100 件を 10 件ずつ内訳つきで提示
- アカウントの登録(Step 0): ホロメン(ホロメンボード)・メンバー(持っているカードと開花段階)をここで登録する(ブラウザ内にのみ保存)。ユニット(お気に入り編成の記録)は準備中
- 探索対象の絞り込み: 持っているカードだけを対象にする / カードを除外する / 一部メンバーを固定する。さがすステップのオプションで、ボード状況・開花状況を考慮するか、衣装スキル・パッシブが発動する編成だけに絞るかを選べる(設定はブラウザ内にのみ保存)
- 開花(凸)の反映: 持っているカードはカードごとに開花段階(0〜5)を登録でき(変更は Step 0 のみ。メンバーピッカーには段階のアイコンだけ出る)、「開花状況を考慮する」が ON のとき段階に応じた試算に反映される(全カードでは常に 0凸。2凸のパラメータ +10% は実測値。スキルの段階別の実数値が未確認の間は仮定倍率による概算)
- ホロメンボードの反映: ホロメンごとに、ゲーム内と同じ配置のボードで解放したマスを登録できる(左右の配置はホロメンごとの固定データで自動、経路のまとめて解放、すべて解放/解除)。今あるのは青ボードのみで、赤・黄・緑は準備中のタブ。ボードはカードでなくホロメンの状態として持ち、持っているカードで「ボード状況を考慮する」が ON のときに効く(全カードは将来に向けた探索なので現在の育成を混ぜず、素の値で比べる)。マスの表記値の合計をパラメータとアクティブスキルの期待値に反映する(コネクトマスによる増幅は含まない)
- 曲を指定した最適化（曲名・ホロメン名の検索、所属・オリジナル/カバーで絞り込み、曲長・レベルで並べ替え。曲の長さがスキル期待値に反映され、未指定なら全曲の演奏時間の中央値で試算）
- 仮想ガチャシミュレーション(ヘッダ右上のメニューから。ピックアップガチャ、仮想ダイヤと課金相当額の表示。実際の課金・排出とは無関係の遊び機能で、状態はブラウザ内にのみ保存)
- (将来)ホロメンボード補正の残り(緑ボード・所属ボーナス・赤ボード)
