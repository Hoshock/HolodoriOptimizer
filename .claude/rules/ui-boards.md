# ホロメンボードの描画と操作（UI 規則）

UI の規則は 4 ファイルに分けてある（触るファイルに応じて読み込まれる）: `ui-design.md` = 全画面に効く原則 / `ui-flow.md` = 本線フローと入口の構成 / `ui-parts.md` = 一覧・ピッカー・詳細シート・結果表示の部品 / `ui-boards.md` = ホロメンボードの描画と操作。実機での確認手順は `ui-verification.md`。分けた先に規則が見つからないときは 4 ファイルを横断して探す。

## 盤面の描画

- ゲーム内の画面を写す部品（ホロメンボード）は実機の形に忠実にする: マスの配置・向き、大きさの差（大マスは 1.5 倍）、接続点の形（丸角の四角）、マスを繋ぐ線の長さ（正方格子）まで再現し、横スクロールは許さない（縦横で線の長さを変えるのは可）。描画領域は格子の外に数 px の余白を取り、端の大マスの輪（選択の線幅 3px）が切れないようにする。隣り合うマス同士を繋ぐ線は「あることが見える」幅を確保する — 大マス同士が隣り合う組がある赤のステータス系エリア（基準で x ≥ 3）だけ間隔を 40px にし、他は 34px（「全」の表示でも同じ）。
- 空間配置の仕様を図から写すときは、実装前に向きの基準（上下・左右・どちらから見るか）を一言確認する（ASCII 図の上下と 5 マス塊の左右が実機と逆だったことがある）。
- 図の中のマス・ノードの記号は 1 文字まで（全パラ = A、P / T / S、緑の所属向け = ユ、報酬系 = 酬、黄 = ソ / ユ / 全 / レ / キ / 特、赤 = A / P / T / S / 支 / 命 / 判 / 回 / 経 / 金 — 2026-09-08 ユーザー承認）。種類の差（割合か固定か）は文字を足さず大きさ・形で表す。ゲーム内表示にない記号を新しく作るときは候補を先に見せる（読みの 1 文字目や意味の中心の字）。
- ゲーム内で色の名前を持つもの（赤・青・黄・緑）はその色のトークン（`--board-*`）で描く（解放マス・接続線。マスの中の文字はどの色でも白）。選択コントロール自体は濃色地の規則のまま。
- ボード効果の割合はゲーム内どおり小数第 1 位まで（+4.0%、+20.0%、+0.5%）で全色そろえ、整数の「+4%」を混在させない（`formatBoardPercent` / `formatBoardPermil`、`src/data/boardGraph.ts`）。
- ホロメンボードのアイコンは六角形の輪郭 + 解放マス数（開花の花びら + 数字と同じ構成）。**解放マス数は「明示的に解放した通常マス + 解放済みのコネクトマス（赤 / 青 / 黄の C）」**で、中心は数えない（最大 150 + 3 = 153。`src/data/boardCount.ts` / `boardState.ts`）。配置の有無は数に影響しない。「先のマスが解放されていればコネクトも解放扱い」という旧推定（`unlockedPassages`）は撤去済み — コネクトは通常マスと同じく明示的に解放する。

## 操作とモード

- ボードの操作は「解放 | 説明」の 2 モード（名前の下の行に、左に色の 5 択「全 / 赤 / 青 / 黄 / 緑」・右にモードの 2 択）。説明モードはタップしても状態を変えず、選んだマスに濃色の輪（未解放・解放済みで同じ色）をつけ、効果文言を「すべて解放 / 解除」と同じ高さの帯に出す。帯は枠線なしの淡色地で、文言の前に選んだマスの縮小（記号入りの丸）を置く。マス以外をタップすると選択が外れ、直前の選択は色ごとに覚える（保存しない）。帯には通常マスの文言の後ろに「（3 Pt）」を添える。
- **既定のタブは「全」**（2026-09-11 ユーザー指示）: 4 色をゲーム内の全体配置（赤上・緑下・青黄左右。中心のコネクトが原点。赤は lifeSide、青は blueSide、黄はその反対で x 反転）のまま 1 枚に繋げて描く。最初は中心を中央に等倍（11 マス幅）で見せ、**2 本指でピンチ・移動**する — 1 本指のドラッグではボードを動かさずページのスクロールに渡す（`touch-action: pan-y`、2 本指のあいだだけ `touchmove` を止める。2 本指で動かし始めたあと 1 本を離しても、残りの 1 本で離すまで動かし続ける。PC はマウスのドラッグとホイール。動かしたジェスチャの click はマスへ届かせない。移動は全体配置の広がりの中、拡大率は 0.5〜3 倍）。マス・接続線はそれぞれの色で描き、解放・説明の操作は色ごとの表示と同じ。効果表は 4 色ぶんを縦に並べるだけで色の見出しは付けない。「すべて解放 / 解除」は表示している 4 色すべてに掛かる。
- **「すべて解放 / 解除」の右に 44px 正方形のアイコンボタンで「1 つ前に戻る / 1 つ先に進む」**（アイコン 28px。シートを開いている間だけ、進めないときは disabled）。**履歴はマスの解放・解除に加えて、コネクトの付け外し・解放・解除（ほかの場所から外して持ってきたものも）を 1 手ずつ戻す**（2026-10-10 ユーザー指示「ボードの undo でコネクトのつけ外しなども戻せるように拡張」）。履歴は `OptimizerPanel` が持ち（`useEditHistory`。写しは開いているホロメンのボード全体 + 全ホロメンのコネクトの配置）、`BoardSheet` は押せるかを props で受けて `undo` / `redo` を出すだけ。戻せるので、**コネクトや配置が一緒に外れる解除にも確認を挟まない**（同日「コネクトマスの効果を外すと、のページ不要じゃね？」）。
- **組み直しプランの「ボードを開く」から開いたときだけ、名前の上に全幅の「現在 / 推奨」**（`view` / `update:view`。既定は推奨。推奨は `preview` で、解放のモードは隠さず disabled、Pt は推奨のボードの使用 Pt。推奨の印（点滅・斜線）は**いまの登録**（`baseline` / `baselinePlacements`）と比べ、コネクトマスも解放・配置が違えば点滅、解放を外すなら斜線。現在はふだんの編集。どちらでも名前の行・色とモードの行・下の帯の高さは同じ — 中身は `ui-flow.md` の組み直しプラン）。ふだんの入口（Step 0 のボード）では出さない。
- **中央のコネクトマスは全色に跨るので、入力済みの地はボードの色でなく選択コントロールと同じ濃色**（`--primary`）。
- 色ごとの表示で 1 つの図を画面幅に収まらない部分に分けて見せるときは、独立した切替部品やスワイプを足さず、内容が画面の外へ続く位置に出口（◀左 / ▲上 / 右▶ / ▼下 の小さな丸角四角）を描いてタップで移る。名前は意味ではなく物理的な位置で、接続線も出口まで引く。出口で移ったらスクロールを一番上へ戻し、一括操作は表示中の部分だけに掛ける。赤ボードの 4 エリア: **1 つの部分に出口の名前と反対の方向の内容を混ぜない** — 幹 = 「下」（中心を含む。最初に出す）、格子 = 「上」。下エリアは C の周りまで（C の左右 2 マスずつとその上の R-022 / R-032、R-021 の上の R-049 を含む 16 マス）、左エリアは 命 の R-023 から、右エリアは R-033 から、上エリアは R-050 から。**中心のあるエリアへ戻る出口の名前は「中」**（1 文字）、位置は境のマスの真下、**矢印は中心のある向き**（左からは →、右からは ←、上からは ↓）。**出口の位置にも実マスがあるので、その解放状態を出口の箱に反映する**（淡いままだと「そこにマスがない」ように見える）。出口の位置のマスは飛び先のエリアで普通のマスとして触れるので、同じマスを両方で触れるようにはしない（どのマスもちょうど 1 つのエリアで解放できることを `redBoard.test.ts` で固定）。

## ホロメンのピッカー（`HolomenPicker.vue`）

- 並び順は左から **ホロメン順 / ランク順 / ボード開放順** の 3 つのセグメント（既定はボード開放順。2026-10-09 ユーザー指示で五十音順を廃止してホロメン順に替えた）。解放マス・ランクは多い方から、ホロメン順は表の先頭からが基準で、同じキーをもう一度押すと逆になる。**ラベルは名前だけで固定し、向きは選択中の ▼（降順）/ ▲（昇順）だけで示す**（「逆順」「多い順」のような言葉は使わない — 2026-10-09 ユーザー指示。曲ピッカーの「Lv 高い順 / 低い順」とは違う形）。**ホロメン順**は `src/ui/labels.ts` の `HOLOMEN_ORDER`（所属のデビュー順 → 各所属の中はユーザー指定の並び。フブキは 1期生の位置）で、解放マス・ランクで同数のときもこの順。ランク未登録のホロメンはどちらの向きでも最後。リストの先頭の行の上に余白を置かない。
- 行は**名前（ボードを開く）・Rank（押すと +/- の `StepperDialog` — 1 ずつと 10 ずつ・未登録は 30 から・「未登録に戻す」あり。未登録は淡く「Rank --」。枠は登録の有無で大きさを変えず固定幅 80px）・六角形の解放マス数**の 3 つで、名前と六角形のどちらを押してもボードが開く。

## ホロメンランクとボードPt

出所・前提・仕様の正典は `docs/human/game-spec.md`「ホロメンランクとボードPt」と ADR-012。

- ボード画面は**名前の行の右端に使用ボードPt だけ**を書く（「94 / 135 Pt」。枠・Rank・残り・超過の文は出さない。未登録は使用Pt だけ「94 Pt」、超過は同じ書式を `--error` で。名前が長いときは名前だけを省略し Pt は必ず収める — `.who-row`）。**Pt は表示だけで、押してもランクは変えられない**（ランクの入力はホロメンのピッカーの行だけ）。
- ランク登録済みで必要Pt が残りを超える解放（マス・経路・コネクト・「すべて解放」）は**操作全体を拒否して何も変えず**、中央のダイアログ（`NoticeDialog`）で「ボードPt が N Pt 足りません」（超過中は「ボードPt を N Pt 超えています」）と知らせる（2026-10-10 に文を短くした）。**解除は常にできる**。すでに超過している登録は自動では削除しない。

## キューブ・コアキューブ（リソース）

- **開けると「リソース」の余りが減り、外すと戻る**（2026-10-10 ユーザー指示「ボードで解放すると資材が減るべきなのに減らない」。経路ごと開けたマスも数える。消費量は `src/data/boardMaterials.ts`、計算は `src/ui/boardSpend.ts`。未登録 = ∞ の項目は変えない）。増減するのは受け側（`OptimizerPanel` の `commitBoards`）で、**戻る / 進むは余りも一緒に戻す**（履歴の写しに余りを入れた）。コネクトの解放（資材 0）・解除（先のマスのぶん戻る）も同じ。
- **余りを超えて開けるとき（「すべて解放」も）は、Pt と違って止めずに `ConfirmDialog` で聞く**（同日ユーザー指示「資材以上を解放するときはモーダルで確認しつつ − にする余地を残す」）: 「リソースが足りないまま解放しますか？」+ 赤い文「赤のキューブ 45・赤のコアキューブ 5 が不足します」（足りない個数 = 開けたあとの負の余り。文の一片は組み直しプランの反映の確認と同じ `shortageLabels`。その操作で使う項目だけを見て、前からの不足だけでは聞かない）+「キャンセル / 解放する」。「解放する」でマイナスのまま開ける。外す操作では聞かない。判定はシート（`BoardSheet` の `resources`）で、確認ダイアログはシートのオーバーレイの子。

## コネクトマス

- コネクトマス（人物アイコン）は**範囲の形と倍率を入れる場所**（`src/data/connect.ts`）で、解放の状態と効果の配置は別。**3 状態の見た目**（どの状態でも不透明の下地を敷き、下を通る接続線が透けない — 線は枠から出る）: **未解放**（淡い実線の枠・淡い人物。点線は隙間から接続線が透けるので使わない）/ **解放済み・配置なし**（ボードの色の枠 + 薄い地・ボードの色の人物。中心は濃色）/ **解放済み・配置あり**（地をボードの色にして人物を白抜き）。**線の色もコネクトの解放状態と一致させる** — 未解放のコネクトを跨いでその先まで線が有効色になってはいけない（中心だけが常に通れる）。**「すべて解放 / 解除」は対象に入る赤 / 青 / 黄のコネクトも解放・解除する**。
- 解放モードでタップすると中央のモーダル `ConnectSheet.vue` が開く（器は 1 つで、見出しの行に「コネクト効果」・「一覧」・✕。2026-10-10 ユーザー指示「サイドバーでなくモーダルにしたい」— それまでは右から出るサイドバーで、ここだけ出方が違った）。**モーダルの上にモーダルを重ねない** — 倍率・持ってくる場所・一覧は、同じモーダルの本文を切り替えて出す（「モーダルの上にモーダルってキモい」「図形選択したらそれが拡大されて％選べるようになる」「シームレスにアニメーション入れて」）。本文の高さは形の一覧で決まり、ほかの中身はその上に重ねるので大きさは変わらない。**形を押すと、その図形（ヒーロー）がタイルの位置から本文の上部へ拡大して移り**（0.34 秒。形の一覧は少し奥へ引いて消え、倍率の候補は下から浮かぶ）、**残り 0 の倍率を選ぶと、その行の矩形がその場で広がって中に持ってくる場所が出て、下の候補は押し下げられる — 図形は動かさない**（「その後のページでどこから外すかみたいなやつでまた図形の位置変わったりするのキモい」「％選んだらそこの矩形が広がって他の%の候補は下に行ってってかんじ」。高さは grid-template-rows の 0fr ⇄ 1fr で 0.32 秒、同じ行をもう一度押すと閉じる。図形 → ％ の行は 1 本の縦の流れで余白は 16px、場所が多いときは中身ごとスクロールし、広がりきったときに画面の外なら見えるところまで送る。図形は動き終えたら枠の中に描き直す — 本文に重ねたままだとスクロールについてこない）。見出しの左の「戻る」で形の一覧へ戻る（行を広げていても、いったん閉じずにそのまま — 2026-10-10 ユーザー指示。図形は元のタイルへ縮んで戻る）、「一覧」は右から送られてくる。`prefers-reduced-motion` では動かさない。図形の位置は transform に左右されない offset で測る（中身が浮かび上がる途中に測ると行き先がずれる）。**中心以外は見出しの下に「コネクトマスを解除」「コネクトマスを解放」を左右に等幅で置き、解放は右**（2026-10-10 ユーザー指示。Pt の表記・見出し・理由の説明文は出さない。解放は直前のマスまで解放していて予算が足りるときだけ押せ、解放済みのときは disabled。解除は解放済みのときだけ押せ、確認は挟まない — 戻るで戻せる）。**未解放のあいだは形・倍率を入れられない**。**「外す」は図形と同じタイルで左上**（入れていないときも枠は残して disabled）。通常マスの解除でコネクトが外れて配置も外れるときも、確認せずに解除する（戻るで戻せる）。**「一覧」はどこにもコネクト効果を置いていないときは押せない**（空の一覧は出さない — 2026-10-10 ユーザー指示「空のときはそもそもその導線のボタンなどを押せないようにする」）。
- 範囲の形 17 種を図形（7 × 7 の格子、塗りはそのボードの色）で 4 列に並べる（2026-10-10 ユーザー指示で 2 列から）。**図形の向きは物理座標のまま（右 = +x、上 = +y）で、ホロメンの左右配置やコネクトマスの色で反転しない** — 形はカードの性質で、ユーザーがゲーム画面の光る範囲を見たまま写す（2026-09-11 ユーザー指示「図形の反転はやめる…純粋に形で決まる」。計算側 `connectTargets` も反転せず、反転して保存していた形は読み込み時に写す — `storage-compat.md`）。タイルは全部同じ大きさの正方形、並びは効果のあるマスの数が少ない順を第一に、同数の中で対称な形が左右に並ぶ固定順（`CONNECT_EXTENT_DISPLAY_ORDER`）で、**入れてある形だけを先頭に**出す（対の形は動かさない）。見出しの下のサブタイトルは出さず、入れた倍率は**タイルの右上**で図形に被らない位置（余白は対称に保ち中心の四角をタイルの中心に）。札の幅で右上の角のマスにかかる**上十字（「上へ 3 + 2 段目の左右」）だけ右下**に置く（2026-10-10 ユーザー指示。`src/ui/connectBadge.ts` の `badgeAtBottom`、アカウントの「コネクト」のタイルも同じ）。
- 形をタップすると倍率の中身 `ConnectPermilPane`（拡大した図形の下に、アカウントの「コネクト」の ％ ごとの行と同じ横幅いっぱいの行 — 左に ％・右に残り。見出しの「範囲内のホロメンボード効果を UP」は自明なので置かない — 2026-10-10 ユーザー指示「横幅いっぱいのチップにしよう。バランス悪すぎる」）で**倍率を候補から選び**、選んだらそのまま確定して閉じる（2026-10-02 ユーザー指示「テンキーの自由入力をやめてありえる候補からの選択制に」。候補は形ごとに取りうる ‰ を Lv1 / Lv2 で合わせた重複なし・昇順 — `connectPermilCandidates`。**保存済みの値が候補にないとき**は候補の末尾にその値を添えて選択中にし、開いただけでは値を変えない — `ConnectSheet.test.ts`）。外す操作は形の一覧の左上の「外す」。
- 配置あり: **範囲に入っているマスは解放の有無を問わず虹色のグラデーションの輪**（`.range-ring`。解放済みは点灯、未解放は点滅。`prefers-reduced-motion` では点滅せず半透明）。輪の幾何は説明モードの選択の黒い輪と同一（マスの円周上に線幅 3。外側に足す輪は大マスと隣のマスで重なる）。
