# ホロメンボードの描画と操作（UI 規則）

UI の規則は 2026-09-09 の棚卸し 24 回目で 4 ファイルに分けた（触るファイルに応じて読み込まれる）: `ui-design.md` = 全画面に効く原則 / `ui-flow.md` = 本線フローと入口の構成（`OptimizerPanel` / `App` / サイドメニュー）/ `ui-parts.md` = 一覧・ピッカー・詳細シート・結果表示の部品 / `ui-boards.md` = ホロメンボードの描画と操作。実機での確認手順は `ui-verification.md`。分けた先に規則が見つからないときは 4 ファイルを横断して探す。

- ゲーム内の画面を写す部品（ホロメンボード）は実機の形に忠実にする: マスの配置・向き、大きさの差（大マスは 1.5 倍）、接続点の形（丸角の四角）、マスを繋ぐ線の長さ（正方格子）まで再現し、横スクロールは許さない（縦横で線の長さを変えるのは可 — 2026-09-06、4 往復）。描画領域は格子の外に数 px の余白を取り、端の大マスの輪（選択の線幅 3px）が切れないようにする（2026-09-07）。ボードの操作は「解放 | 説明」の 2 モード（名前の下の行に、左に色の 4 択・右にモードの 2 択）。説明モードはタップしても状態を変えず、選んだマスに濃色の輪（未解放・解放済みで同じ色）をつけ、効果文言を「すべて解放 / 解除」と同じ高さの帯に出す。帯は枠線なしの淡色地で、文言の前に選んだマスの縮小（記号入りの丸）を置く。マス以外をタップすると選択が外れ、直前の選択は色ごとに覚える（保存しない — 2026-09-07、3 往復）。空間配置の仕様を図から写すときは、実装前に向きの基準（上下・左右・どちらから見るか）を一言確認する（ASCII 図の上下と 5 マス塊の左右が実機と逆だった）。 隣り合うマス同士を繋ぐ線は「あることが見える」幅（数 px）を確保する — 大マス同士が隣り合う組がある赤のステータス系エリアだけ間隔を 34 → 40px にし、他のエリア・他の色は 34px のまま（「大マスが隣り合う時接続線が狭すぎる」「それ以外は他の色の線の長さと一緒でいい」— 2026-09-08）。
- 1 つの図を画面幅に収まらない部分に分けて見せるときは、独立した切替部品（セグメント・トグル）やスワイプを足さず、内容が画面の外へ続く位置に出口（◀左 / ▲上 / 右▶ / ▼下 の小さな丸角四角）を描いてタップで移る。名前は意味（ライフ系 / ステータス系）でなく物理的な位置（左 / 上 / 右 / 下）で、接続線も出口まで引く。出口で移ったらスクロールを一番上へ戻し、「すべて解放 / 解除」のような一括操作は表示中の部分だけに掛ける（赤ボードの 4 エリア。セグメント案は「別トグルを用意したくない。スマートな UI を。スワイプ切替は嫌。名前も左上右にして」で置き換え — 2026-09-08）。**1 つの部分に出口の名前と反対の方向の内容を混ぜない** — 幹と最上部の格子を 1 つの「上」にしていたのを、幹 = 「下」・格子 = 「上」に分け、赤のタブで最初に出すのは中心を含む「下」（2026-09-11「上って押してるのに下方向も出るのわかりにくい。下も追加しよう。最初は下エリアの表示に」）。**下エリアは C の周りまで**（C の左右 2 マスずつとその上の R-022 / R-032、R-021 の上の R-049 を含む 16 マス。左エリアは 命 の R-023 から、右エリアは R-033 から、上エリアは R-050 から — 2026-09-11「左のSと、その左と上にそれぞれあるSとAは下エリアに含む。命マスから左エリア。右も同様。上エリアも支の上のAから」）。**中心のあるエリアへ戻る出口の名前は「中」**、位置は境のマスの真下（左は 命 の下、右は R-033 の下、上は R-050 の下）、**矢印は中心のある向き**（左のエリアからは →、右からは ←、上の格子からは ↓ — 2026-09-11「左エリアと右エリアからの移動は下ではなく中央」→ 右隣に 2 文字の「中央」を置いたら「位置違うし、欠けてる。中にしよう。命の下に何もないように見えるから命の下で中」→「左エリアなら ↓中ではなく →中とかにして。右エリアも」。出口の名前は 1 文字に収める）。**出口の位置にも実マスがあるので、その解放状態を出口の箱に反映する**（解放済みなら解放色。淡いままだと「そこにマスがない」ように見え、隣のマスがもう開けられることが読み取れない — 2026-09-13 ユーザー報告「右と書かれている場所には本来マスがある。そこが解放されていれば A はあけられる」）。出口の位置のマスは飛び先のエリアの表示で普通のマスとして触れるので、同じマスを両方で触れるようにはしない（どのマスもちょうど 1 つのエリアで解放できることを `redBoard.test.ts` で固定）。
- **既定のタブは「全」**（2026-09-11 ユーザー指示）: 色の 4 択の左に「全」を置き、4 色をゲーム内の全体配置（赤上・緑下・青黄左右。中心のコネクトが原点。赤は lifeSide、青は blueSide、黄はその反対で x 反転）のまま **1 枚に繋げて描く**。最初は中心のコネクトを中央に等倍（11 マス幅）で見せ、**2 本指でピンチ・移動**する — **1 本指のドラッグではボードを動かさず**ページのスクロールに渡す（`touch-action: pan-y`、2 本指のあいだだけ `touchmove` を止める。**2 本指で動かし始めたあと 1 本を離しても、残りの 1 本で離すまで動かし続ける** — 2026-09-11「2 本指で少し動かしたあと手を離さずにいたら 1 本指で動かせたい」。PC はマウスのドラッグとホイール。動かしたジェスチャの click はマスへ届かせない。移動は全体配置の広がりの中、拡大率は 0.5〜3 倍 — 2026-09-11「ドラッグ、スクロールスムーズに動かないな。2 本指で動かすことにしよう。1 本指でのドラッグではボードは動かないように」）。赤のステータス系（基準で x ≥ 3）は全でも横の間隔を 40px にして大マス同士を重ねない（「全体図のそのエリアではそうなってないせいで丸が重なってる」）。マス・接続線はそれぞれの色で描き、解放・説明の操作は色ごとの表示と同じ。効果表は 4 色ぶんを縦に並べるだけで**色の見出しは付けない**（「説明文の左下に赤とか書いてあるの何？不要」）。「すべて解放 / 解除」は表示している 4 色すべてに掛かる。**「すべて解放 / 解除」の右に 44px 正方形のアイコンボタンで「1 つ前に戻る / 1 つ先に進む」**（アイコンは 28px — 20px は「小さすぎる」。解放の履歴。シートを開いている間だけ、進めないときは disabled。コネクトの入力は含めない — 2026-09-11 ユーザー指示）。**中央のコネクトマスは全色に跨るので、入力済みの地はボードの色でなく選択コントロールと同じ濃色**（`--primary`。「トグルボタンの選択色と一緒」）。
- ホロメンボードのピッカー（`HolomenPicker.vue`）の並び順の既定は**解放マスが多い順**（ラベルも「解放マスが多い順 / 少ない順」。五十音順は 2 つ目 — 2026-09-11）。リストの先頭の行の上に余白を置かない（上の余白 8px で先頭の行だけ上下が非対称に見えた — 2026-09-11「一番先頭のメンバーの上側と下側の余白が違う」）。
- 図の中のマス・ノードの記号は 1 文字まで（全パラ = A、P / T / S、緑の所属向け = ユ（ユニット。2026-09-08 に「グ」から変更）、報酬系 = 酬、黄 = ソ / ユ / 全 / レ / キ / 特、赤 = A / P / T / S / 支 / 命 / 判 / 回 / 経 / 金 — 2026-09-08 ユーザー承認）。種類の差（割合か固定か）は文字を足さず大きさ・形で表す（「全」→「All」→「A」、「P%」→「P」と 2 段階で削られた — 2026-09-06）。ゲーム内表示にない記号を新しく作るときは候補を先に見せる — 「所」「報」は「グループのグ、報酬は酬」に直された（読みの 1 文字目や意味の中心の字 — 2026-09-07）。ホロメンボードのアイコンは六角形の輪郭+解放マス数（開花の花びら+数字と同じ構成）。**解放マス数はゲーム内の数え方**で、中心以外のコネクトマス（赤 / 青 / 黄の C）も「そこを通らないと届かないマスが解放されているとき」だけ 1 マスとして数える（経路が手前で止まっていれば数えない。`src/data/boardCount.ts` / `boardGraph.ts` の `unlockedPassages` — 2026-09-11「全ボードの中心以外のコネクトマスも開放マスの数に入る。ただしマスに到達してない場合は開放扱いにならない」）。
- ゲーム内で色の名前を持つもの（赤・青・黄・緑のホロメンボード）は、その色のトークン（`--board-*`）で描く（解放マス・接続線。マスの中の文字はどの色でも白 — 2026-09-09 ユーザー指示で黄も濃茶から白へ）。選択コントロール自体は濃色地の規則のまま。用意できていない種類はタブとして先に置き disabled で見せる（Step 0 の「ユニット」と同種 — 2026-09-07。ボードの色は 2026-09-08 に赤も入り 4 色そろった） 切替の既定（シートを開いたときの色）も実装順でなくゲーム内の並びの先頭にする（青で実装を始めたが「ボードのデフォルトは青じゃなく赤」— 2026-09-08）。
- コネクトマス（人物アイコン）は解放の対象ではなく**範囲の形と倍率を入れる場所**（2026-09-11、暫定仕様 — `src/data/connect.ts`）。解放モードでタップすると右のサイドバー `ConnectSheet.vue` が開き、範囲の形 17 種を図形（7 × 7 の格子、塗りはそのボードの色）で 2 列に並べる。**図形の向きは物理座標のまま（右 = +x、上 = +y）で、ホロメンの左右配置やコネクトマスの色で反転しない** — 形はカードの性質で、ユーザーがゲーム画面の光る範囲を見たまま写す（青が右のホロメンで青のコネクトの形を反転して見せていたのを「図形の反転はやめる。コネクトマスは左右のどちらに青エリアがあるかとか気にしない。色に関係ないので。純粋に形で決まる」で廃止。反転していた時期は対の形の見た目がホロメンによって入れ替わって見えた — 2026-09-11）。計算側（`connectTargets`）も反転せず、反転して保存していた形は読み込み時に左右反転した形へ写す（`unmirrorPlacements`、`connect-placements` v2 → v3、`debug-boards` v1 → v2。「既存の localStorage 壊れないように注意」） — タイルは**全部同じ大きさの正方形**、並びは**効果のあるマスの数が少ない順を第一に、同数の中で対称な形が左右に並ぶ固定順**（`CONNECT_EXTENT_DISPLAY_ORDER`）で**入れてある形だけを先頭に**出す（対になる形は動かさない。「入力した図形は一番目」→ 対も一緒に上げていたのを「そのペアみたいなのも一緒に上に来るのはやめよう」で戻した — 2026-09-11）、見出しの下のサブタイトルや倍率の候補は出さず、入れた倍率は**タイルの右上**で図形に被らない位置（どの形も使わない角の 2 × 2 マスに収める。余白は対称に保ち中心の四角をタイルの中心に。2026-09-11「サブタイトルは不要。対称性を考慮。候補の表示も不要、自分で入れる。囲みのサイズを完全に統一、可能なら正方形。入力した図形は一番目」→「やっぱ % 表示右上で。図形に被らないように。マスは正方形に。中心の四角が中心に来るように」）。形をタップすると `NumberPad`（小数 1 桁・上限 999%）で倍率を入れ、決定で確定して閉じる。確定したアイコンは地をそのボードの色にして人物を白抜き、**範囲に入っているマスは解放の有無を問わず虹色のグラデーションの輪**（`.range-ring`。解放済みは点灯、未解放は点滅。`prefers-reduced-motion` では点滅せず半透明）で示す。輪の幾何は**説明モードの選択の黒い輪と同一**（マスの円周上に線幅 3。外側に足す輪は大マスと隣のマスで重なり「でかいマスの時オーバーラップする」— マスの外径を変えず文字にも掛からず、選択すると黒線がちょうど上に重なって隠す — 2026-09-11 実機指摘） — 解放済みだけの点線の輪は「解放していないマスにも影響が可視化されて欲しい」「点線は可読性が悪い。解放している時は虹色のグラデーション、解放していない時はそれの点滅」で置き換えた（2026-09-11）。外す操作はサイドバーの下の「外す」。サイドバーの見出しの右に「一覧」ボタン（一覧アイコン + 文字）を置き、押すと中央のダイアログ `ConnectListDialog.vue` 倍率）を出す（2026-09-11「どのコネクトマスを誰のホロメンボードに使っていてその倍率がいくつか、みたいなのの一覧が見たい。アクセスはコネクト効果のサイドバーの右上に分かりやすいボタンで。ダイアログが出るのがいい」— 添付のイメージは形 / 倍率 / ホロメンの表。最初はコネクトマスごとに色分けと「中心 / 青」の字を添えたが「色の違いは区別必要ない。中心とか青とかの文も。純粋に形。並びはマスの少ない順かつ似ているものは近くに」で外した）。図形の描画は `ConnectFigure.vue` でタイルと一覧が共用する。説明モードでコネクトマスをタップすると「範囲内のマス +X%」だけを帯に出す（アンカー名・形の名前は付けない。入れていなければ空 — 2026-09-11「範囲内のマス +100% みたいな感じだけ」「赤ボードのコネクト: とかいらない」「開けてない時の説明は空白」）。帯の先頭の縮小は通常マスと同じく必ず置き、コネクトマスは人物アイコンの丸角四角（入力済みならボードの色に白抜き — 2026-09-11「コネクトマスの時だけアイコン出てないね。他のマスだと説明文の先頭にアイコンでるのに」）。範囲に入っているマスの説明は**増幅後の値だけ**を書く（表記値との対比・倍率は書かない — 2026-09-11「説明モードの時コネクト効果込みの効果表示にして」→「効果分上がった数字で書けばいいだけ。変化とかいらない」）。盤面の下に一覧表は置かない（「表のところに出す必要はない」）。通常マスの経路解放とはイベントを分ける（`connect`）。カードは指定しない（「ホロメンカードを指定するよりそちらの方が楽」— 最初はカード選択で作って差し戻された）。公式の画像は使わない（既存の人物アイコンを流用）。
- ボード効果の割合はゲーム内どおり小数第 1 位まで（+4.0%、+20.0%、+0.5%）で全色そろえ、整数の「+4%」を混在させない（`formatBoardPercent` / `formatBoardPermil`、`src/data/boardGraph.ts`。青の発動率・黄のホロワーク報酬が整数表記だった — 2026-09-08「小数第一位で .0% までつけること。他の色のボード効果も表記揺れしてるので直す」）。
