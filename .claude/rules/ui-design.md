# UI デザインの制約(2026-08-31 ユーザーフィードバック由来)

- モバイルファーストで設計する。iPhone 実寸(390px 級)での崩れ・不自然な改行は出荷前に playwright-cli で確認する(確認手順は docs/ai/rules/ui-verification.md)。
- 「AI デザインの典型」を使わない: カード片側の細い色ストライプ、意味のないグラデーション、全要素同一の角丸+影、装飾絵文字。地・罫線は無彩色に保ち、色は意味(タイプ・状態)にだけ使う。
- 色は意味に整合させる: 選択強調はそのカードのタイプ色を使い、無関係な固定色(例: ピュアのカードにピンク枠)を当てない。タイプ色の正はキュート=ピンク/ハッピー=黄/ピュア=緑(docs/human/game-spec.md)。黄は淡地+濃文字でのみ使う(白抜き禁止)。
- UI は「何も知らないユーザー」のユーザーストーリーから設計する。長いドロップダウンで選ばせない — 検索+フィルタつきの視覚的な選択 UI にする。
- 選択 UI は単一選択か複数選択かがぱっと見で分かる形にする(単一=常にちょうど 1 つが塗り+チェック、など)。除外などの状態は件数だけでなく「何が」対象かを一覧で見せる。
- カード類の高さは文字列長で揺らさない(行数固定+省略)。数値は `tabular-nums`。
- デザイントークンの正は `src/style.css` の `:root`。根拠と定石の出典は docs/human/tmp/20260831-design-research.md。
