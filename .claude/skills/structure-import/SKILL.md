# スクショからの構造化インポート (structure-import)

このスキルは、ホロドリ編成お助けツールが**貼り付けて取り込める JSON の形**を定義する。想定する流れは「ユーザーが自分のゲーム内スクショを**自分の端末のローカル LLM** に渡す → このスキルの指示に従って構造化データを作らせる → その JSON をコピーしてサイトの取り込み欄に貼る」。画像はどこにもアップロードされず、サイトはサーバを持たないので、貼った内容はそのブラウザの `localStorage` に入るだけである（`.claude/rules/storage-compat.md`）。種別ごとのスキーマは References にあり、このファイルは全種別に共通する封筒・禁止事項・手順だけを持つ。

## 共通の封筒

種別が増えても貼り付け口を 1 つに保つため、どの種別も同じ封筒に入れる。

```json
{
  "format": "holodori-optimizer/import",
  "version": 1,
  "kind": "owned-members",
  "capturedAt": "2026-09-10",
  "notes": ["人間向けの補足。任意"],
  "unreadable": [{ "reason": "指で隠れている", "hint": "3 枚目の右下" }]
}
```

- `format` / `version` / `kind` は必須。`format` は固定文字列で、無関係な JSON を貼ったときにサイト側が弾くための目印。`version` は封筒の版で、フィールドを増やしても読めるように上げない（互換を壊す変更のときだけ上げる）。
- 種別ごとの本体（所持メンバーなら `cards`）は `kind` に対応するキーへ入れる。詳細は References。
- `capturedAt`（スクショを撮った日付）・`notes`・`unreadable` は任意。`unreadable` は**読み取れなかったものを黙って落とさないため**の枠で、人間が後から手で埋める材料になる。
- 出力は**コードブロック 1 つの JSON だけ**にする（ユーザーはそれをそのままコピーする）。説明はコードブロックの外に書く。

## 守ること

- **推測で埋めない。** 読めなかったものは `unreadable` に理由つきで置く。0凸と読み間違えるより、未読取のまま人間に回すほうが安い（試算がずれると原因が追えなくなる）。
- **スクショ・画像そのものを出力やリポジトリに持ち込まない。** base64 の埋め込みも不可。公式アセットをコミットしない方針（ADR-002）は、この経路にも同じく効く。
- **プレイヤー名・ユーザー ID・フレンドコード・課金履歴などの個人を特定する情報を出力に含めない。** スクショの隅に写っていても構造化データには入れない。
- **ゲームクライアントの解析・データダンプ由来のマスターデータを使わない**（ADR-002）。名前の確認はスクショの目視とネット検索（攻略サイトの一覧）で行い、**両者が食い違ったらスクショ（実機）を優先する**。
- **カードの数値（P/T/S・レベル）は出力しない。** ツールはカードデータ側の値を使い、ユーザーの入力として保存するのは「どのカードを持っているか」と育成状態だけ（`.claude/rules/storage-compat.md`）。

## 手順

1. どの種別を作るのか決め、対応する References を読む。
2. 必要なスクショが揃っているか確かめる（種別ごとの「必要なスクショ」の節）。足りなければ、何をどう撮ってほしいかを具体的に伝える — 撮り直しのほうが推測より速い。
3. スクショ 1 枚ずつ、写っているものを列挙する。複数枚にまたがる重なりは最後に 1 件へまとめる。
4. 読み取りが怪しい固有名詞（漢字・カタカナ・英数の混在）はネット検索で正式表記を確認する。確認できなければ `unreadable` へ。
5. 封筒に入れた JSON をコードブロック 1 つで出す。
6. コードブロックの外に、人間が確認すべきことだけを短く添える: 件数、`unreadable` の中身、判断に迷った行。

## 出力前の自己チェック

- 種別ごとの必須フィールドが全件そろっているか。型・範囲（整数か、上限下限）を外していないか。
- 同じ対象を 2 行に分けていないか（スクショの重なり）。
- 推測で埋めた値が残っていないか。
- 個人を特定する情報・画像・カードの数値が混ざっていないか。
- JSON が単体で妥当か（末尾カンマ・全角の引用符・コメントが入っていないか）。
