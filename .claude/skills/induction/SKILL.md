# フィードバックの帰納

ユーザーの訂正・好みから、将来も有効な規則だけを抽出する。

## 分類

- **事実の訂正**: 対象の正典や Golden を直す。ルール候補にはしない。
- **1 回の好み・事例**: 再利用できそうな場合だけ具体例として一時記録する。
- **一般規則**: ユーザーが一般化した、または同種の訂正が繰り返された場合に候補化する。

未査定の候補は `docs/ai/tmp/rules.md` に `Rules` / `Cases` で記録する。ファイルがなければ作る。候補が無いのに「今回もなし」という履歴を残すためだけには作らない。

housekeep で次へ昇格する。

- 無条件の全体規則 → `CLAUDE.md`
- パス限定規則 → `.claude/rules/`
- 手順・専門知識 → `.claude/skills/`
- ゲーム仕様・人間向け事実 → `docs/human/`
- 覆しにくい設計判断 → `docs/adr/`

昇格後、`rules.md` が空なら削除する。
