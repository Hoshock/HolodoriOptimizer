# Docs-Convention

docs/ の文書は、誰が保守するかで置き場を分ける。`human/` は人間が読むために人間が書く文書(運用ガイド、設計書、議事録など)で、読みやすさも人間が整える。エージェントは読んでよいが、頼まれない限り書き換えない。`ai/` はエージェントが自分のために書いて保守する文書で、作業の中で自由に更新してよく、人間向けの読みやすさは要らない。`adr/` は決まったことの記録で、人間が決めて文章はエージェントが書くこともあるため、この分け方を当てはめない。

## 置き場

CLAUDE.md の「ドキュメントの分担」表には、この表をそのまま入れ、リポジトリ固有の行(状況ログ・一次情報の所在など、具体的なファイルを指す行)を下に足す。パスは文書ルート(既定 `docs/`)からの相対で書く。

| 内容の種類                                                                       | 置き場                                        | 扱い                                                                                           |
| :------------------------------------------------------------------------------- | :-------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| 人間が書き、人間が責任を持つ文書(運用ガイド、設計書、議事録)                     | `human/`                                      | 頼まれない限り書き換えない。誤りに気づいたら指摘だけする。人間の指示があって初めて作る         |
| エージェントが書いて保守するリファレンス(用語集、体制、一次情報の所在、状況ログ) | `ai/`                                         | 作業の中で更新する。古くなった部分は棚卸しで要約に縮める                                       |
| 作成日時点の記録(一回の調査結果、検討メモ)                                       | `ai/snapshots/YYYYMMDD-<topic>.md`            | 作ったあと更新しない。消すかどうかは人間が決める                                               |
| 進行中のタスクの計画・進捗・保留                                                 | `ai/tmp/`(plan.md / progress.md / pending.md) | タスクが終わったら、残すものを移して丸ごと消す。「まだ決めていない」は置き続ける理由にならない |
| ユーザーの訂正・作業中に見つけた落とし穴                                         | `ai/tmp/journal.md`                           | 訂正を受けたターンのうちに書く(`journal`)。棚卸しで規則にまとめて移す                          |
| 覆しにくい決定(ほかの選択肢を閉じ、戻すのにコストがかかるもの)                   | `adr/`                                        | 新しい ADR を書く。追記はしてよいが、決定の中身は変えない。書き方は `adr-convention`           |
| エージェント向けの恒久ルール(どの作業でも要る)                                   | CLAUDE.md の「作業ルール」                    | docs/ には置かない。docs/ の文書は読みに行かない限り読まれないため                             |
| 特定の作業でだけ要る手順・ルール                                                 | その作業のスキル                              | 同上                                                                                           |
| 毎回、機械的に起きなければならないこと                                           | hook または CI チェック                       | 文章で書いても依頼にとどまる                                                                   |

## 索引

文書ルートに `index.md` を置き、ルート配下のすべての文書を 1 行ずつ並べる。`adr/` は `adr/index.md` に委ね、`ai/tmp/` の行はファイルがなくても残す。整合は棚卸し(`distill`)が `check-docs.py` で検査する。

## 複数の所有者が同居するリポジトリ

チームや個人の文書が 1 つの `docs/` に同居するなら、`docs/<owner>/` を所有者ごとの文書ルートにし、上の表のパスと `index.md` はその下に置く。ルートが `docs/` でないことは、所有者の CLAUDE.md の分担表の前に 1 文で書く。
