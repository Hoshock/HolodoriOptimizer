# 緑ホロメンボードのノード構成（2026-09-07 ユーザー実機確認）

緑ホロメンボードは全体配置の**下**にあり、全ホロメン共通で左右反転などの配置差はない。座標は青と同じ向きで、x は右が正・**y は上が正**、`(0, 0)` が全ボードの中心のコネクト（コネクトに色という概念はない）。緑は y ≤ -1 の側。効果はアカウント全体に効く（編成の有無にかかわらず、登録した全ホロメンの緑ボードの「全員の〜UP」が全カードに、所属向けの UP がその所属のカードに足される — parameter-calculation スキル）。解析由来の情報は参考にとどめ、確定は実機確認で行った（2026-09-07 ユーザー判断）。実装は `src/data/greenBoard.ts`（ツールのマス内の記号は A / P / T / S / ユ（ユニット = 所属向け。2026-09-08 に「グ」から変更）/ 酬（報酬・獲得量）— ユーザー指定）。

## 仕様

- 全体配置の下側。`(0, 0)` の人物アイコン（全ボードの中心のコネクト）から下へ伸びる。緑専用のコネクトマスはない。
- マスの配置・接続線・効果は全ホロメン共通（所属向け 3 マスの対象所属と値だけホロメンで変わる）。青のような左右反転はない。
- 接続は上下左右の 4 近傍（斜めなし）。09・10 の列は縦に全部繋がる（G-009–G-012–G-019–G-022、G-010–G-015–G-020–G-023）。
- 大きく描かれるマス: G-011（所属向け 2 個目）・G-014・G-017（両端の報酬系）。
- 効果の種類: 全員の全パラメータ +5 / 全員の P・T・S +5・+10 / 所属グループの全パラメータ UP（3 マス）/ 報酬・獲得量 +0.5%（7 マス、パラメータには効かない）。
- 所属向け効果の合計は 1 カードあたり全パラメータ +900 が上限（複数所属でも超えない）。

## 実測との関係（コネクト増幅）

実機のボードに表示される値はコネクトで増幅された後の値で、上の表記値を超えうる（`docs/ai/tmp/status.md` の緑の表示値・3期生 +200 / +100・ゲマズ +300 など）。表示値にさらに倍率を掛けない。ツールは表記値（増幅前）で試算する。

## 実機確認のログ

- 2026-09-07（1 回目）: 緑は下。コネクトに色という概念はなく、全ボードの中心 `(0, 0)` のコネクトから緑が下へ伸びる。24 マスの位置は図どおり。緑エリアの配置にホロメンによる差はない。
- 2026-09-07（2 回目）: 接続線は 09・10 の列も縦に全部繋がる（= 格子の 4 近傍）。大マスは G-011・G-014・G-017。24 マスの効果、所属別の値（+50/+150/+100 と +75/+225/+150）、フブキの 3 マスは仮定どおりで確定。
