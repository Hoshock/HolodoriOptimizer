# 赤ホロメンボード

赤ボードの**配置・ノード効果・接続**の正典。表示ユニットスコアへのスコアサポート換算はここでは定義せず、[`docs/human/display-score.md`](../../../../docs/human/display-score.md) を正典とする。

## 基本仕様

- 全体配置の上にあり、リーダーにしたホロメンの赤ボードだけがメンバー 5 人へ効く。
- カード詳細 P/T/S には反映されない。
- `lifeSide = left` を基準にし、`lifeSide = right` は x 座標を反転する。
- `(0,0)` は全ボード中央のコネクト。赤内コネクトは `(0,7)`。
- 接続は上下左右の 4 近傍。斜め線はない。座標が縦横に隣接するノードは接続する。
- 歌唱者条件の R-002 / R-044 / R-062 / R-063 は、そのホロメンが楽曲歌唱者に含まれる時だけ有効。
- 表の値はコネクト増幅前。増幅は `connect-effect.md` の暫定モデルを参照。

## 計算への適用

### P/T/S

赤の P/T/S 固定・割合はユニット総合力の**ホロメンボード効果**へ入る。衣装・パッシブと連鎖乗算しない。歌唱者条件の P/T/S も成立時に同じ項へ入り、メンバー強化ボーナスの基準にも影響する。

割合の厳密な丸め単位は未解明で、実装と実機に ±1〜2 の残差があるケースがある。Golden を丸め仮説に合わせない。

### スコアサポート

一般式は未解明。**旧 `X × 基準候補秒 / 200` は 2026-09-12 の追加実験で一般式として棄却済み**。現行コードの `redScoreSupportDisplayGain` は既知の近似として残っているだけで、正典ではない。

実測・棄却式・現在の仮説は [`docs/human/display-score.md`](../../../../docs/human/display-score.md)、数値 Golden は [`docs/human/repro/display-score-20260912.md`](../../../../docs/human/repro/display-score-20260912.md) を参照する。
