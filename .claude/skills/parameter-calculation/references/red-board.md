# 赤ホロメンボードのノード構成（2026-09-08 ユーザー実機確認・確認中）

赤ホロメンボードは全体配置の**上**にあり、リーダー用の効果を持つ（カード詳細の P/T/S には反映されない — 2026-09-06 実機確認）。構成は全ホロメン共通で、**上エリア / ライフ系エリア / ステータス系エリア**の 3 エリアからなる。ライフ系が左か右かはホロメンごとに固定で `src/data/holomen.json` の `board.lifeSide`（ステータス系はその反対。青の左右 `blueSide` とは別）。座標は青・緑・黄と同じ向きで、x は右が正・**y は上が正**、`(0, 0)` が全ボードの中心のコネクト。解析由来の情報は参考にとどめ、確定は実機確認で行う（`.claude/rules/game-facts.md`）。**このファイルは確認中**: 確認できた項目だけを書き、未確認の項目は「未確認事項」に列挙する。

## 仕様（確認済み）

- 全体配置の上。`(0, 0)` の人物アイコン（全ボードの中心のコネクト）から上へ幹が伸びる。
- 幹の中央から 7 マス目 `(0, 7)` に**赤ボード内のコネクトマス**（人物アイコン）があり、そこから左右へ枝が分かれる。青・黄と同じく入力対象ではなく、通路として常に通れる扱い。
- 左右の枝の一方が**ライフ系エリア**（ライフ・判定強化・ライフ回復・メンバー Exp・ホロゴールド）、他方が**ステータス系エリア**（P/T/S・全パラメータ・スコアサポート）。`lifeSide = left` のホロメン（ときのそらなど）はライフ系が左、`lifeSide = right`（白上フブキなど）は**上エリアを含めて**全体が左右反転 `(x, y) -> (-x, y)` で、形は同じ。
- 座標は `lifeSide = left` を基準に書く。
