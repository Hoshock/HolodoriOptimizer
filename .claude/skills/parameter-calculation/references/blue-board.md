## 全体配置（4 色とホロメン別の左右）

ホロメンボードは赤・青・黄・緑の 4 色で 1 つの全体配置をなす（2026-09-07 ユーザー共有）。

- 赤は常に上、緑は常に下。青と黄は左右で、**どちらが左かはホロメンごとに決まっている**（青が左のホロメンの青ボードが左型、青が右なら右型 = 左右反転）。
- 赤ボードは上エリア（大きな「All」のマスがある）と、左右のエリア（ライフ系エリアとステータス系エリア）で構成され、**ライフ系が左か右かもホロメンごとに決まっている**（内容の詳細は未確認 — pending 4）。
- 全 54 名の値は `src/data/holomen.json` の `board`（`blueSide` / `lifeSide`）に持つ。ツールはユーザーに左右を選ばせず、ここから引いて描く。

## 仕様

- メンバー編成時に、そのホロメン自身へ適用される。
- 効果・ノード構成は全ホロメン共通。左型 = `tree-model-001 / 003`、右型 = `tree-model-002 / 004`。
- 右型は左型の左右反転 `(x, y) -> (-x, y)`。効果・ID は同じで x 座標だけ反転する。
- 青ボード内のコネクトマスは 1 つ。左型では B-009 と B-016 の間 `(-7, 0)` にある人物アイコン（右型では `(7, 0)`）。
- `(0, 0)` にも人物アイコンの接続点がある（反転しても `(0, 0)` のまま）。これは全ボードの中心にある色を持たないコネクトで、緑ボードはここから下へ伸びる（2026-09-07 実機確認 — references/green-board.md）。
- 左端の上側・下側の斜め位置は接続していない: B-013 と B-029 / B-028、B-020 と B-031 / B-030 を斜め接続として扱わない（接続は上下左右の 4 近傍のみ）。
- 見た目: マスは正方格子に並び、マス同士を繋ぐ線は縦横とも同じ長さ。初期地点とコネクトマスは丸角の四角の人物アイコン。初期地点側から最初の発動率（B-007）と、3 つの 5 マス塊（上・下・左端）の両端（割合 UP と発動頻度）は他のマスの 1.5 倍の大きさで描かれる。マス内の記号は A（全パラ）/ P / T / S / 率 / 頻（割合 UP のマスも文字は同じで大きさで区別）。

## 実測との関係（コネクト増幅）

実機のボードに表示される値はコネクトマスで増幅された後の値で、上の単純合計を超えうる（例: `docs/ai/tmp/status.md` のおかゆは全パラ +546・S +688・発動率 +35.1%、ころねは発動率 +39.6%）。発動頻度はおかゆで +12% と単純合計に一致しており、増幅の倍率と対象マスはノード位置に依存する模様（詳細は**未確認**）。ボード補正を入力にするときは、増幅込みの表示値をそのまま入力してもらうのが確実。
