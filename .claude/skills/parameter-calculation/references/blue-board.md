## 仕様

- メンバー編成時に、そのホロメン自身へ適用される。
- 効果・ノード構成は全ホロメン共通。左型 = `tree-model-001 / 003`、右型 = `tree-model-002 / 004`。
- 右型は左型の左右反転 `(x, y) -> (-x, y)`。効果・ID は同じで x 座標だけ反転する。
- 青ボード内のコネクトマスは 1 つ。左型では B-009 と B-016 の間 `(-7, 0)` にある人物アイコン（右型では `(7, 0)`）。
- `(0, 0)` にも人物アイコンの接続点がある（反転しても `(0, 0)` のまま）。
- 左端の上側・下側の斜め位置は接続していない: B-015 と B-029 / B-028、B-022 と B-031 / B-030 を斜め接続として扱わない。

## 実測との関係（コネクト増幅）

実機のボードに表示される値はコネクトマスで増幅された後の値で、上の単純合計を超えうる（例: `docs/ai/tmp/status.md` のおかゆは全パラ +546・S +688・発動率 +35.1%、ころねは発動率 +39.6%）。発動頻度はおかゆで +12% と単純合計に一致しており、増幅の倍率と対象マスはノード位置に依存する模様（詳細は**未確認**）。ボード補正を入力にするときは、増幅込みの表示値をそのまま入力してもらうのが確実。
