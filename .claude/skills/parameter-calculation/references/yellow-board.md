# 黄ホロメンボード

黄ボードの配置・ノード効果・接続と、確認済みの楽曲ボーナス適用位置をまとめる。

## 基本仕様

- 青の反対側にあり、青が左なら黄は右型、青が右なら黄は左型。
- 右型を基準にし、左型は x 座標を反転する。
- `(0,0)` は全ボード中央、黄内コネクトは右型 `(7,0)`。
- 接続は上下左右の 4 近傍。斜め線はない。
- 黄はパラメータではなく、楽曲スコアボーナスとホロワーク報酬を持つ。
- 効果はアカウント全体。黄を育てたホロメンが編成外でも対象曲なら有効。
- 楽曲スコアボーナスのアカウント合計は 10.0% 上限。

## 楽曲区分

- **ソロ**: そのホロメンだけが歌唱者。
- **ユニット**: 複数歌唱者のうち本人を含む。
- **全体**: hololive IDOL PROJECT。
- FUWAMOCO のソロ系は「歌唱者が FUWAMOCO のみの楽曲」が対象。
- 所属名だけで解けない歌唱者は `src/data/songSingers.ts` の明示データを使い、推測しない。

## 表示ユニットスコアへの適用

曲に乗る黄ボーナスを `Y`（10% = 0.10）とすると、表示前 raw の Board 増分は次で実機と一致する。

```txt
YellowBoardIncrement
= Y × (100 + Costume + Active + Passive + Special)
```

2026-09-12 の同一ミオ編成で、R-061 後の曲なしと Gamers は赤 X=26 が同じ。カテゴリは次の通り。

| 条件         | Costume | Active | Board | Passive |   SP |
| :----------- | ------: | -----: | ----: | ------: | ---: |
| 曲なし Y=0   |    14.1 |   77.7 |  40.7 |     1.9 | 47.0 |
| Gamers Y=10% |    14.1 |   77.7 |  64.8 |     1.9 | 47.0 |

Board 差は +24.1。`0.1 × (100 + 14.1 + 77.7 + 1.9 + 47.0) = 24.07` で一致する。Costume を除く旧4カテゴリ式なら22.66で明確に外れる。

厳密には各カテゴリの**表示前 raw**を使う。表示済みの0.1刻み値から計算すると境界で0.1ずれる場合がある。

この黄増分は Board へ入る。黄だけを変えた時、総合力・Costume・Active・Passive・SP は変わらない。実ライブスコアへの掛かり方は別問題。
