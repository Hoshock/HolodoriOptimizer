# 黄ホロメンボードのノード構成（2026-09-08 ユーザー実機確認）

黄ホロメンボードは全体配置の**左右のうち青の反対側**にあり、ノード構成は全ホロメン共通で右型・左型の 2 配置（左右反転）がある。どちらになるかは `src/data/holomen.json` の `board.blueSide` から導く（青が左 → 黄は右型、青が右 → 黄は左型）。黄の左右を別に持たない。座標は青・緑と同じ向きで、x は右が正・**y は上が正**、`(0, 0)` が全ボードの中心のコネクト（コネクトに色という概念はない）。効果はパラメータでなく楽曲のスコアボーナスとホロワークの報酬で、**ゲーム内での適用のしかたは未確認**（下の「未確認事項」）。解析由来の情報は参考にとどめ、確定は実機確認で行った（`.claude/rules/game-facts.md`）。実装は `src/data/yellowBoard.ts`（ツールのマス内の記号は ソ / ユ / 全 / レ / キ / 特）。

## 仕様

- 青の反対側。`(0, 0)` の人物アイコン（全ボードの中心のコネクト）から横へ伸びる。**形は青ボードを左右反転したものと同じ**（31 マス、右型で x = 1〜10、y = -3〜+3）。
- 黄ボード内のコネクトマスは 1 つ。右型では中心から 7 マス目 `(7, 0)`（左型では `(-7, 0)`）の人物アイコン。青と同じく入力対象ではなく、通路として常に通れる扱い。
- 左型は右型の左右反転 `(x, y) -> (-x, y)`。効果・ID は同じで x 座標だけ反転する。
- 接続は上下左右の 4 近傍（斜めなし）。縦横に隣り合うマスは全部繋がる（Y-009–Y-024、Y-016–Y-025、Y-027–Y-028–Y-029、Y-027–Y-030–Y-031 を含む）。斜めに近い組（Y-015 と Y-029、Y-022 と Y-031）に線はない。
- 大きく描かれるマス: Y-008・Y-013・Y-015・Y-020・Y-022・Y-029・Y-031（中央の列の大マスは中心から 6 個目で、青の 5 個目とは違う）。
- 効果の種類: 楽曲のスコアボーナス（本人のソロ楽曲 12 マス / 本人を含むユニット楽曲 3 マス / 全体楽曲 3 マス）と、ホロワークの報酬の獲得量 UP（レッスン Pt 5 マス / キューブ 4 マス / 特訓アイテム 4 マス）。パラメータには効かない。

| 種類                    | 文言の型                                                                      |
| :---------------------- | :---------------------------------------------------------------------------- |
| ソロ                    | ○○が楽曲歌唱者のソロ楽曲をプレイ時 スコアボーナス X% UP                       |
| ユニット                | ○○が楽曲歌唱者に含まれるユニット楽曲をプレイ時 スコアボーナス X% UP           |
| 全体                    | 全体楽曲をプレイ時 スコアボーナス X% UP                                       |
| ホロワーク レッスン Pt  | ○○をホロワークのメンバー編成時に発動 ホロワークでのレッスン Pt 獲得量が X% UP |

## FUWAMOCO の例外

フワワ・モココのソロ系マス（12 マス）は「○○が楽曲歌唱者のソロ楽曲」でなく「**楽曲歌唱者が FUWAMOCO のみの楽曲**をプレイ時」が対象（2026-09-08 に Y-029 の文言で確認）。ツールではソロの見出し・説明文を「FUWAMOCO のみの楽曲」に変える（`src/data/yellowBoard.ts` の `FUWAMOCO_HOLOMEN_IDS`）。

## 楽曲の区分と上限

2026-09-08 ユーザー確認。

- **楽曲の区分**: そのアーティスト（ホロメン 1 人）だけが歌っている曲がソロ楽曲、何人かで歌っている曲は（歌唱者に含まれる 1 人にとって）ユニット楽曲、hololive IDOL PROJECT の曲が全体楽曲。ツールは `src/data/songs.json` の `artists` から導く（`src/data/songSingers.ts`。所属名のアーティストはその所属の全員が歌唱者。Blue Journey・不知火建設は歌唱者未確認）。
- **上限**: 楽曲スコアボーナスは合計 **10.0%** が上限（`YELLOW_SONG_BONUS_CAP_PERMIL`）。

## 未確認事項

盤面（位置・効果・大マス・接続線）は確定したが、**効果のゲーム内での適用のしかたは未確認**。確定するまでツールは黄の登録と効果表の表示だけを行い、試算スコアに入れない。

- 黄を育てたホロメンが編成外でも効くか（緑と同じアカウント全体か、編成内だけか）。
- 複数ホロメンの黄の合算方法（単純合計で上限 10.0% と仮定してよいか）。FUWAMOCO 2 人分の扱い（両方の黄が同じ曲に乗るか）。
- コネクト増幅の倍率・対象。
- ライブスコアの計算式のどこに入るか（ゲーム内の「スコアボーナス」が最終スコアにどう掛かるか）。

## 実機確認のログ

- 2026-09-08（1 回目）: 青が左のホロメンで右型を確認。形は青の左右反転と同じ 31 マス、黄の内側の人物アイコンは中心から 7 マス目、大マスは Y-008・Y-013・Y-015・Y-020・Y-022・Y-029・Y-031、縦横に隣り合うマスは全部繋がり斜めの線はない。
- 2026-09-08（2 回目）: 位置番号 → 効果の候補表（31 マス）が全部一致。フワワ・モココの Y-029 は「楽曲歌唱者が FUWAMOCO のみの楽曲」。
- 2026-09-08（3 回目）: 楽曲スコアボーナスは 10.0% が上限。楽曲の区分はアーティストのみが歌っていればソロ、何人かで歌っているうちの 1 人ならユニット、IDOL PROJECT の曲は全体楽曲。
