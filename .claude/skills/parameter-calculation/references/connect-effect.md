# コネクト効果（暫定仕様・実装仮説）

ホロメンボードのコネクトマス（人物アイコン。中心 / 赤 / 青 / 黄の 4 か所）にカードを置くと、そのカード固有の「コネクト効果」が、置いたコネクトマスを原点にした相対座標の範囲にある**解放済み**のマスの効果を増幅する。ゲーム内の文言は「範囲内のホロメンボード効果を 150% UP」の形。実装は `src/data/connect.ts`、方針は [ADR-008](../../../../docs/adr/008-connect-effect-provisional-model.md)。

**この文書の値は実機確認済みではない。** 範囲の座標と増幅 ‰ は外部の公開データベースのスナップショット【外部情報】から引き継いだもの（2026-09-11。ADR-002 の Update）。一般規則（倍率の解釈・丸め・向き）はユーザーの実機観測と突き合わせて決めた。

**ツールでの入れ方**（2026-09-11 ユーザー指示。カードの指定はしない）: ボード画面のコネクトマス（人物アイコン）をタップ → 右のサイドバーに範囲の形 17 種が図形で並ぶ（盤面と同じ向き）→ 形をタップ → テンキーで倍率（%。カード詳細の「範囲内のホロメンボード効果を X% UP」の X）→ 決定で確定し、コネクトマスがそのボードの色になる。倍率の候補は画面に出さない（ユーザーが自分で入れる）。図形は同じ大きさの正方形で、マスの数が少ない順（同数の中では対称な形が左右に並ぶ）の固定順、入れてある形だけが先頭。範囲に入るマスは盤面で解放の有無を問わず虹色の輪（未解放は点滅）で示す。外すのはサイドバーの下の「外す」。サイドバー右上の「一覧」で、全ホロメンのコネクト効果（コネクトマス・形・倍率・使っているホロメン）を 1 つの表で見られる（`ConnectListDialog.vue`、`connectUsageRows`）。保存は `holodori-optimizer:connect-placements`（`{ extent, permil }`。`src/storage/connect.ts`）。

## 一般規則

| 項目            | 規則                                                                                                                             | 根拠                                                                                                                                                 |
| :-------------- | :------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| 倍率            | 元値 × (1 + ‰/1000)。「150% UP」= × 2.5、「85% UP」= × 1.85                                                                      | おかゆ 発動率 +35.1 = 30 + (+2 × 3 個) × 0.85、みこ +36.0 = 30 + (+2 × 2 個) × 1.5。「‰/1000 をそのまま倍率」（× 0.85）だと 29.1 / 32.0 になり不一致 |
| 重複            | 同じマスが複数の範囲に入るときは増分を加算: 1 + Σ ‰/1000（150% と 140% は 1.9 倍。2.1 倍ではない）                               | 未確認。`combineConnectPermils` 1 関数に分離してあり、乗算へ変えるならそこだけ                                                                       |
| 丸め            | 固定値（+50 / +100 など整数）はマスごとに切り上げ。割合・‰ は丸めない                                                            | おかゆ P/T +528 = 400 + ceil(150 × 1.85 = 277.5) = 278。四捨五入でも同値の 1 点なので既存の「割合は切り上げ」に合わせた                              |
| 対象            | 範囲内の**解放済み**マスだけ。未解放は 0 のまま。コネクトマスそのものは増幅しない                                                | ゲーム内 Tips「効果範囲のマスを解放すると効果を発揮」【外部情報】                                                                                    |
| レベル          | 開花 5凸で Lv2、0〜4凸は Lv1                                                                                                     | 公開データの「★4 以上の 5凸 = コネクト効果 Lv UP」の読み【外部情報】。従来の「5凸 = コネクト効果」は「Lv2 になる」の意味と読む（暫定）               |
| 向き（中心）    | 物理座標のまま（右 = +x、上 = +y）。+x に伸びる範囲は青が右のホロメンでは青、青が左では黄に掛かる                                | おかゆ（青が右）の全パラ / S の増分は、中心から +x へ 3 マス直線（B-001 / B-002 / B-005）× 2.6 で一致                                                |
| 向き（青 / 黄） | 相対座標は青が左（黄が右）のホロメンを基準とし、反対側のホロメンでは dx を反転（結果としてどのホロメンでも同じマス ID に掛かる） | おかゆ（青が右）の card-2 は外向き（B-023 / B-026 / B-009 / B-010 / B-016 / B-017 / B-024 / B-025）で一致                                            |
| 向き（赤）      | ライフ系が左のホロメンを基準とし、右なら dx を反転（同じマス ID に掛かる）                                                       | 未確認（青と同じ規則を置いた）                                                                                                                       |

## アンカー（置ける場所）

| アンカー  | 位置（物理座標）                 | ボード上の見た目                         |
| :-------- | :------------------------------- | :--------------------------------------- |
| `center`  | (0, 0)                           | 全ボードの中心の人物アイコン             |
| `leader`  | (0, 7)                           | 赤ボードのコネクトマス（3 エリアの分岐） |
| `card`    | (−7, 0)（青が右のホロメンは +7） | 青ボードのコネクトマス                   |
| `content` | 青の反対側                       | 黄ボードのコネクトマス                   |

ゲーム内ではここにカードを置くが、ツールはカードではなく範囲の形と倍率を入れる（同じホロメンのカードでなくてよいことも含め、カードの対応はツールのデータに持たない）。

## 実機観測との整合

`docs/ai/tmp/status.md`「ホロメン別の青ホロメンボード」（青ボードの表示値。増幅込み）:

- **猫又おかゆ**（青が右、青は全解放）: 全パラ +546 / S +688 / P +528 / T +528 / 発動率 +35.1% / 頻度 +12%。単純合計 300 / 400 / 400 / 400 / 30 / 12 との差が、**青のコネクトに card-2（Lv1、+85%）、中心に card-3 の形（Lv1 の ★4、+160%）** を置いた形で全項目一致（`src/data/connect.test.ts`）。置いたカードの実体は未確認。
- **さくらみこ** 発動率 +36.0%: +2 のマス 2 個が +150% の範囲（30 + 2 × 2 × 1.5）。白上フブキ +39.0%、戌神ころね +39.6%、フワワ +45.0% も「+‰ の加算」の読みで整数倍の形になる（マスの組は未特定）。ぺこら +30.0% は増幅なし。

## 未確認事項

- カード → 効果の対応はツールに持たない（形と倍率を実機のカード詳細の文言・光る範囲から直接写す）。効果一覧の 20 種で全部かは未確認。
- 重複時の合成（加算か乗算か）、赤の左右の向き、割合・‰ の丸め、黄 / 赤 / 緑への適用の有無（青しか実機値がない）、5凸で Lv2 になること。
- 「ボード状況を考慮しない」（全解放）試算での置き方（ツールは増幅なし。最適配置の探索は未実装）。
