# パラメータ計算仕様

このスキルは**パラメータと総合力**の正典。時点依存のアカウント状態や表示スコアの仮説を抱え込まない。

## カード詳細 P/T/S

カード詳細に反映される:

- カード本体の Lv と開花
- 青ボードの固定値・P/T/S 割合
- 緑ボードの全員向け・所属向けパラメータ
- 所属グループ向け効果
- コネクトで増幅された青・緑の値

カード詳細に反映されない:

- 赤ボード
- メモリーのユニットパラメータ
- メンバー強化ボーナス
- 編成条件つき衣装・パッシブ
- アクティブ / SP のスコア効果

所属向け同一効果は確認済み範囲で全パラメータ +900 が上限。青を 1 マスも解放していないカードでも緑と所属効果は入る。

## 開花

確認済みの ★5:

| 段階 | 主な強化 | P/T/S |
| :--- | :--- | :--- |
| 1凸 | アクティブ | 直接変化なし |
| 2凸 | 全パラメータ +10% | 変化あり |
| 3凸 | SP | 直接変化なし |
| 4凸 | パッシブ | 条件次第 |
| 5凸 | コネクト関連 | 直接変化なし |

カードごとの途中段階の文言・数値は `cards.json` の `bloomVariants` を優先し、一律の仮定倍率を確定値として扱わない。

## ボードの役割

- **赤**: リーダー用。メンバー 5 人への P/T/S・スコアサポート等。カード詳細 P/T/S には入らない。
- **青**: メンバー本人用。P/T/S とアクティブ発動率 / 頻度。
- **黄**: 曲・ホロワーク用。パラメータ効果ではない。
- **緑**: アカウント全体からメンバーへ効く P/T/S・所属効果。

ボード状態はホロメン単位であり、カード単位ではない。

## 総合力

ユニット編成画面の総合力は 6 項目の加算。

```txt
totalPower = memberParameters
           + costumeSkill
           + holomenBoard
           + passiveSkill
           + memory
           + enhancement
```

重要:

- 各項目は素値を基準に独立に算出する。前の項目へ後の倍率を連鎖させない。
- 「◯◯2人の」など count 人を選ぶ確認済み効果は、対象候補の**素値合計 P+T+S 上位**から count 人を選ぶ。
- メンバー強化ボーナスはメモリーを含めない基準へ掛かる。
- 赤の P/T/S 効果は Board 項へ入る。歌唱者条件も成立時に同じ系統へ入る。
- 丸め単位には未解明が残り、実機と ±1〜2 のケースがある。Golden を丸め仮説へ合わせない。

詳細な設計判断は ADR-004。

## 表示ユニットスコアとの分界

表示スコアの一般式・赤 / 青 / 衣装 / パッシブの相互作用はこのスキルへ書かない。正典は `docs/human/display-score.md`。

確定している入口だけ:

```txt
unitScore = ceil(totalPower × (1 + scoreBonus / 100) × 2.03734)
```

実ライブ中のスコアは別問題（ADR-006）。
