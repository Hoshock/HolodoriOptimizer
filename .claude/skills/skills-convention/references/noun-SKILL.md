# 知識型スキルのリファレンス

知識型スキルは「これは何か・どういう形であるべきか」に答える。Claude は `description` のマッチで自動読込する — 100 件を超えることもある一覧の中で、本文を読むかどうかの判断材料は `description` **だけ**である。

## スケルトン

```markdown
---
name: <skill-name>
description: |
  What: <1 文 — このスキルが何を定義するか>。
  Use when: <具体的なトリガー — ファイル種別・ディレクトリ・操作・ユーザーの言い回し。明示的に頼まれない場合も含む>。
version: <yyyy-mm-dd-nn>
---

# <人間可読なタイトル>

<三人称の段落 1 つ: このスキルが何を統べるか。ここだけ読めば続きを読むべきか分かる状態にする。>

<!-- references/ がないスキルではこの節を削除する。 -->

## External References

| ファイル                                       | 説明         | いつ読むか                   |
| :--------------------------------------------- | :----------- | :--------------------------- |
| [references/<name>.md](./references/<name>.md) | <1 行の要約> | <1 行の「このとき読む」導線> |

## <節>

- ...
```

## 命名

- 動名詞または名詞句。`helper` / `utils` / `tools` は禁止 — 曖昧な名前は衝突するうえ Claude に何も伝えない。
- ディレクトリ名がスキルの同一性**そのもの**: 64 文字以下、小文字・数字・ハイフンのみ、先頭・末尾・連続のハイフン禁止。`name` フィールドはディレクトリ名と一致させる。
