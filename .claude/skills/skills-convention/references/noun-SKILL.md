# noun 型（知識）スキルのリファレンス

noun 型スキルは「これは何か／どういう形であるべきか」に答える。Claude は `description` を見て、このスキルを読み込むかどうかを自動で判断する。その時点で Claude が目にするのは、100 件以上並ぶスキル一覧の中の `description` _だけ_である。`description` は日本語で書き、起動の手がかりになる固有名やコマンド名は原語のまま書く。

## スケルトン

```markdown
---
name: <skill-name>
description: |
  What: <このスキルが定めることを 1 文で>
  Use when: <具体的な起動条件。ファイル種別・ディレクトリ・操作・ユーザーの言い回しを列挙し、「迷ったら」のような包括的な広げ方はしない>
version: <yyyy-mm-dd-nn>
---

# <Skill-Name>

<三人称の 1 段落: このスキルが何を扱うか。この段落だけで、読み進めるべきかどうか判断できるようにする。>

<!-- references/ がないスキルでは、このセクションを削除する。 -->

## 外部リファレンス

| File                                           | Description  | When to read                       |
| ---------------------------------------------- | ------------ | ---------------------------------- |
| [references/<name>.md](./references/<name>.md) | <1 行の要約> | <1 行の「これを読むとき」のフック> |

## <セクション>

- ...
```

## 命名

- 動名詞または名詞句にする。`helper` / `utils` / `tools` は使わない。曖昧な名前は他のスキルと衝突しやすく、Claude に中身が伝わらない。
- ディレクトリ名が、スキルの識別子**そのもの**である。64 文字以下、小文字・数字・ハイフンのみで、先頭・末尾・連続するハイフンは不可。`name` フィールドはそれと一致させる。
