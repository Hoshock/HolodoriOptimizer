# コマンド型スキルのリファレンス

コマンド型スキルは「これを、この順でやれ」に答える。自動マッチは一切せず、ユーザーが `/<name>` と打って起動する。

## スケルトン

```markdown
---
name: <skill-name>
description: <三人称の動作動詞 —「〜を雛形生成する」「〜を実行する」— に続けて「ユーザーが〜したいときに使う」>
disable-model-invocation: true
argument-hint: "<arg1> [<arg2>]"
version: <yyyy-mm-dd-nn>
---

# <人間可読なタイトル>

あなたは<1 文の役割宣言>。<入力・成果物・実行全体にかかる制約。>

<!-- references/ がないスキルではこの節を削除する。 -->

## External References

| ファイル                                       | 説明         | いつ読むか                   |
| :--------------------------------------------- | :----------- | :--------------------------- |
| [references/<name>.md](./references/<name>.md) | <1 行の要約> | <1 行の「このとき読む」導線> |

## 手順

1. <具体的な手順。`$ARGUMENTS` を解決し、省略時の既定を明記する。>
2. <具体的な手順。ゲートはインラインで書く:「<破壊的操作>の前に AskUserQuestion で確認する」。>
3. 報告する: <生成した成果物>、<書き込んだパス>、<提案する次の一手>。
```

## 命名

- 動詞の命令形。`helper` / `utils` / `tools` は禁止 — 曖昧な名前は衝突するうえ Claude に何も伝えない。
- ディレクトリ名がスキルの同一性**そのもの**: 64 文字以下、小文字・数字・ハイフンのみ、先頭・末尾・連続のハイフン禁止。`name` フィールドはディレクトリ名と一致させる。
