# verb 型（コマンド）スキルのリファレンス

verb 型スキルは「これを、この順で行う」に答える。Claude が自動で読み込むことはなく、ユーザーが `/<name>` と入力して呼び出す。`description` は日本語で書き、起動の手がかりになる固有名やコマンド名は原語のまま書く。

## スケルトン

```markdown
---
name: <skill-name>
description: <何をするかを 1 文で（例: 「〜を作る。」「〜を実行する。」）。続けて「〜したいとき使う。」>
disable-model-invocation: true
argument-hint: "<arg1> [<arg2>]"
version: <yyyy-mm-dd-nn>
---

# <Skill-Name>

あなたは<役割を 1 文で述べる>。<入力、生成するもの、実行中ずっと守る制約。>

<!-- references/ がないスキルでは、このセクションを削除する。 -->

## 外部リファレンス

| File                                           | Description  | When to read                       |
| ---------------------------------------------- | ------------ | ---------------------------------- |
| [references/<name>.md](./references/<name>.md) | <1 行の要約> | <1 行の「これを読むとき」のフック> |

## ワークフロー

1. <具体的な手順。`$ARGUMENTS` を解決し、省略時の既定を明記する。>
2. <具体的な手順。ゲートはその場に書く: 「<破壊的な操作>の前に AskUserQuestion で確認する」。>
3. 報告: <生成した成果物>、<書き込んだパス>、<次の推奨ステップ>。
```

## 命名

- 動詞の命令形にする。`helper` / `utils` / `tools` は使わない。曖昧な名前は他のスキルと衝突しやすく、Claude に中身が伝わらない。
- ディレクトリ名が、スキルの識別子**そのもの**である。64 文字以下、小文字・数字・ハイフンのみで、先頭・末尾・連続するハイフンは不可。`name` フィールドはそれと一致させる。
