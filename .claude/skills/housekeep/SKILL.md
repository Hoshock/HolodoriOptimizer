# 棚卸し (housekeep)

あなたはこのリポジトリのドキュメントを棚卸しし、すべての内容を正しい置き場に戻す。分担表の正典は CLAUDE.md の「ドキュメントの分担」、読者向けの索引は `docs/index.md`。判定基準は規約スキル（claude-md-convention / rules-convention / skills-convention）が持つ — 自分の基準を発明しない。棚卸しはコンパクション直前に行われることが多く、タスク完了のタイミングとは限らない — クローズ（手順 7）は完了しているときだけ行う。指示がない限り commit / push はしない。

## 手順

`docs/ai/tmp/` の各ファイルに関する項目は、該当ファイルがないときはスキップする。

1. 全部読む: `docs/index.md`、`.claude/rules/` の全ファイル、`docs/ai/tmp/` の全ファイル（あれば）、このプロジェクトのネイティブメモリの索引。メモリはポインタと習慣として尊重し、メモリの内容をリポジトリのドキュメントへ書き写したり、その逆をしたりしない。
2. `docs/ai/tmp/rules.md` を昇格する — ファイルが存在する限り必須で、昇格しないまま棚卸しを終えてはならない。昇格先は CLAUDE.md の「ドキュメントの分担」の判定に従う:
   - パス単位のルール → `.claude/rules/<topic>.md`（必ず `paths:` glob つき。rules-convention 準拠）
   - 覆しにくい決定だったと判明したもの → `docs/adr/`（形式は `docs/adr/index.md` 冒頭）
   - ドメイン・プロジェクトの事実だったもの → `docs/human/` + `docs/index.md` への行追加
   - 無条件・毎セッション必要な恒久ルール → CLAUDE.md「注意点」（claude-md-convention の One Test を通るもののみ）
   - 多手順のワークフロー・随時参照の知識 → `.claude/skills/`（skills-convention 準拠。既存スキルに収まるならそこへ統合）
   - まだ一般化できない事例は tmp/rules.md に残す。昇格済み・無効化された項目は削除する
3. `.claude/rules/` を棚卸しする: 各ルールの glob が実在するファイルにマッチするか、制約が今も正しいかを rules-convention と照らして確認する。陳腐化したものは修正し、削除はユーザーに提案してから行う。
4. CLAUDE.md を棚卸しする: ディレクトリ構成・コマンド・技術スタック・分担表を実リポジトリと突き合わせてドリフトを直し、全体を claude-md-convention（One Test・矛盾・肥大・振り分け表）に照らして監査する。行の削除・移設はユーザーに提案してから行う。
5. README.md の整合を確認する: 機能一覧・使い方が現状の実装と一致するか、非公式ファンツールの免責と「試算値」表記が残っているか（CLAUDE.md「注意点」の必須要件）。ずれていれば直す。
6. 揮発性ドキュメントを現状に合わせる:
   - tmp/plan.md: 完了したフェーズは完了サマリへ縮約する。未解決の項目は tmp/pending.md へ移す
   - tmp/progress.md: 完了済み項目の詳細を要約に縮める
   - tmp/pending.md: 各項目を現状と突き合わせ、解消済みのものを落とす（削除前に現状を確認して裏取りする）
   - `docs/human/tmp/` は棚卸しの対象外 — 日付つきスナップショットの削除はユーザー自身の判断で行う
7. tmp/progress.md にコンパクション地点のログを書く: 未コミット / 未 push の変更、次のアクション、参照すべき方針の場所。
8. タスクが完全に完了している場合のみクローズする: 残す価値のあるものを昇格（残すべき意思決定 → ADR へ、ルール → 手順 2 の昇格先へ、人間向けの事実 → `docs/human/` + `docs/index.md` への行追加、残す価値のある事例 → 関連するルールファイルへ例として統合）したうえで、`docs/ai/tmp/` を丸ごと削除する。`docs/index.md` の tmp の行は予約リンクなのでそのまま残す。
9. `docs/index.md` を更新する: 実在する全ドキュメントに行があり、移動した内容を指す行がない状態にする。
10. 報告する: 昇格・移動・削除したものと、ユーザーの判断が必要なものを報告する。
