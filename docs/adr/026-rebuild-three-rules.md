# ADR-026: 組み直しのボードは 3 つのルール(効率順・効かないマスだけ外す・新しく触る手間)で選ぶ

Date: 2026-10-10

## Status

Accepted

## Decision

組み直しのボードは次の 3 つのルールで選び、範囲(最小限オン / オフ)の違いは「ユニット外に足してよいマス」だけにする。モードごとに足してきた個別ルールを、ユーザーの言う本質(Pt あたりの伸びが良いこと、変えるホロメンを少なくすること)にまとめるためである。

1. **開ける順は効率だけ**: 伸び ÷ Pt / 伸び / 伸び ÷ 資源の消費の割合 の 3 通りを試して最良を採る。色の順位や十字の特別扱いはしない(十字は効率が良いので自然に先に来る)。例外は最小限のリーダー・メンバーの緑で、所属マスと十字の 5 マスまでを、赤・青・黄とユニット外の緑のあとに残った Pt で開ける。
2. **外してよいのはこの編成に効かないマスだけ**: ユニット外の赤・青の全部、曲に効かない黄、報酬のマス、メンバーの所属に効かない所属マス、上限で頭打ちのマス(外しても伸びが減らない所属マス・黄。スコアで確かめる)。ユニット外の全員・パラメータの緑は誰が持っていても効くので外さず、所属マスを外すときに巻き込みもしない。リーダー・メンバーのボードは組み直すので何を外してもよい。
3. **新しく触る手間**: まだ変えていないユニット外のホロメンを初めて変えるときは、伸びからいまのユニットスコアの 0.05%(`NEW_HOLOMEN_COST_RATIO`)を差し引いて比べる。

## Context

[ADR-025](025-green-unit-squares-and-cross.md) を置き換える。残すのは、最小限のリーダー・メンバーの緑は所属マスと十字の 5 マスまでで赤・青・黄のあと、という最小限の方針と、緑をホロメンの間で移さないこと(取り置き)。やめるのは、全整理の十字の特別扱い(十字がそろってからその先・上乗せの段)、色の順位(最小限のリーダー・メンバーの緑を除く)、取り崩しはユニット系マスのためだけ、全整理でユニット外をゼロから組み直すこと。

ADR-025 までに足してきた個別ルール(色の順位・十字の段・取り崩しの用途・取り置き・すでに触っている人を先に)は、モードごとにちぐはぐになりやすかった。ユーザーの指摘(2026-10-10)は、十字から開ける話は本質的には Pt あたりの伸びと変えるホロメンの少なさの話なので、それを踏まえて全体をシンプルにすること。ユーザーが決めたのは、3 つのルールにまとめること、ほかの所属の所属マスは外してよいこと、所属向けの +900 を超えて効いていない所属マスと楽曲スコアボーナスの 10.0% を超えて効いていない黄も効かないマスとして外してよいこと、1 人分の手間の重さはエージェントが決めること。

- ルール 2 で所属マスを外すときは、奥のマスから、巻き込みの出ないものだけを外す。巻き込まずに何も空かないときだけ先のマスごと外し、その損は取り崩しの損得で差し引く。
- ルール 3 の手間は、取り崩しの損得と、出発点どうしの比較(変えたユニット外の人数分)にも同じく効かせる。0.05% は、そのときのアカウントで、緑のないホロメンに G-001 を 1 マス開ける伸び(約 0.06%)は採り、十字の G-003 だけを 1 マス開ける伸び(約 0.009%)は採らない値。
- モードの違い: ユニット外で登録が整合している人は、どちらのモードでも登録から足す・外すだけ。足せるのは、最小限オンではメンバーの所属に効く所属マス(と経路)と曲に効く黄、オフでは緑ならどのマスでも(全員・パラメータも)と曲に効く黄。登録が整合していないユニット外は、オンでは変えず、オフではゼロから組み直す。リーダー・メンバーはどちらでも組み直す。

## Consequences

同じアカウント(2026-10-09 の登録)の さがす 上位 3 編成で、曲なし(推奨と、ボードを変えるホロメンの数):

|                       | 最小限オン                                      | 最小限オフ                                         |
| :-------------------- | :---------------------------------------------- | :------------------------------------------------- |
| ADR-025 Update の実装 | 1,746,238 / 1,754,089 / 1,769,937(7 / 5 / 8 人) | 1,780,816 / 1,797,446 / 1,808,465(20 / 18 / 22 人) |
| この ADR              | 1,746,854 / 1,756,382 / 1,763,001(7 / 7 / 8 人) | 1,770,049 / 1,787,462 / 1,789,459(7 / 9 / 10 人)   |

### Pros

- ルールが 3 つになり、モードの違いが「ユニット外に足してよいマス」だけになった。
- 最小限オフでボードを変えるホロメンが 20 人前後 → 10 人以下になった。
- 上限で頭打ちの所属マス・黄を、資材や Pt の出どころとして使える。

### Cons

- 最小限オフの推奨は、ADR-025 Update の実装より 0.6〜1.1% 低い。主な理由はルール 2 の「巻き込まない」で、ほかの所属の所属マス(G-008 / G-011)の先にはセンス +10(G-018)などの全員・パラメータのマスがあるので、ふつうは奥の G-021 しか外せない。先のマスごと外すのを認めると、推奨は今日の変更前(1,801,167 / 1,821,258 / 1,828,197、53〜54 人)とほぼ同じになり、人数は 22〜27 人になる(下の Update で認めた)。
- 手間の 0.05% は 1 つのアカウントで決めた値(推薦ポリシーで、ゲームの仕様ではない)。0.01〜0.1% で人数とスコアの動きを測ってある(0% でも 1,778,786 / 1,796,675 / 1,792,879)。
- 上限を超えた黄は、外して Pt を空けるときだけ使う(キューブの出どころとしての静的な勘定 `recoverableMaterials` は上限を見ない)。

**Update (2026-10-10):** 最小限のリーダー・メンバーの緑も十字に限らず効率で埋め、取り崩しの巻き込みを認めた(ユーザー判断: 十字までというのも本質ではなく、余った Pt があれば Pt やキューブあたりの伸びで緑を埋めるのが本質)。ルール 1 の例外は「赤・青・黄とユニット外の緑のあとに残った Pt で、効率順」になり、ルール 2 の「巻き込まない」はやめて、巻き込まれる全員・パラメータのマスの損を取り崩しの損得で差し引く(外す対象は今までどおり効かないマスだけ)。同じ 3 編成で推奨は最小限オン 1,756,043 / 1,769,519 / 1,782,183(13 / 14 / 16 人)、オフ 1,797,633 / 1,816,282 / 1,827,766(22 / 25 / 27 人)と今日の変更前並みに戻り、変えるホロメンは半分になった。代わりに計算は長くなった(最小限 3〜5 秒 / 全整理 18〜31 秒。初版は 2〜3 秒 / 7〜11 秒。`docs/ai/tmp/pending.md` 8)。

**Update (2026-10-10):** ルール 3 の手間は、ユニット外の緑を変えるときだけ数える(ユーザー判断: 赤は外すのが基本 1 人、青・黄も最大 5 人程度で、手間を一番考えたいのは緑)。また、余りが負になった資材は、この編成に効かないマスを外す差分として推奨に入れる(`optimizePlan.ts` の `coverDeficits`。外してもスコアは変わらない)。それまでは盤面を変えず、反映すると余りが負になる「外して回すぶん」([ADR-016](016-true-ranking-proxy-boards.md))だったが、結果に差分として入れるほうがシンプルなため(ユーザー判断)。曲なしと曲 song-213 の上位 3 編成 × 最小限オン / オフの 12 通りで、推奨・変えるホロメンの数・計算時間は変わらなかった(song-213 の 3 位で出ていた青のキューブの不足は、もともと緑を変えるユニット外の青を外して埋まった)。
