# ADR-026: 組み直しのボードは 3 つのルール(効率順・効かないマスだけ外す・新しく触る手間)で選ぶ

- Date: 2026-10-10
- Status: Accepted

[ADR-025](025-green-unit-squares-and-cross.md) を置き換える。残すのは、最小限のリーダー・メンバーの緑は所属マスと十字の 5 マスまでで赤・青・黄のあと、という最小限の方針と、緑をホロメンの間で移さないこと(取り置き)。やめるのは、全整理の十字の特別扱い(十字がそろってからその先・上乗せの段)、色の順位(最小限のリーダー・メンバーの緑を除く)、取り崩しはユニット系マスのためだけ、全整理でユニット外をゼロから組み直すこと。

## Context

ADR-025 のあと、ユーザーから「緑の十字から開ける話は、本質的には Pt あたりのステータスの伸びがいい + 変更のホロメンを少なくする、ということ。それを踏まえて全体をシンプルに」(2026-10-10)。それまで足してきた個別ルール(色の順位・十字の段・取り崩しの用途・取り置き・すでに触っている人を先に)が、モードごとにちぐはぐになりやすかった。

ユーザーが決めたこと(2026-10-10):

- 3 つのルールにまとめる(下)。ほかの所属の所属マスは外してよい。
- 所属向けの +900 を超えて効いていない所属マスと、楽曲スコアボーナスの 10.0% を超えて効いていない黄も「効かないマス」として外してよい。
- 1 人分の手間の重さはエージェントが決める。

## Decision

1. **開ける順は効率だけ**: 伸び ÷ Pt / 伸び / 伸び ÷ 資源の消費の割合 の 3 通りを試して最良(今までどおり)。色の順位や十字の特別扱いはしない(十字は効率が良いので自然に先に来る)。**例外は最小限のリーダー・メンバーの緑**で、ユーザーの最小限の指示(「開けないで済むなら開けない」「Pt が余っていれば十字も」)のとおり、所属マスと十字の 5 マスまでを赤・青・黄とユニット外の緑のあとに残った Pt で開ける。
2. **外してよいのはこの編成に効かないマスだけ**: ユニット外の赤・青の全部、曲に効かない黄、報酬のマス、メンバーの所属に効かない所属マス、上限で頭打ちのマス(外しても伸びが減らない所属マス・黄 — スコアで確かめる)。**ユニット外の全員・パラメータの緑は誰が持っていても効くので外さず、所属マスを外すときに巻き込みもしない**(奥のマスから、巻き込まないものだけ。巻き込まずに何も空かないときだけ先のマスごと外し、その損は取り崩しの損得で差し引く)。リーダー・メンバーのボードは組み直すので何を外してもよい。
3. **新しく触る手間**: まだ変えていないユニット外のホロメンを初めて変えるときは、伸びからいまのユニットスコアの **0.05%**(`NEW_HOLOMEN_COST_RATIO`)を差し引いて比べる。取り崩しの損得と、出発点どうしの比較(変えたユニット外の人数分)も同じ。0.05% はそのときのアカウントで、緑のないホロメンに G-001 を 1 マス開ける伸び(約 0.06%)は採り、十字の G-003 だけを 1 マス開ける伸び(約 0.009%)は採らない値。

モードの違いは「ユニット外に足してよいマス」だけにする:

|                                    | 最小限オン                                                                           | 最小限オフ                                                                             |
| :--------------------------------- | :----------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------- |
| リーダー・メンバー                 | 組み直す。緑は所属マスと十字の 5 マスまで(赤・青・黄のあと)                          | 組み直す。緑も効率で比べる                                                             |
| ユニット外(登録が整合している人)   | 登録から足す・外すだけ。足せるのはメンバーの所属に効く所属マス(と経路)と、曲に効く黄 | 登録から足す・外すだけ。足せるのは緑ならどのマスでも(全員・パラメータも)と、曲に効く黄 |
| ユニット外(登録が整合していない人) | 変えない                                                                             | ゼロから組み直す                                                                       |

## Consequences

同じアカウント(2026-10-09 の登録)の さがす 上位 3 編成で、曲なし:

|                       | 最小限オン                                      | 最小限オフ                                         |
| :-------------------- | :---------------------------------------------- | :------------------------------------------------- |
| ADR-025 Update の実装 | 1,746,238 / 1,754,089 / 1,769,937(7 / 5 / 8 人) | 1,780,816 / 1,797,446 / 1,808,465(20 / 18 / 22 人) |
| この ADR              | 1,746,854 / 1,756,382 / 1,763,001(7 / 7 / 8 人) | 1,770,049 / 1,787,462 / 1,789,459(7 / 9 / 10 人)   |

### Pros

- ルールが 3 つになり、モードの違いが「ユニット外に足してよいマス」だけになった。
- 最小限オフでボードを変えるホロメンが 20 人前後 → 10 人以下になった。
- 上限で頭打ちの所属マス・黄を資材や Pt の出どころとして使える。

### Cons

- 最小限オフの推奨は、ADR-025 Update の実装より 0.6〜1.1% 低い。主な理由はルール 2 の「巻き込まない」で、ほかの所属の所属マス(G-008 / G-011)の先にはセンス +10(G-018)などの全員・パラメータのマスがあるので、ふつうは奥の G-021 しか外せない。先のマスごと外すのを認めると、同じ 3 編成で 1,797,633 / 1,816,282 / 1,827,766(22 / 25 / 27 人)になる(今日の変更前の 1,801,167 / 1,821,258 / 1,828,197・53〜54 人とほぼ同じ)。
- 手間の 0.05% は 1 つのアカウントで決めた値(推薦ポリシー。ゲームの仕様ではない)。0.01〜0.1% で人数とスコアの動きを測ってある(0% でも 1,778,786 / 1,796,675 / 1,792,879)。
- 上限を超えた黄は、外して Pt を空けるときだけ使う(キューブの出どころとしての静的な勘定 `recoverableMaterials` は、上限を見ない)。
