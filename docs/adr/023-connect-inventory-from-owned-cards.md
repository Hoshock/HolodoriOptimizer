# ADR-023: 持っているコネクトは所持カードから導き、カード固有のコネクト効果の対応表を持つ

Date: 2026-10-09

## Status

Accepted

## Decision

カード ID → コネクト効果（既存 `CONNECT_EFFECTS` の ID。形と Lv1 / Lv2 の ‰）の対応表を `src/data/cardConnect.ts` に別モジュールとして持ち、持っているコネクト（形 × ％ × 枚数）は所持カードと開花段階から導いて、手で登録する画面と保存（`connect-inventory`）を廃止する。廃止するのは、手での登録が、持っているカードと同じ情報の二重入力だからである。ボードのコネクトマスに形 × ‰ を直接置く配置の入力は変えない。

## Context

[ADR-008](008-connect-effect-provisional-model.md) の Update のうち、「`Card.connectEffect` は削除し、効果の一覧は形ごとの ‰ の候補として持つだけ」（2026-09-11）と、「持っているコネクト（形 × ％ × 枚数）を登録し、その範囲で最適化する」（2026-10-02〜03）の所持の登録の部分を置き換える。コネクトの一般モデル（範囲・‰・合成・丸め・向き）は変えない。

★4 の収録（[ADR-022](022-star4-cards-fixed-only.md)）と一緒に、★5 全 84 枚のカード固有コネクト効果が抽出マスターからそろい、既存の 20 種（`CONNECT_EFFECTS`）の形 × ‰ と全件一致した。対応表は ★5 84 枚・★4 54 枚の全件をそこから転記したもので、外部解析・実機未確認である。ユーザーの指示（2026-10-09）は、コネクトの登録を廃止し、所持カードにコネクトを紐づけて、所持カードを登録すれば何を持っているか分かるようにすること。手で登録する方式では、枚数や ％ の入れ間違いが「所持に収まっていない」エラーになっていた。

ADR-008 の Update で `Card.connectEffect` を消したのは、当時カード → 効果の対応が実機確認できたカードにしかなく、ユーザーが画面の光る範囲を写すほうが確実だったためである。いまは全件の対応があるので、配置の入力は変えずに所持の導出だけに使う。

導き方は、カード 1 枚 = コネクト 1 枚、％ は `connectLevel(bloom)` の暫定モデル（0〜4凸 = Lv1、5凸 = Lv2）。手で登録していた保存は読まずに消し（ユーザー指示）、「データの出力」からも `connectInventory` を外す。カード詳細にはコネクト（範囲の形の図、Lv1 / Lv2 の ％、実機未確認の脚注）を出すが、配置の候補をカードから提案・絞り込む機能は入れない。

退けた案:

1. 対応表を `Card.connectEffect` に戻す。効果の定義（カードの性質）と、どのコネクトマスに何を置いたか（`connect-placements`）を同じ型に混ぜると、配置の入力（形 × ‰）をカード指定に変える圧力になる。
2. 登録画面を残し、所持カードから既定値を入れる。二重管理が残る。
3. 配置もカード指定にする。ユーザーが要求しておらず、実機の配置（どのカードを置いたか）は保存に持っていない。

## Consequences

### Pros

- 所持カードと開花段階を登録すれば、持っているコネクトが自動で決まり、組み直しプランのコネクトの段がそのまま使える。
- 対応表のテスト（`cardConnect.test.ts`）で、全カードに効果があること・既存の 20 種を指すこと・レアリティの整合を固定できる。

### Cons

- カード → 効果の対応は外部解析で実機未確認（`docs/ai/tmp/pending.md` 6 / 21）。実機のカード詳細と違えば、その対応を直す。
- 5凸 = Lv2 の暫定モデルがそのまま所持の ％ になる。実機で違えば `connectLevel` を直す（1 か所）。
- 手で登録していた所持コネクトは消える。所持カードを登録していなければ持っているコネクトは 0 になり、ボードに置いた配置が「所持に収まっていない」扱いになる。
- 保存の封筒 `account` から `connectInventory` が消える（版は上げない。読む側は無い項目を空として扱う）。

**Update (2026-10-10):** 所持の導き方は変えず、ボードに置いている配置と見比べる場面を足した（ユーザー指示）。アカウントの「コネクト」とボードのコネクト効果の一覧に使用 / 所持を出し、所持を超えて置こうとすると警告して、同じ形 × ％ を置いている場所から外すかを選ばせるが、超えて置くことは禁止しない。ゲームでは同じカードを 2 か所に置けないが、所持カードの登録漏れ（★4 など）があっても配置を入れられるようにするためである。所持カードが未登録のあいだも見比べる（未登録のあいだは見比べない案は、ユーザーが採らなかった）。
