# ADR-014: 「ボードの最適化」はボードとコネクトを選んで回し、発動頻度マスは OFF にして行う

Date: 2026-10-07

## Status

Superseded by [ADR-015](015-optimize-with-frequency-stage.md)（入口と頻度の扱いを置き換えた。頻度マス OFF でのボードの最適化と周回は ADR-015 が引き継ぐ）

## Decision

コネクトの最適化を「ボードの最適化」の中の選択肢にまとめ、ボード → コネクトの順でスコアが上がらなくなるまで最大 3 周回す。ボードの最適化は青の発動頻度マスをすべて OFF にして行い、頻度の配分は別の入口の「頻度の最適化」に任せる。

## Context

[ADR-012](012-board-points-rank-model.md)・[ADR-013](013-board-materials-shared-constraint.md) のホロメンボードの最適化と、2026-10-02 に別の入口で足したコネクトの最適化（`connectOptimize.ts`）を 1 つの入口にまとめ、その中で頻度マスの扱いを決める。ボードPt・資材・コネクトの明示解放の決定は変えない。

2026-10-07 のユーザー指示。3 つの最適化が独立していて順序依存が大きかった（1 周だけだとボード → コネクトがコネクト → ボードより 4〜5% 高く、2 周目で +0.9〜1.8% 上がる。`docs/ai/tmp/pending.md` 項目 8）。

決定の内訳と理由:

- **入口は「ボードの最適化」と「頻度の最適化」の 2 つ**。「コネクトの最適化」の入口は廃止し、ボードの最適化の中でボード / コネクトを独立に ON/OFF する（少なくとも 1 つ）。頻度を同じ入口に入れないのは、目的の違うモデル（ライブ側 2 つと表示側 1 つ）で後段のユニットスコア最大化と目的がずれるため。
- **頻度の最適化は反映の機能を持たない**。頻度マスへの経路が一意でなく（途中のマスが違えば P/T/S も変わる）、どの経路で登録するかをツールが決められないので、推奨を見てユーザーが手で登録する。
- **ボードの最適化では頻度マス（B-013 / B-020 / B-031）をすべて OFF にする**。頻度マスは青ボードの枝の端（`src/data/blueBoard.ts`）なので、外しても他のマスは孤立しない。外したぶんの資材・Pt は他のマスへ回せる。頻度マスはターゲットにも経路にもせず、ボードを反映すると登録の頻度マスは外れる（反映の確認でそう伝える）。頻度の配分は、必要ならそのあと頻度の最適化で回し直す。
- **「現在」のスコアは頻度マスを外した登録の値にそろえ、結果はそれを下回らない**。頻度マスを外したぶんの低下を最適化の効果と混ぜないため。コネクトの評価も頻度マスを外した世界で行う（コネクトだけを選んだときはボードを変えないので、登録の頻度マスは外さない）。例外は登録がランクの予算を超えているホロメンで、予算内へ直すのでスコアが下がってもその結果を返す。
- **周回はボード → コネクトの順で最大 3 周**（両方を選んだときだけ）。段の間では、ボードは最適化後の盤面と余りのリソースを、コネクトは最適化後の配置を次の段の出発点にし、各段は土台を下回らない。反映はボード・コネクトの解放・余り・配置を 1 回でまとめて登録する。
- **コネクトの範囲は常にユニットのみ**にし、「ユニットのみ変更する」はボードだけにかかる。
- **置いているコネクトが所持の登録に収まっていないとき**は、コネクトを選んだままでは最適化せず、登録を促す。

## Consequences

### Pros

- 入口が 2 つになり、ボードとコネクトの順序依存（周回）を 1 回の操作に閉じ込められる。
- 頻度マスの非単調な効果が貪欲法から消える（足し戻しが推奨を登録より下げる不具合の原因だった）。

### Cons

- ボードの最適化は頻度の配分を取りこぼす（頻度の全探索を最終段に入れると +0.5〜2.9% の計測があった）。頻度の最適化へ分担した。
- ボードを反映すると登録していた頻度マスが外れるので、必要ならユーザーが頻度の最適化の結果を手で登録し直す。
- 「現在」のスコアが結果一覧の値より低く見えることがある（頻度マスを外した値のため）。

**Update (2026-10-08):** [ADR-015](015-optimize-with-frequency-stage.md) で、頻度の段を選ばないときは頻度マスを外さずに残し、「現在」はいつも登録そのままの値にした。「ユニットのみ変更する」もコネクトにかかる形へ戻した。
