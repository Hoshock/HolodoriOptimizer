# ADR-028: 組み直しのボードの決まり(効率順・効かないマスだけ外す・緑を初めて変える手間・緑の形・手前の 7 マスを先に)

- Date: 2026-10-10
- Status: Accepted

[ADR-026](026-rebuild-three-rules.md)(3 つのルールと Update(1)〜(3))と [ADR-027](027-green-shape-rule.md)(緑の形と Update)を 1 本にまとめ、2026-10-10 の判断「先へ行く前に、ほかの人の手前の 7 マスを埋める」を加えて置き換える。

## Decision

組み直しプランのボードの段は、「Pt・キューブあたりのステータスの伸びが大きいマスから」と「ボードを変えるホロメン(とくに緑)を少なく」の 2 つを軸に、次の決まりでマスを選ぶ。緑ボードの縦一直線(x = 0。G-001・002・005〜008・011・018・021)を**幹**、1 つ目の所属マス G-008 より手前の G-001〜G-007(十字の左右を含む)を**手前の 7 マス**と呼ぶ。

1. **開ける順は効率**(伸び ÷ Pt / 伸び / 伸び ÷ 資源の消費の割合 の 3 通りを試して最良)。色の順位はつけない。順位を下げる例外は 2 つ:
   - 最小限オンのリーダー・メンバーの緑は、赤・青・黄とユニット外の緑のあと。
   - 形 A の人(下の 4)が手前の 7 マスより先を開けるのは、範囲によらず、1 人につき何マス目でも、ほかの候補を取り切ったあと。
2. **外してよいのはこの編成に効かないマスだけ**: ユニット外の赤・青の全部、曲に効かない黄、報酬のマス、メンバーの所属に効かない所属マス、上限で頭打ちのマス(所属向けの +900・楽曲スコアボーナスの 10.0% を超えて効いていない — スコアで確かめる)。ユニット外の全員・パラメータの緑は外す対象にしないが、効かないマスの先にあって中心から切れるマスは一緒に外れる(巻き込み。損は差し引いて決める)。リーダー・メンバーは組み直すので何を外してもよい。余りが足りなくなった資材は、最後に効かないマスを外す差分として推奨に入れる。
3. **緑を初めて変える手間**: まだ緑を変えていないユニット外の緑を変えるときは、伸びからいまのユニットスコアの 0.05% を差し引く(取り崩しの損得・出発点どうしの比較も同じ)。**数えないのは、赤・青・黄だけの変更と、手前の 7 マスを足すだけの変更**(登録のマスを外さず、G-001〜G-007 だけを足す)。
4. **緑の形**: 推奨で緑を変えるホロメンだけ、**効く**所属マス(その所属の合計が、そのマスを除くと +900 に届かない所属マス)を持つ人(形 B = ユニット系担当)は幹のマスだけ、それ以外(形 A)は手前の 7 マスまでにそろえる。形 A の人は、登録の足し戻しのあとの 2 周目で、ほかを取り切ってまだ余れば、効かない所属マスを通ってその先も開けてよい(リーダー・メンバーはどちらの範囲でも、ユニット外は最小限オフだけ)。緑を変えない人の登録は形の外でも残す。
5. **緑をホロメンの間で移さない**([ADR-025](025-green-unit-squares-and-cross.md) から): ゼロから組み直したリーダー・メンバーが外した登録の緑の資材は、登録を戻す段までほかのホロメンの全員・パラメータの緑に使わない。

範囲(画面の「最小限で組み直す」)の違い:

|                                    | 最小限オン                                                                         | 最小限オフ                                                                                 |
| :--------------------------------- | :--------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| リーダー・メンバー                 | 組み直す。緑は赤・青・黄のあと                                                     | 組み直す。緑も効率で比べる                                                                 |
| ユニット外(登録が整合している人)   | 登録から足す・外すだけ。足せるのはメンバーの所属に効く所属マス(と経路)と曲に効く黄 | 登録から足す・外すだけ。足せるのは緑ならどのマスでも(手前の 7 マス → 余れば先)と曲に効く黄 |
| ユニット外(登録が整合していない人) | 変えない                                                                           | ゼロから組み直す                                                                           |

コネクトの段の範囲(オンはリーダー・メンバーと、曲に効く黄を持つユニット外。オフは全ホロメン)も同じ「最小限で組み直す」で切り替わる。

## Context

すべて 2026-10-10 のユーザー指示・判断。

- 「緑の十字から開ける話は、本質的には Pt あたりのステータスの伸びがいい + 変更のホロメンを少なくする、ということ。全体をシンプルに」→ ルール 1〜3。個別ルール(色の順位・十字の段・取り崩しの用途)を足し続けるとモードごとにちぐはぐになった(ADR-025 まで)。
- 「まきこみをみとめる」— 巻き込まない版は、ほかの所属の所属マスの先にセンス +10(G-018)などがあってふつうは奥の G-021 しか外せず、推奨が 0.6〜1.1% 低かった。
- 「赤は基本外すとして 1 人、青も最大 5 人程度、黄色も同様。緑は手間を一番考えたい」→ 手間は緑だけ。
- 「ユニットマスを開ける役割のあるホロメンは一直線上のマスのみ。ユニット系担当とそれ以外をわかりやすくするため」「ユニット系以外ならユニット系マスの直前までのすべてのマスを開けられるなら開ける」→ 形の決まり。
- 「ユニット系マスなんか 900 超える時も開けようとしてる」→ 形 B は「効く」所属マスで決める。所属マスを持つだけで形 B にした版では、ゼロから組み直すメンバーの所属マスを外している間にほかの人が同じ所属を開け、登録を戻すと +900 を超えて効かなかった。
- 「余るなら A の人も先へ行っていい。ユニットを取らないようにしつつステータス UP に影響のあるマスを順にとる」→ 2 周目で先へ。1 周目から許すと、登録の所属マスを捨てる入れ替わりが増えた。
- 「先へ行く前に、ほかの人の G-001〜G-007 が空いていなければそっちを優先するべきでは？コスト的にも」→ 例外 1 の 2 つ目とルール 3 の除外。手前の 7 マスは 1〜2 Pt・20〜80 キューブで、先は G-008(通り道 2 Pt・80)のうえ G-009・010(2 Pt・80、パラメータ +10)、G-012・013(3 Pt・160、全員 +5)。それまでは「先へ」が最後になるのが 1 人につき最初の 1 マスだけで、周の途中で取れるようになった手前のマスにも先を越され、手前の 7 マスを足すだけでも手間を数えたので、最小限オフでは手前が空いたままの人を残して先のマスにキューブを使っていた(2026-10-10 のスナップショットのラミィのソロ曲で、手前が空いた 18 人を残し、ミオ・あやめ・ねねが 1 人 400〜480 キューブを先のマスに使っていた)。
- 退けた案: 手間は手前の 7 マスにも数えたまま、順番のずれだけ直す — 同じ例で推奨は変わらず、メンバーの組み方だけが変わった。

## Consequences

| 2026-10-09 の登録、莉々華(★4)リーダーの さがす 上位 3 編成(曲なし) | 最小限オン                                         | 最小限オフ                                         |
| :----------------------------------------------------------------- | :------------------------------------------------- | :------------------------------------------------- |
| ADR-027 Update                                                     | 1,692,367 / 1,637,657 / 1,613,086(17 / 12 / 12 人) | 1,749,190 / 1,692,622 / 1,663,082(30 / 25 / 23 人) |
| この ADR                                                           | 1,692,202 / 1,637,982 / 1,613,248(16 / 12 / 12 人) | 1,748,126 / 1,692,023 / 1,662,080(39 / 34 / 32 人) |

2026-10-10 のスナップショット、ラミィのソロ曲(song-212)・水着こぼリーダー: 最小限オン 2,049,106(3 人)→ 2,052,465(7 人)、最小限オフ 2,067,834(9 人)→ 2,072,317(18 人。先へ行く人はいなくなった)。

### Pros

- 決まりが 1 本の ADR になり、範囲の違いは「ユニット外に足してよいマス」と「整合していないユニット外を組み直すか」だけ。
- 盤面を見れば役割が分かる(縦一直線 = ユニット系担当、手前の 7 マス = それ以外)。
- 安い手前の 7 マスを先に埋め、先のマスは最後に回る。

### Cons

- 最小限オフでボードを変えるホロメンが増える(手前の 7 マスを足すだけの人は手間に数えない): 上の例で +9 人。
- 推奨は上下する(ラミィの例 +0.16〜0.22%、莉々華の 3 編成の最小限オフ −0.03〜0.06%)。手前の 7 マスの中でも、G-006・007(80 キューブ)を多くの人に配るより G-003・004(20 キューブ)や空の人の G-001〜005 を埋めるほうがキューブあたりで勝つことがあり、伸び / 伸び ÷ Pt の順ではそれを拾い切れない(貪欲法の近似 — `pending.md` 8)。
- 最小限オンでも順番の変更で組み方が変わる。ラミィの例では、メンバーのクロニーが登録の Promise の所属マスを IRyS に任せて先のマスを開けた(メンバーの所属マスの入れ替わり — `pending.md` 27)。
- 手間の 0.05% は 1 つのアカウントで決めた値で、「効く」所属マスの判定はコネクトの増幅を見ない(どちらも推薦ポリシー。ゲームの仕様ではない)。
