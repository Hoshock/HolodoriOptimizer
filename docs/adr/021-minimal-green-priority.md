# ADR-021: 最小限の組み直しでは、緑はユニット外の所属マス → ユニットの残り Pt の順で、ユニット外の全員マスは足さない

Date: 2026-10-09

## Status

Superseded by [ADR-025](025-green-unit-squares-and-cross.md)

## Decision

最小限の組み直しでは、ユニット外に足せる緑をメンバーの所属に効く所属マスとそこまでの経路だけに戻し（所属マス自体が上限 900 で効かないなら開けない）、緑は 赤・青・黄 → ユニット外の緑 → ユニットの緑（残った Pt で）の順に後回しにする。「ユニットのボードは赤・青・黄に注力し、緑は同じ所属のユニット外で賄う」というユーザーの方針を、増分の大小ではなく色の優先順位として扱うためである。

## Context

[ADR-020](020-minimal-rebuild-outsiders-pt.md) を置き換える。ADR-020 から残すのは、「ユニット外の Pt は、その人のこの編成に効かない赤・青・黄・報酬のマスを外して空ける」と「ユニットのメンバーの赤は外してよい」。変えるのは、ユニット外に足せる緑の範囲と、緑の優先順位。

ADR-020 のあとも、同じアカウント（水着ポルカ L・HOLOGRAM CIRCUS）の「組み直すと」1 位（ポルカ・おかゆ・ころね・ぼたん・ミオ）で、ポルカの緑が 8 マス開く推奨だった（ユーザー指摘: ポルカの緑は 0 マスが正しいはず）。原因は 2 つあった。

- 緑の全員 +5 のマスはホロメンごとに別枠で足されるので、ポルカ自身の全員マスは貪欲法の「増分 ÷ Pt」で青・黄の末端のマスより上に来る。
- ADR-020 で同じ所属のユニット外に全員・パラメータのマスまで足せるようにしたら、ねね・ぼたん・ラプラス・フブキが側のマスを 1〜4 個ずつ開ける推奨になり、変更が多すぎた（ユーザー判断: 経路にないグループ外の緑を開けるのはなし）。

所属向けの合計は 1 カードあたり +900 が上限（`GREEN_AFFILIATION_CAP`）なので、上限に達した所属マスを「経路の全員マスに価値がある」という理由で開けてはいけない（ユーザー確認）。そこで、経路込みの増分から所属マスだけを除いた増分を引き、所属マスの寄与が 0 なら候補にしない。

緑の順位は推薦ポリシーで、ゲームの仕様ではない。増分 ÷ Pt が緑のほうが高くても順を守る。全整理（`all`）では順を変えない。

## Consequences

### Pros

- ユニットの Pt は赤・青・黄に使われ、緑は同じ所属のユニット外の所属マス（と経路の全員マス）で賄われる。
- ユニット外の変更は所属マスへの経路に限られ、推奨の変更量が減る。
- 上限 900 に達した所属へ所属マスを積まない。

### Cons

- ユニットの緑を後回しにするぶん、表示ユニットスコアは貪欲法の最良より少し低くなりうる（ポルカの例では緑ありとなしの差が 0.03%）。
- 同じ所属のユニット外に空いた Pt があっても、所属マスが上限に達していれば緑は足されない（全員マスは全整理の役目）。

**Update (2026-10-09):** 曲を指定したら、ユニット外の歌唱者の黄とそのコネクトも組み直す（ユーザーの狙いは「曲を指定するときはその曲のスコアを最大化したい」）。最小限のコネクトでも、その曲の楽曲スコアボーナスに入る黄のマスを持つユニット外のホロメンには、解放済みのその黄のマスに掛かる置き方だけを候補に足す（ほかの色・ほかのユニット外は変えず、黄のコネクトマスを置くためだけに開けることもしない）。なお、曲を指定しても「組み直すと」の順位が変わらないのは想定どおりで、黄の楽曲スコアボーナスはアカウント全体に効き、どの編成にも同じ割合で乗るからである。
