# ADR-029: 組み直しのボードの決まり(効率順・効かないマスだけ外す・緑を初めて変える手間・緑の形)

- Date: 2026-10-10
- Status: Accepted

[ADR-028](028-rebuild-board-rules.md) を置き換える。変えたのは 2 つ: 緑を初めて変える手間を範囲で分け(最小限オフは 0.02%)、「手前の 7 マスを足すだけは数えない」をやめた / 「資源の消費の割合」を残りに対して測る。ほかの決まりは ADR-028 のまま(経緯は ADR-026・027 → 028)。

## Decision

組み直しプランのボードの段は、「Pt・キューブあたりのステータスの伸びが大きいマスから」と「ボードを変えるホロメン(とくに緑)を不必要に増やさない」の 2 つを軸に、次の決まりでマスを選ぶ。緑ボードの縦一直線(x = 0。G-001・002・005〜008・011・018・021)を**幹**、1 つ目の所属マス G-008 より手前の G-001〜G-007(十字の左右を含む)を**手前の 7 マス**と呼ぶ。

1. **開ける順は効率**(伸び ÷ Pt / 伸び / 伸び ÷ 資源の消費の割合 の 3 通りを試して最良)。**資源の消費の割合は、そのホロメンの残りの Pt と共有の残りのキューブ・コアキューブに対して測る**(足りなくなってきた資源ほど重い)。色の順位はつけない。順位を下げる例外は 2 つ:
   - 最小限オンのリーダー・メンバーの緑は、赤・青・黄とユニット外の緑のあと。
   - 形 A の人(下の 4)が手前の 7 マスより先を開けるのは、範囲によらず、1 人につき何マス目でも、ほかの候補を取り切ったあと。
2. **外してよいのはこの編成に効かないマスだけ**: ユニット外の赤・青の全部、曲に効かない黄、報酬のマス、メンバーの所属に効かない所属マス、上限で頭打ちのマス(所属向けの +900・楽曲スコアボーナスの 10.0% を超えて効いていない — スコアで確かめる)。ユニット外の全員・パラメータの緑は外す対象にしないが、効かないマスの先にあって中心から切れるマスは一緒に外れる(巻き込み。損は差し引いて決める)。リーダー・メンバーは組み直すので何を外してもよい。余りが足りなくなった資材は、最後に効かないマスを外す差分として推奨に入れる。
3. **緑を初めて変える手間**: まだ緑を変えていないユニット外の緑を変えるときは、伸びからいまのユニットスコアの**最小限オンは 0.05%、オフは 0.02%** を差し引く(取り崩しの損得・出発点どうしの比較も同じ)。赤・青・黄だけの変更は数えない。
4. **緑の形**: 推奨で緑を変えるホロメンだけ、**効く**所属マス(その所属の合計が、そのマスを除くと +900 に届かない所属マス)を持つ人(形 B = ユニット系担当)は幹のマスだけ、それ以外(形 A)は手前の 7 マスまでにそろえる。形 A の人は、登録の足し戻しのあとの 2 周目で、ほかを取り切ってまだ余れば、効かない所属マスを通ってその先も開けてよい(リーダー・メンバーはどちらの範囲でも、ユニット外は最小限オフだけ)。緑を変えない人の登録は形の外でも残す。
5. **緑をホロメンの間で移さない**([ADR-025](025-green-unit-squares-and-cross.md) から): ゼロから組み直したリーダー・メンバーが外した登録の緑の資材は、登録を戻す段までほかのホロメンの全員・パラメータの緑に使わない。

範囲(画面の「最小限で組み直す」)の違い:

|                                    | 最小限オン                                                                         | 最小限オフ                                                                                 |
| :--------------------------------- | :--------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| リーダー・メンバー                 | 組み直す。緑は赤・青・黄のあと                                                     | 組み直す。緑も効率で比べる                                                                 |
| ユニット外(登録が整合している人)   | 登録から足す・外すだけ。足せるのはメンバーの所属に効く所属マス(と経路)と曲に効く黄 | 登録から足す・外すだけ。足せるのは緑ならどのマスでも(手前の 7 マス → 余れば先)と曲に効く黄 |
| ユニット外(登録が整合していない人) | 変えない                                                                           | ゼロから組み直す                                                                           |
| 緑を初めて変える手間               | 0.05%                                                                              | 0.02%                                                                                      |

コネクトの段の範囲(オンはリーダー・メンバーと、曲に効く黄を持つユニット外。オフは全ホロメン)も同じ「最小限で組み直す」で切り替わる。

## Context

ADR-028 の Context(3 つのルール・形の決まり・「効く」所属マス・2 周目で先へ・先へは最後)はそのまま。ここでは変えた 2 つの理由だけを書く。ユーザー指摘・判断はどれも 2026-10-10。

- 「オフの時、G-007 までまず埋めるといってるけど、キューブや Pt あたりの効率考えながらやればまず G-005 からってなると思ってた」→ 資源の消費の割合を残りに対して測る。予算・総量に対して測っていたので、Pt の余っているユニット外でも Pt の割合が勝ち、キューブが尽きかけても 20 キューブの G-003・004(パラメータ +5)より 80 キューブの G-006・007(全員 +5)を先に取っていた。キューブあたりなら G-001・005 → G-002〜004 → G-006・007 の順。
- 「オフの時は緑の手間は考えないでいいかも。ただし変更のホロメン数が不必要に多くなるようにはならないように」→ オフの手間を 0.02% に下げ、手前の 7 マスの除外(ADR-028)はやめた。退けた案:
  - 手間ゼロ: キューブあたりの効率どおりに、G-003 だけ(約 0.01%)を開けるために 40 人前後を触り、変えるホロメンが 50 人近くになった(推奨の上積みは +0.1% 前後)。「不必要に多く」に当たる。
  - 同じ伸びの候補はすでに変える人を先に、という同点の決め方だけで人数を抑える: 手間があれば伸びの側で差がつくので、同点がほとんど起きず効かなかった。
- 0.02% は、緑のないホロメンに G-001 を 1 マス開ける伸び(約 0.06%)や G-006・007 の 2 マス(約 0.06%)は採り、G-003 だけ(約 0.01%)は採らない値。0.01% でもほぼ同じだった(人数は 0〜2 人多く、スコアは編成によって上下 — 貪欲法の近似なので単調ではない)。

2026-10-10 のスナップショット、ラミィのソロ曲(song-212)・水着こぼリーダー: 最小限オン 2,052,465(7 人。ADR-028 と同じ)、最小限オフ 2,072,317(18 人)→ 2,074,079(22 人)。最小限オフでは、どのホロメンも G-001・002・005 から埋まり、緑のキューブを使い切る。

### Pros

- 決まりが 1 本の ADR のままで、範囲の違いは「ユニット外に足してよいマス」「整合していないユニット外を組み直すか」「手間の重さ」の 3 つ。
- キューブが足りないときに、キューブあたりの伸びが大きいマスから開ける。
- 最小限オフで、1 マスぶんのわずかな伸びのためだけにホロメンを触らない。

### Cons

- 最小限オフで変えるホロメンは ADR-027 Update より +2〜5 人(莉々華の 3 編成)、ラミィの例では 9 → 22 人(手前の 7 マスを多くの人で埋めるため)。
- 推奨は ADR-027 Update と比べて −0.01〜+0.09%(最小限オフ)。貪欲法の近似で、手間の重さを変えると人数・スコアが単調に動かない(`pending.md` 8)。
- 最小限オンは、資源の消費の割合の測り方を変えたぶんだけ組み方が変わりうる(上の例では 3 編成目が −0.01%)。
- 手間の 0.05% / 0.02% は 1 つのアカウントで決めた値で、「効く」所属マスの判定はコネクトの増幅を見ない(どちらも推薦ポリシー。ゲームの仕様ではない)。メンバーの所属マスを同じ所属のユニット外に任せる入れ替わり(`pending.md` 27)は残る。
