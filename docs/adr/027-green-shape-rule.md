# ADR-027: 組み直しで緑を変えるホロメンは、ユニット系担当なら縦一直線・それ以外は最初の所属マスの手前までにそろえる

- Date: 2026-10-10
- Status: Accepted

[ADR-026](026-rebuild-three-rules.md) の 3 つのルール(効率順・効かないマスだけ外す・新しく触る手間)はそのまま。そこに緑の盤面の**形**の決まりを足し、ADR-026 Update の「最小限のリーダー・メンバーの緑はマスを限らず効率で埋める」を置き換える。

## Context

ユーザー指示(2026-10-10): 「組み直しの時、ユニットマスを開ける役割のあるホロメンは一直線上のマスのみ開けられる、という制限をつける。十字の左右を開けないということ。ユニット系担当とそれ以外をわかりやすくするため」「リーダー・メンバーの緑はいまフルで開けようとしてるがそれもやめ、ユニット系以外ならユニット系マスの直前までのすべてのマスを開けられるなら開ける。最小限オンの時は推奨スコアが少し下がるが許容する。オフの時も条件はおなじ。オフ時はそれでなおまだ資材や Pt が余る時はリーダー・メンバー以外の追加の緑マスを適宜開けていい」。

確認した点(同日ユーザー回答): すでに登録で開いている形の外のマスは、**緑を変えるホロメンだけ**そろえる(緑を変えない人の登録は残す)/ 手前の 7 マスを全部は開けられないときは、優先度を踏まえて開けられるだけ開ける / 最小限オフのユニット外にも同じ形を当て、それでも余れば先まで開けてよい。

## Decision

緑ボードの縦一直線(x = 0。G-001・G-002・G-005〜G-007・所属マス G-008 / G-011 / G-021・G-018)を「幹」、1 つ目の所属マス G-008 より手前の 7 マス(G-001〜G-007。十字の G-003・G-004 を含む)を「手前」と呼ぶ。

- **ユニット系担当**(緑にメンバーの所属に効く所属マスを持つホロメン — `sharedAffiliation`)は、**幹のマスだけ**。幹の外のマスは外す。
- **それ以外**は**手前の 7 マスまで**。効かない所属マスを経路にしてその先へは行かない。
- この形にそろえるのは**推奨で緑を変えるホロメンだけ**(リーダー・メンバー・ユニット外とも。最小限オン・オフとも)。緑を変えないホロメンの登録は形の外でも残す。
- どのリーダー・メンバーがユニット系担当になるかは、ほかのマスと同じくスコア(効率)で決まる。リーダー・メンバーの緑の順位は ADR-026 のまま(最小限オンは赤・青・黄とユニット外の緑のあと、オフは効率で比べる)。手前の 7 マスは開けられるだけ効率順に開ける。
- **最小限オフのユニット外だけ**、ほかの候補を取り切ってもまだ Pt・資材が余るときは、「手前まで」を外してその先も効率順に開けてよい(最後の順位 — `tier` 3)。ユニット系担当の幹は、そのときも守る。
- 実装(`boardOptimize.ts`): 緑の候補を測るとき、経路を足した盤面を形にそろえ(`alignedGreen` / `shapeOf`)、経路のマスまで外れるなら取らない。そろえるために外すマスの損・空く Pt と資材は、Pt を空けるための取り外し(`reclaim`)と同じく伸びに差し引く。取り崩し(`release`)と登録の足し戻しのあとも、緑が登録と違えば形にそろえる。資材に上限があるときの別経路(core を避けて十字の左右を通る経路)は、形に合わなければ使わない。

## Consequences

2026-10-09 のアカウントで、莉々華(★4)をリーダーにした さがす 上位 3 編成(曲なし、ボード・コネクト・頻度をすべて最適化):

|          | 最小限オン                                         | 最小限オフ                                         |
| :------- | :------------------------------------------------- | :------------------------------------------------- |
| ADR-026  | 1,694,959 / 1,643,463 / 1,614,705(17 / 14 / 13 人) | 1,745,025 / 1,689,277 / 1,659,807(27 / 23 / 22 人) |
| この ADR | 1,685,128 / 1,635,172 / 1,606,269(13 / 10 / 7 人)  | 1,749,190 / 1,692,622 / 1,663,082(30 / 25 / 23 人) |

### Pros

- 盤面を見ればユニット系担当(縦一直線)とそれ以外(手前の 7 マス)の役割が分かる。
- 最小限オンでボードを変えるホロメンが 3〜6 人減った(リーダー・メンバーが緑を広く開けにいかず、そのための取り崩しも減る)。

### Cons

- 最小限オンの推奨は 0.5〜0.6% 下がる(ユーザーは許容)。
- 最小限オフは、リーダー・メンバーが開けなくなった資材をユニット外の追加の緑が使うので、推奨はわずかに上がり、変えるホロメンは 1〜3 人増えた。
- 推奨の最後に足りない資材を埋める `coverDeficits` が外す報酬のマスは、形にはそろえない(外しても形から遠ざからない)。
