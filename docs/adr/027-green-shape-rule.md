# ADR-027: 組み直しで緑を変えるホロメンは、ユニット系担当なら縦一直線・それ以外は最初の所属マスの手前までにそろえる

Date: 2026-10-10

## Status

Superseded by [ADR-028](028-rebuild-board-rules.md)

## Decision

組み直しの推奨で緑を変えるホロメンは、メンバーの所属に効く所属マスを持つ人(ユニット系担当)なら緑ボードの縦一直線(幹)のマスだけ、それ以外は 1 つ目の所属マス G-008 より手前の 7 マス(G-001〜G-007)までにそろえる。盤面を見てユニット系担当とそれ以外を見分けられるようにし、リーダー・メンバーが緑を広く開けにいくのをやめるためである。

## Context

[ADR-026](026-rebuild-three-rules.md) の Update の「最小限のリーダー・メンバーの緑はマスを限らず効率で埋める」を置き換える。ADR-026 の 3 つのルール(効率順・効かないマスだけ外す・新しく触る手間)はそのまま。

幹は x = 0 の列(G-001・002・005〜007、所属マス G-008・011・021、G-018)で、手前の 7 マスは十字の左右(G-003・004)を含む。役割を盤面で分けることと、そのために最小限オンの推奨が少し下がるのを許すことは、ユーザーが決めた。細部は次のとおり。

- 形にそろえるのは、推奨で緑を変えるホロメンだけ(リーダー・メンバー・ユニット外とも、最小限オン・オフとも)。登録で形の外のマスが開いていても、緑を変えない人の登録は残す(ユーザー確認)。
- 手前の 7 マスを全部は開けられないときは、開けられるだけ効率順に開ける。どのリーダー・メンバーがユニット系担当になるかもスコアで決まり、リーダー・メンバーの緑の順位は ADR-026 のまま。
- 最小限オフのユニット外だけは、ほかの候補を取り切ってまだ Pt・資材が余れば、手前より先も最後の順位で開けてよい。ユニット系担当の幹はそのときも守る。
- そろえるために外すマスの損と、それで空く Pt・資材は、伸びに差し引いて候補を比べる。

## Consequences

2026-10-09 のアカウントで、莉々華(★4)をリーダーにした さがす 上位 3 編成(曲なし、ボード・コネクト・頻度をすべて最適化。推奨と、ボードを変えるホロメンの数):

|          | 最小限オン                                         | 最小限オフ                                         |
| :------- | :------------------------------------------------- | :------------------------------------------------- |
| ADR-026  | 1,694,959 / 1,643,463 / 1,614,705(17 / 14 / 13 人) | 1,745,025 / 1,689,277 / 1,659,807(27 / 23 / 22 人) |
| この ADR | 1,685,128 / 1,635,172 / 1,606,269(13 / 10 / 7 人)  | 1,749,190 / 1,692,622 / 1,663,082(30 / 25 / 23 人) |

### Pros

- 盤面を見れば、ユニット系担当(縦一直線)とそれ以外(手前の 7 マス)の役割が分かる。
- 最小限オンでボードを変えるホロメンが 3〜6 人減った。リーダー・メンバーが緑を広く開けにいかず、そのための取り崩しも減るため。

### Cons

- 最小限オンの推奨は 0.5〜0.6% 下がる(ユーザーは許容)。
- 最小限オフは、リーダー・メンバーが開けなくなった資材をユニット外の追加の緑が使うので、推奨はわずかに上がるが、変えるホロメンは 1〜3 人増える。
- 推奨の最後に足りない資材を埋める `coverDeficits` が外す報酬のマスは、形にそろえない(外しても形から遠ざからない)。

**Update (2026-10-10):** ユニット系担当(形 B)は、所属マスを持つ人ではなく「効く」所属マス(その所属の合計が、そのマスを除くと +900 に届かない)を持つ人にし、登録を戻したあとに形をそろえ直してもう 1 周開ける(所属マスを持つだけで形 B にすると、ゼロから組み直すメンバーの所属マスを外している間にほかの人が同じ所属を開け、登録を戻すと +900 を超えて効かなかった)。それ以外(形 A)のリーダー・メンバーと最小限オフのユニット外は、この 2 周目でだけ、効かない所属マスを通って手前より先へ進めてよい(1 周目から許すと、登録の所属マスを捨てる入れ替わりが増えた)。
