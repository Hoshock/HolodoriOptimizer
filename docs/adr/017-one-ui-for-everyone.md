# ADR-017: 画面はモードを分けず、全員が同じ導線を使う（育成の前提の 3 択・組み直すと・組み直しプラン）

Date: 2026-10-08

## Status

Accepted

## Decision

「シンプル / 詳細」のようなモードは作らず、開発者・よく使う人も初めての人と同じ画面を使う。さがすの条件は育成の前提の 3 択（いまの育成で / 育てきったら / 全カード）にまとめ、結果は「いまのまま / 組み直すと」のタブ、最適化は「組み直しプラン」と呼んで、細かい条件は使う場所（組み直しプランの「条件」）に置く。

## Context

[ADR-016](016-true-ranking-proxy-boards.md) の画面の入口（結果の見出しの「最適化順」のチップと進み具合のダイアログ）を置き換える。計算（探索・最適化・見込みのボード）は変えない。

最適化順・最適化・さがすのオプションは、開発者には使えるが、ほかの人には優しくない（ユーザー指摘）。問題は 4 つあった。

- 入口で何を登録すればよいか分からない（アカウントの 4 ボタンに状態が出ない）。
- 登録の量で結果の意味が変わるのに見えない（ボード未登録でも「ボード状況を考慮する」が既定 ON で、最適化順も Pt・資材の制限なしで 10 分回る）。
- 言葉が開発者の言葉（最適化順・ユニットのみ変更する・所持リソースを考慮する + 色ごと など）。
- 道具の切れ目（さがす / 最適化順 / 最適化）が、遊ぶ人の問い（「この曲で誰を出す？」「何を育てればもっと強くなる？」）と合っていない。

モック 3 案（結果のタブ化 / 「シンプル / 詳細」の切り替え / モードを分けない一本化）を見比べた。「シンプル / 詳細」は、ボードと開花の片方だけを考慮する組み合わせが要らないと分かった時点で（ユーザー判断）、メイン画面の差分がほとんど残らなかった。

決定の内訳と理由:

- **さがす**: 「所持カードから探す」「ボード状況を考慮する」「開花状況を考慮する」を 3 択にまとめ、ボードと開花の片方だけを考慮する組み合わせは持たない。除外 / 選択は「絞り込み」から開くダイアログへ移す。保存の形（`search-all` / `search-options` / `selection`）は変えない。
- **アカウント**: 登録がまだの入口にだけ「未登録」を出す（件数は出さない）。
- **「組み直すと」は、「いまの育成で」探した結果で、ボードを登録しているときだけ計算する**。ボード未登録で Pt・資材の制限なしに回すと「育てきったら」とほぼ同じ結果になり、意味が伝わらないため。
- **組み直しプランの条件**: 「ユニットのみ変更する」は反転して「ほかのホロメンも変える」（既定 OFF）にした。外す案もあったが、ほかのホロメンの緑ボードの全員・所属のマスやコネクトでもこの編成が伸びるので残す。所持リソースの色ごとの ON / OFF は 1 つにまとめる。
- **名前**: 同日に「育成すると」「育成プラン」で入れたが、さがすの「育てきったら」と何が違うのか分からなかった（ユーザー指摘）ので「組み直すと」「組み直しプラン」に改めた。育てきったら = 全部開けた理想（Pt・キューブの制限なし、開花最大）、組み直すと = いまのランクの Pt と持っているキューブの範囲でボード・コネクト・発動頻度を組み直す（開花は登録のまま）。

## Consequences

### Pros

- 入口で登録の抜けが分かり、結果の意味（いまの育成で / 育てきったら / 組み直すと）が選択肢とタブの名前で分かる。
- 開発者の言葉が、遊ぶ人の問いに沿った名前に置き換わる。
- 今までの機能の多くは形を変えて残った（除外 / 選択、頻度マスの数の固定、曲の選び直し、対象の個別 ON / OFF、頻度の選び方、最適化順は「組み直すと」のタブとして）。

### Cons

- ボード ON・開花 OFF / ボード OFF・開花 ON での探索と、所持リソースの色ごとの考慮はできなくなった。どちらもユーザー判断で外した。

画面の規則の正典は `.claude/rules/ui-flow.md` と `.claude/rules/ui-parts.md`。

**Update (2026-10-09):** 組み直しプランの「条件」を、結果のタブ（ボード / コネクト / 発動頻度）と同じ列の 4 択から離し、横に別のボタンとして置いた。条件は入力で、ほかの 3 つは 1 回の結果の見方だから（ユーザー指示。モック 3 案から選んだ）。

**Update (2026-10-09):** 「ほかのホロメンも変える」(ユニットのみ / 全ホロメンの 2 択)は、[ADR-019](019-minimal-rebuild-scope.md) で「最小限で組み直す」と全整理の 2 つに置き換わった。
