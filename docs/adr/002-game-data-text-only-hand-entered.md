# ADR-002: ゲームデータは手入力のテキストのみで保持し、公式アセットと解析ダンプに依存しない

Date: 2026-08-31

## Status

Accepted

## Decision

カード・楽曲・衣装スキルなどのゲームデータは、ゲーム画面や公開の攻略情報から手入力したテキスト(リポジトリ内の JSON / TS)としてだけ持ち、公式アセット(カードイラスト・ロゴ・音声・映像・スクリーンショットなど)はリポジトリにもサイトにも含めず、ゲームクライアントの解析やマスターデータのダンプに由来するデータ・ツールにも依存しない。データはコードと別のファイルに置き、権利者から要請があればすぐ公開を止められるようにする。

## Context

カバー株式会社の二次創作ガイドラインは公式素材(イラスト・ロゴなど)の転載・再配布を認めておらず、『hololive Dreams』の利用規約はリバースエンジニアリングなどの解析を禁じている。一方で、カード名・数値・スキル効果といったテキスト情報は著作物性が弱く、複数の攻略サイトや先行のファンツールが同じ種類のデータを載せて運営されている。あわせて、本ツールは収益化せず広告も置かず、非公式である旨をサイトと README に明記する。

外した案:

- GitHub 上にあるクライアント解析由来のマスターデータダンプを使う — 入手が楽で網羅的だが、規約違反に加担することになる。
- 画像を使う — ガイドライン上できない。

## Consequences

### Pros

- 法的なリスクを先行ツールや攻略サイトと同じ水準以下に抑えられる。
- データがプレーンテキストなので、diff でのレビューやスキーマ検証がしやすい。

### Cons

- 新カード・新曲の追加が手作業になり、更新が遅れうる。
- 手入力の誤りが起こりうる(スキーマ検証と相互チェックで減らす)。
- 画像がないぶん、カードの見分けやすさで公式や既存ツールに劣る(テキスト中心の UI で補う)。

**Update (2026-09-11):** コネクト効果の範囲の相対座標と増幅 ‰ はゲーム画面に数値で出ないので、外部の公開データベースのスナップショット【外部情報】の値を暫定仕様として持つ(ユーザーが「仮定でよい」と明示。[ADR-008](008-connect-effect-provisional-model.md))。持ち込むのは範囲の形と ‰ の値だけで、外部のカード識別子・ファイル名・データ構造は入れず、値を実機確認済みとは書かず、一般規則は実機観測で決め、カードとの対応はツールに持たない(扱いは `docs/ai/evidence-policy.md`)ので、この Decision は変えない。

**Update (2026-10-09):** ★4 のカードデータ([ADR-022](022-star4-cards-fixed-only.md))とカード固有のコネクト効果([ADR-023](023-connect-inventory-from-owned-cards.md))は、抽出マスター(外部解析)からの転記で持つことにした。この 2 つについては、Decision の「解析・ダンプ由来のデータに依存しない」と、上の Update の「カードとの対応はツールに持たない」が置き換わっている。転記した値は外部解析の扱いで、実機確認済みとは書かない。
