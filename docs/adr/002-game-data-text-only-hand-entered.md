# ADR-002: ゲームデータは手入力のテキストのみで保持し、公式アセットと解析ダンプに依存しない

- Date: 2026-08-31
- Status: Accepted

## Decision

カード・楽曲・衣装スキル等のゲームデータは、ゲーム画面や公開されている攻略情報からの手入力によるテキストデータ(リポジトリ内の JSON/TS)としてのみ保持する。カードイラスト・ロゴ・音声・映像・スクリーンショット等の公式アセットは一切リポジトリ・サイトに含めない。ゲームクライアントの解析・マスターデータダンプ由来のデータやツールには依存しない。データはコードと分離したファイルに置き、権利者からの要請があれば速やかに公開停止できる構成とする。

## Context

カバー株式会社の二次創作ガイドラインは公式素材(イラスト・ロゴ等)の転載・再配布を許諾しておらず、『hololive Dreams』の利用規約はリバースエンジニアリング等の解析を禁止している。一方、カード名・数値・スキル効果といったテキスト情報は著作物性が弱く、複数の攻略サイト・先行ファンツールが同種データを掲載して運営されている実績がある。GitHub 上にはクライアント解析由来のマスターデータダンプも存在するが、これに依存すると規約違反への加担となるため採用しない。本ツールは非収益・広告なしで運営し、非公式である旨をサイトと README に明記する(却下した代替案: 解析ダンプの利用は入手が楽で網羅的だが規約違反リスクがあり不採用。画像利用はガイドライン上不可のため不採用)。

## Consequences

### Pros

- 法的リスクを先行ツール・攻略サイトと同水準以下に抑えられる。
- データがプレーンテキストなので diff レビュー・スキーマバリデーションが容易。

### Cons

- 新カード・新曲の追加が手作業になり、更新が遅れうる。
- 手入力ミスのリスクがある(スキーマバリデーションと相互チェックで軽減する)。
- 画像がないぶん、カードの視認性で公式・既存ツールに劣る(テキスト主体の UI 設計で補う)。

**Update (2026-09-11):** コネクト効果（`src/data/connect.ts`）の範囲の相対座標と増幅 ‰ は、ゲーム画面に数値として出ないため、外部の公開データベースのスナップショット【外部情報】から引き継いだ値を**暫定仕様**として持つ（ユーザーが「仮定でよい」と明示。ADR-008）。この Decision の「解析・ダンプ由来のデータに依存しない」は変えない — 持ち込むのは範囲の形と ‰ の値だけで、外部のカード識別子・ファイル名・データ構造の写しは入れず、値を「実機確認済み」とは書かず、一般規則はユーザーの実機観測で決める（`.claude/rules/game-facts.md` の【外部情報】の扱い）。カードとの対応はツールに持たず、ユーザーがコネクトマスごとに範囲の形と倍率をカード詳細の表示から写す（ADR-008 の Update）。
