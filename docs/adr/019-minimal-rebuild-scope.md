# ADR-019: 組み直しの範囲は「最小限で組み直す」と全整理の 2 つで、最小限でもユニット外の緑・黄を使う

- Date: 2026-10-09
- Status: Accepted

[ADR-016](016-true-ranking-proxy-boards.md) の「緑の全員・パラメータ・所属のマスは外して回せる資材に入れない」と、[ADR-017](017-one-ui-for-everyone.md) の「ほかのホロメンも変える」（ユニットのみ / 全ホロメンの 2 択）を置き換える。計算の近似の仕方（貪欲法・ボード → コネクト → 頻度の段）は変えない。

## Context

「ユニットのみ変更」は名前と意図が合っていなかった。この編成を強くするのに最低限組み直すべきものには、ユニット外のホロメンのボードも含まれる（ユーザー指摘 2026-10-09）:

- 緑の所属向けのマス（G-008 / G-011 / G-021）はそのホロメンの所属のカード全員に効くので、メンバーと同じ所属のユニット外のホロメンに開けても同じだけ効く。そこへ開ければ、メンバーのボードPt は赤・青・黄に注力できる。
- 緑のキューブが足りないときは、メンバーに効かない所属のホロメンの所属マスから拝借してよい（「所属グループ系のマスの移し替えはしてよい。アカウント全体でのキューブ総量は守る」）。幹の G-008 / G-011 を外すとその先のマスも落ちるので、スコアの損と引き換えの取引になる。
- 黄も同じ方向で、全体曲ならユニット外のホロメンの「全体」のマスも効くし、ソロ / ユニット曲の歌唱者がユニット外にいることもある。曲に効かない黄のマスはすでに外して回している（ADR-016）。
- 赤・青は、ライフ・報酬系を除いた効くマスを全部開けるのが理論値で、足りなければユニット外の赤・青から外して回す（ADR-016 のまま）。

もう一方の「全ホロメンのボードを組み直す」は理論上限を目指すときの全整理で、勝ちに行くときにしか使わない。

考えて退けた案: 緑の所属マスの移し替えを「外して回せる資材」に静的に足す（ADR-016 の数え方の延長）。幹のマスを外すと先の全員のマスが落ちてスコアが下がるので、損を評価せずに数えると取りすぎる。

## Decision

- **範囲は 2 つ**で、画面は「最小限で組み直す」のチップ 1 つ（ON が既定）。OFF が全整理（`all`）。「ユニットのみ変更する」「ほかのホロメンも変える」の名前は使わない。
- **最小限（`minimal`）**: リーダーとメンバーのホロメンのボードを組み直す（いままでどおり）。**ユニット外のホロメンは登録の状態から足す・取り崩すだけ**:
  - 足せるのは、メンバーの所属に効く緑の所属マスと、指定した曲に効く黄のマス（経路の途中のマスは通る）。全員のマスなどはターゲットにしない — それは全整理の役目。
  - 緑の資材が足りないときは、ユニット外の「メンバーに効かない所属マスと報酬のマス」を先のマスごと外して回す。取れるものがなくなったときだけ 1 人ずつ試し（空く資材が多い人から）、取り崩しが報われなければ戻して止める — 外すホロメンの数を最小にする。
  - 赤・青・黄のユニット外の効かないマスは ADR-016 のまま静的に外して回す。
- **コネクトの範囲**は変えない（最小限 = リーダーとメンバーだけ。枚数が足りないときだけユニット外から外す）。
- ⓘ の説明は 赤 → 青 → 黄 → 緑 の順に書く。

## Consequences

### Pros

- 最小限でも、緑の所属マスと黄の全体のマスをユニット外に置けるので、メンバーの Pt を赤・青・黄に使える。
- 緑のキューブが足りないアカウントでも、関係ない所属の所属マスから回して推奨が出る。
- 画面の選択肢は 1 つのチップのままで、名前が意図（最低限 / 理論上限）と合う。

### Cons

- 最小限の推奨にユニット外のホロメンの変更（開ける・外す）が混じる。ボードのタブに行として出るので見えるが、「ユニットだけ」ではなくなった。
- 取り崩しは 1 人ずつの貪欲法で、2 人分外せば届く候補は取らない。近似の精度は `docs/ai/tmp/pending.md` 8。
- 緑の所属マス以外（ユニット外の赤・青・黄）は静的な回収のままなので、取り崩しの損得評価は緑にしかない。
