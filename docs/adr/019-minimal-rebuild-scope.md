# ADR-019: 組み直しの範囲は「最小限で組み直す」と全整理の 2 つで、最小限でもユニット外の緑・黄を使う

Date: 2026-10-09

## Status

Superseded by [ADR-020](020-minimal-rebuild-outsiders-pt.md)

## Decision

組み直しの範囲を、画面のチップ「最小限で組み直す」の ON（`minimal`。既定）と OFF の全整理（`all`）の 2 つにする。最小限ではリーダーとメンバーのボードを組み直すほか、ユニット外のホロメンにも登録の状態から、メンバーの所属に効く緑の所属マスと曲に効く黄のマスを足し、緑の資材が足りなければ効かない所属マスを取り崩す。この編成を強くするのに最低限組み直すべきものには、ユニット外のボードも含まれるからである。

## Context

[ADR-016](016-true-ranking-proxy-boards.md) の「緑の全員・パラメータ・所属のマスは外して回せる資材に入れない」と、[ADR-017](017-one-ui-for-everyone.md) の「ほかのホロメンも変える」（ユニットのみ / 全ホロメンの 2 択）を置き換える。計算の近似の仕方（貪欲法、ボード → コネクト → 頻度の段）は変えない。

「ユニットのみ変更」は名前と意図が合っていなかった（2026-10-09 ユーザー指摘）。

- 緑の所属マス（G-008 / G-011 / G-021）はその所属のカード全員に効くので、メンバーと同じ所属のユニット外のホロメンに開けても同じだけ効く。そこへ開ければ、メンバーのボードPt を赤・青・黄に回せる。
- 緑のキューブが足りないときは、メンバーに効かない所属のホロメンの所属マスから回してよい（ユーザー判断: 所属マスの移し替えはよいが、アカウント全体のキューブ総量は守る）。
- 黄も同じで、全体曲ならユニット外の「全体」のマスも効き、ソロ / ユニット曲の歌唱者がユニット外にいることもある。
- 赤・青は ADR-016 のまま（効くマスを全部開けるのが理論値で、足りなければユニット外の効かない赤・青を外して回す）。

全ホロメンのボードを組み直すのは理論上限を目指す全整理で、勝ちに行くときにしか使わない。そのため最小限でユニット外に足すのは、メンバーの所属に効く緑の所属マスと指定した曲に効く黄のマス（とそこまでの経路）だけにし、全員のマスなどは全整理の役目とする。ユニット外の効かない赤・青・黄は ADR-016 のまま静的に外して回す。コネクトの範囲は変えない（最小限ではリーダーとメンバーだけで、枚数が足りないときだけユニット外から外す）。画面では「ユニットのみ変更する」「ほかのホロメンも変える」の名前を使わない。

退けた案: 緑の所属マスの取り崩しを「外して回せる資材」に静的に足す（ADR-016 の数え方の延長）。幹の G-008 / G-011 を外すと先の全員のマスも落ちてスコアが下がるので、その損を評価せずに数えると取りすぎる。そこで取り崩しは、ユニット外の「メンバーに効かない所属マスと報酬のマス」を先のマスごと外すものとし、取れるものがなくなったときだけ 1 人ずつ（空く資材が多い人から）試して、報われなければ戻して止める。外すホロメンの数を最小にするためである。

## Consequences

### Pros

- 最小限でも、緑の所属マスと黄の全体のマスをユニット外に置けるので、メンバーの Pt を赤・青・黄に使える。
- 緑のキューブが足りないアカウントでも、関係ない所属の所属マスから回して推奨が出る。
- 画面の選択肢は 1 つのチップのままで、名前が意図（最低限 / 理論上限）と合う。

### Cons

- 最小限の推奨にユニット外のホロメンの変更（開ける・外す）が混じる。ボードのタブに行として出るので見えるが、「ユニットだけ」ではなくなった。
- 取り崩しは 1 人ずつの貪欲法で、2 人分外せば届く候補は取らない。近似の精度は `docs/ai/tmp/pending.md` 8。
- 取り崩しの損得を評価するのは緑だけで、ユニット外の赤・青・黄は静的な回収のまま。
