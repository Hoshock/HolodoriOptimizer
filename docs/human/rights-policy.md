# 権利ポリシー

本ツールがカバー株式会社・株式会社 QualiArts の権利を侵害しないための恒久ポリシー。すべての実装・データ追加はこのポリシーの範囲内で行う。関連する設計判断は [ADR-002](../adr/002-game-data-text-only-hand-entered.md)。

## 関係する規約(3 層)

| 規約                                       | 所在                                                        | 本ツールへの含意                                     |
| :----------------------------------------- | :----------------------------------------------------------- | :---------------------------------------------------- |
| カバー株式会社 二次創作ガイドライン        | <https://hololivepro.com/terms/>                              | 公式素材の転載・再配布は不可。営利目的は原則不可。公式と誤認させる表現の禁止 |
| 二次創作ゲームに関するガイドライン / holo Indie | <https://cover-corp.com/news/detail/20231115-02>              | 二次創作「ゲーム」の枠組み。本ツール(攻略補助)への直接適用は要確認 |
| hololive Dreams 利用規約・配信ガイドライン | <https://www.hololive-dreams.com/terms> ほか                  | 逆アセンブル・リバースエンジニアリング等の解析禁止。静止画は自撮スクリーンショット+感想の投稿のみ許容 |

注意: 上記の要点は 2026-08-31 時点の調査(検索要約を含む)に基づく。**原文の直接確認が完了するまでは要点を確定扱いしない**(docs/ai/tmp/pending.md 参照)。

## やること / やらないこと

| 区分       | 内容                                                                                                             |
| :--------- | :---------------------------------------------------------------------------------------------------------------- |
| やる       | カード名・数値・スキル効果等のテキストデータをゲーム画面・公開攻略情報から手入力で保持する                        |
| やる       | サイトと README に非公式免責(下記の文面)を常時表示し、スコアに「試算値」と明記する                                |
| やる       | 無収益(広告・投げ銭・計測なし)で運営する                                                                          |
| やる       | 権利者からの要請があれば速やかに公開停止する(データとコードを分離し、Pages の無効化だけで停止できる状態を保つ)    |
| やらない   | 公式イラスト・ロゴ・音声・映像・スクリーンショットのリポジトリへのコミット、サイトでの表示                        |
| やらない   | ゲームクライアントの解析、マスターデータダンプ・アセット抽出物(およびそれらに由来するデータ・コード)の利用        |
| やらない   | 「hololive」「ホロライブ」の正式名称・ロゴをツール名に冠すること(略称「ホロドリ」系 + 非公式明記で運用)           |
| やらない   | 公式提供と誤認させる表現・デザイン                                                                                 |

## 免責文(サイト・README 共通の基準文面)

> 本ツールはファンによる非公式ツールであり、カバー株式会社・株式会社 QualiArts とは一切関係ありません。ゲーム内の名称等の権利はすべて各権利者に帰属します。スコアはコミュニティの解析に基づく試算値であり、実際のゲーム内の値と異なる場合があります。権利者からの要請があれば速やかに公開を停止します。
