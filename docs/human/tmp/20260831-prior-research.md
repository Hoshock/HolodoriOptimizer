### 差別化の候補

既存ツールがリーダー固定全探索・TIER・所持管理までカバー済み。本ツールの差別化候補: (1) 一部メンバー固定での最適化と TOP n 提示を第一級機能にする、(2) ホロメンボード補正の織り込み、(3) 楽曲別最適化(曲長・コンボ数 × アクティブ発動周期)、(4) 構造化スキルデータによる計算根拠の透明化(内訳表示)。

## 組合せ規模感(2026-08 時点)

- ★5 は約 70 枚。リーダー固定の残り 5 枠全探索 = C(69,5) ≈ 1,124 万通り → 単一スレッド TS で数秒以内。
- 100 枚時 C(99,5) ≈ 7,528 万通り、150 枚時 C(149,5) ≈ 5.9 億通り → Web Worker / 枝刈りが必要になる目安。
- 全リーダー × 全探索(TIER 生成)は現時点でも約 7.9 億通り → やるならビルド時事前計算。

## Vite+ の状況(2026-08 時点)

- VoidZero(現 Cloudflare 傘下)開発。2026-03-13 に MIT で完全 OSS 化。npm レジストリで `license: MIT` を確認済み。
- 最新 v0.3.0(2026-08-24)。0.x で破壊的変更が続く。
- CLI は `vp` 1 本(`vp dev` / `vp check` / `vp test` / `vp build` / `vp create` 等)。設定は `vite-plus` の `defineConfig` で `vite.config.ts` に集約。
- pnpm 併用時は `pnpm-workspace.yaml` の `overrides` で `vite` → `@voidzero-dev/vite-plus-core` エイリアスが公式手順。
- CI: 公式アクション `voidzero-dev/setup-vp`。`v1` タグは更新停止のため、リリースの正確なバージョンかコミット SHA でピン留めし Renovate/Dependabot で追従するのが公式推奨。
- GitHub Pages デプロイは通常の Vite と同一(`base` 設定 + `actions/upload-pages-artifact` + `actions/deploy-pages`)。
