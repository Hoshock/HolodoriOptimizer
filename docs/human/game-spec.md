# ホロドリ ゲーム仕様メモ

HolodoriOptimizer が扱う『hololive Dreams』の仕様のうち、実機観測などで裏付けられた変わりにくい事実をまとめる。表示ユニットスコアの逆解析の詳細は [display-score.md](./display-score.md)、個別観測値は `repro/` を正典とする。

## 情報の扱い

- 実機で確認できる仕様はユーザーの実機観測を最優先する。
- 実機で数値確認できない発動確率やサーバー応答構造などは【外部情報】として分ける。
- 実装上の近似をゲーム内部の仕様として書かない。

## ユニット

- リーダー 1 人とメンバー 5 人は別枠。
- 赤ホロメンボードはリーダーにしたホロメンのものがメンバー 5 人へ効く。
- 総合力はメンバー 5 人から作る。
- 「◯◯2人の」のように count 人を選ぶパラメータ効果・スコアサポートは、確認済みケースでは**対象集合の素値合計 P + T + S が高い順**に count 人を選ぶ。編成順の先頭や対象パラメータ単体の上位ではない。

## カードと開花

★5 の確認済み範囲:

| 段階 | 主な強化 |
| :--- | :--- |
| 1凸 | アクティブスキル |
| 2凸 | 全パラメータ +10% |
| 3凸 | SP スキル |
| 4凸 | パッシブスキル |
| 5凸 | コネクト関連 |

カードごとの途中段階の実数値は `src/data/cards.json` の `bloomVariants` を使う。未確認カードを一律倍率で「確定値」と扱わない。

## カード詳細 P/T/S

カード詳細に反映されるのは、カード本体の Lv・開花、青・緑ホロメンボード、所属向けパラメータ効果など。赤ボード、メモリーのユニットパラメータ、メンバー強化ボーナス、編成条件つき衣装・パッシブはカード詳細値には直接入らない。

詳細な計算規則は `.claude/skills/parameter-calculation/SKILL.md` を正典とする。

## ホロメンボード

### 青

メンバー時の本人へ効く。P/T/S の固定値・割合、アクティブ発動率 UP、発動頻度 UP を持つ。配置・座標・全取得合計は `parameter-calculation/references/blue-board.md`。

### 緑

アカウント全体から全メンバーへ効くパラメータ効果と所属向け効果を持つ。配置は `green-board.md`。

### 黄

本人のソロ / 本人を含むユニット / 全体楽曲へのスコアボーナスと、ホロワーク報酬を持つ。曲に乗る黄の楽曲スコアボーナスはアカウント全体で上限 10.0%。表示スコアへの入る位置は [display-score.md](./display-score.md) を参照。

### 赤

リーダー時にメンバー 5 人へ効く。P/T/S の固定値・割合、歌唱者条件、スコアサポート、ライブ報酬・ライフ系効果を持つ。63 マスの配置・効果は `parameter-calculation/references/red-board.md`。

赤の**パラメータ効果**と、赤の**スコアサポートが表示スコアへどう換算されるか**は別問題。後者の一般式は未解明で、[display-score.md](./display-score.md) を正典とする。

### コネクト

コネクトの範囲・倍率・重複方法には未確認が残る。現在実装は ADR-008 の暫定モデルである。実機の観測値をモデルへ合わせて書き換えない。

## 総合力

ユニット編成画面の総合力は次の 6 項目の加算として扱う。

1. メンバーパラメータ
2. 衣装スキル
3. ホロメンボード効果
4. パッシブスキル
5. メモリー効果
6. メンバー強化ボーナス

2026-09-08 以降の実機内訳でこの構造を確認している。各項目は素値を基準に独立に算出し、連鎖的に前項へ倍率を掛けない。詳細は ADR-004 と `parameter-calculation` スキル。

## 表示ユニットスコア

実機で次が一致する。

```txt
ユニットスコア = ceil(総合力 × (1 + スコアボーナス / 100) × 2.03734)
```

スコアボーナスは現在の実機では「衣装 / アクティブ / ホロメンボード / パッシブ / SP」のカテゴリを観測できる。衣装が 0 の過去観測では 4 項目だけ表示されていた。

カテゴリ内部の式は [display-score.md](./display-score.md) を参照。実際のライブプレイ中のスコア式とは分ける（ADR-006）。

## 楽曲

- ソロ: 歌唱者 1 人
- ユニット: 複数歌唱者
- 全体: hololive IDOL PROJECT

所属名だけでは判定できない曲は `src/data/songSingers.ts` の明示データを使う。歌唱者条件を名前から推測しない。

## イベント

イベントの獲得ボーナスでは「メンバー」指定と「ホロメン」指定を別々に扱う。確認済みイベントのスコアボーナスは対象カードが複数いても +10% 上限で、リーダー枠は判定に入らない。イベントスコアボーナスを表示ユニットスコアのどの段階へ適用するかは未確認。
