# ホロドリ ゲーム仕様メモ

実機観測などで裏付けられた変わりにくい仕様の概観。証拠状態は [evidence-policy.md](./evidence-policy.md)、カード出所は [card-data-provenance.md](./card-data-provenance.md)、表示スコア詳細は [display-score.md](./display-score.md)。

## ユニット

- リーダー1人とメンバー5人は別枠。
- 赤ホロメンボードはリーダーにしたホロメンのものがメンバー5人へ効く。
- 総合力はメンバー5人から作る。
- count人を選ぶ確認済み効果は、対象集合の素値P+T+Sが高い順から選ぶ。

## カードと開花

★5の確認済み強化段階:

| 段階 | 主な強化    |
| :--- | :---------- |
| 1凸  | Active      |
| 2凸  | 全パラ+10%  |
| 3凸  | SP          |
| 4凸  | Passive     |
| 5凸  | Connect関連 |

`cards.json` トップレベルは最大開花側として扱う取り込みレコードで、全件実機確認済みという意味ではない。途中開花は `cardAtBloomWithProvenance()` で出所を区別する。未確認スキル値の÷1.1は推定。

衣装スキルはリーダーカード、パッシブはメンバーカードの効果として扱う。カード仕様を議論するときはroleを混同しない。

## カード詳細P/T/S

カード本体Lv・開花、青・緑、所属向けパラメータ等が反映される。赤、メモリーのユニットパラメータ、メンバー強化、編成条件衣装/パッシブはカード詳細P/T/Sに直接入らない。

## ホロメンボード

- 青: メンバー本人のP/T/S、Active発動率/頻度
- 緑: アカウント全体のP/T/S・所属効果
- 黄: 楽曲スコアボーナス・ホロワーク報酬。曲ボーナス上限10%
- 赤: リーダー時にメンバー5人へP/T/S、歌唱者条件、スコアサポート等

赤パラメータ効果と赤スコアサポート表示換算は別問題。

## 総合力

ユニット編成画面は6項目の加算として扱う。

1. メンバーパラメータ
2. 衣装スキル
3. ホロメンボード
4. パッシブ
5. メモリー
6. メンバー強化

各項目は素値基準で独立算出し、連鎖乗算しない。

## 表示ユニットスコア

```txt
unitScore = ceil(totalPower × (1 + scoreBonus / 100) × 2.03734)
```

カテゴリは現在 `Costume / Active / Board / Passive / SP` を観測。内部式は [display-score.md](./display-score.md)。

## 個別の実機訂正

水着フワワ `fuwawa-abyssgard-02` の衣装は2026-09-12再確認で、

```txt
ピュアタイプ2人以上で全員の全パラメータ30%UP
ピュアタイプ2人以上で全員のスコアサポート25%
```

の2行。両効果とも条件付き。旧「後半25%は無条件」解釈は誤り。

## 楽曲・イベント

所属名だけで歌唱者を解けない曲は `songSingers.ts` の明示データを使う。イベントのメンバー対象とホロメン対象は別。イベントスコアボーナスの表示ユニットスコア内での適用位置は未確認。
