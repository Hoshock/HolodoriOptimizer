# 表示ユニットスコアの逆解析

ユニット編成画面に表示される「スコアボーナス」と「ユニットスコア」の現在の知識を、**確定 / 強い推定 / 未解明 / 棄却済み**に分ける。実測値そのものは [repro/display-score-20260912.md](./repro/display-score-20260912.md) に置く。

この文書が表示スコアに関するドキュメント上の正典。`src/engine/displayScore.ts` に残る式は実装の現状を示すだけで、反証済みの近似を含む。

## 確定していること

### ユニットスコア

```txt
unitScore = ceil(totalPower × (1 + scoreBonus / 100) × 2.03734)
```

多数の実機ケースで 1 点単位まで一致している。

### 5カテゴリ

現在の実機では次の 5 カテゴリを観測できる。

1. 衣装（Costume / Leader）
2. アクティブ（Active）
3. ホロメンボード（Board / SkillTree）
4. パッシブ（Passive）
5. SP（Special）

衣装が 0 の過去観測では 4 項目だけだった。【外部情報】サーバー応答も Active / Leader / Passive / SkillTree / Special の独立カテゴリを持つとされる。現在実装の「タイムライン差分を Board / Passive へ配賦する」処理をゲーム内部式とみなさない。

### 黄ボード

曲の黄ボーナスを `Y`（10% = 0.10）とすると、表示前 raw の Board 増分は次で実機と一致する。

```txt
YellowBoardIncrement
= Y × (100 + Costume + Active + Passive + Special)
```

2026-09-12、R-061後の同一ミオ編成で「曲なし」とGamersは赤 X=26 が同じ。曲なしは `14.1 / 77.7 / 40.7 / 1.9 / 47.0`、Gamersは `14.1 / 77.7 / 64.8 / 1.9 / 47.0`。Board差 +24.1 は `0.1×(100+14.1+77.7+1.9+47.0)=24.07` と一致し、Costumeを除く旧式22.66は外れる。

したがって、衣装カテゴリが非0でも黄は5カテゴリのうち Board 以外を基準にする。厳密には表示済み値でなく各カテゴリの量子化前 raw を使う。黄だけを変えた時、総合力・Costume・Active・Passive・Special は変わらない。

### 赤のパラメータ変更とスコアカテゴリは別

赤ボードの P/T/S 固定値・割合を大きく変更して総合力が変わっても、スコアカテゴリが変わらない対照実験がある。赤のパラメータ効果を、赤スコアサポートの表示換算へ混ぜない。

## 強い推定

### アクティブ欄

200 秒の共通仮想タイムラインを使うモデルが実測に非常によく一致する。

- 発動候補: `k × interval <= s < k × interval + duration`、`k >= 1`
- 基礎発動確率: 高 55% / 中 46% / 低 37%
- 同時候補時は確率和で正規化する現在モデル
- Active の 0.1% 単位化は切り上げで既存 Golden と一致

発動確率の実数値はゲーム内で直接読めないため【外部情報】も含むが、表示 Active の再現性は高い。

### SP欄

現在モデルは多くのケースで近いが、発動率 UP を含むケースに残差がある。Activeほど確定度は高くない。

## 赤「全員のスコアサポート効果」

### 実機で確定した性質

- 表示への効きは編成に依存する。
- 同じ赤 +24 でも 2026-09-12 の観測では表示合計差が約 18.6〜20.9 pt に分布する。
- 赤 +24 は Active / SP を変えず、主に Board と Costume、場合によって Passive を動かす。
- R-061 の +3 だけを開いた対照実験では総合力不変で表示合計が +2.7 pt。
- 同一の白上フブキの青ボードを維持したまま、水着フブキ0凸から恒常フブキ1凸へカードだけ替えると赤+24の効きが約18.6→20.6 ptに変わる。単純な「フブキの青ボード量」が原因ではない。
- 水着ころねを青0の恒常マリンへ替えても、ミオ入りでは赤+24が20.9→20.9 ptと変わらない。単純な「青が多いほど赤が効く」式ではない。

### 棄却済み

一般式として次を使わない。

- `固定係数 × X`（0.88、0.85など）
- `X × 基準候補秒 / 200`
  - 旧ケースには合ったが、ミオ + 恒常マリンは基準候補秒149/200に対し +24 の実測が+20.9 pt。予測17.88 ptと大きく外れる。
- `X × 表示Active / 90`
  - ミオ + 恒常マリンではActive72.1から19.23 ptしか予測せず、実測20.9 pt。
- Costume表示値をそのまま赤の倍率にする式
  - 恒常マリン入り観測で明確に崩れた。
- 青込み候補秒・発動確率込み占有率だけで決める単純式
  - 置換実験の方向を説明できない。

現行 `redScoreSupportDisplayGain` の候補秒率式は**既知の近似であり、一般式として反証済み**。実機 Golden を近似式へ合わせて変更しない。

### 現在の本命仮説

水着フブキ0凸を含む編成だけ赤+24の効きが系統的に低い。

| 編成中の差替え | 赤+24の表示合計差 |
| :--- | ---: |
| 水着フブキ + 恒常マリン | +18.6 |
| 恒常フブキ + 恒常マリン | +20.6 |
| 水着フブキ + 水着ころね | +19.1 |
| 恒常フブキ + 水着ころね | +20.7 |
| 恒常フブキ + 恒常ころね | +20.5 |

水着フブキはキュート対象のパッシブ・スコアサポートを持ち、実測でも Passive が追加される。このため**赤スコアサポートと既存パッシブ・スコアサポートの合成位置**が次の有力候補。ただし未確定で、Activeの個別構造など別要因を排除し切っていない。

次の実験は水着フブキを固定し、そのパッシブ・スコアサポートの成立・対象だけをできるだけ独立に変える。

## Costumeカテゴリ

水着フワワの衣装スキルのスコアサポートは0凸でも25%だが、表示 Costume は25.0ではなくメンバー構成に応じて13〜17 pt台へ変化する。Costumeは衣装の記載%をそのまま表示するカテゴリではない。

赤+24の曲差でも Costume が約+0.3〜+0.5動く観測があり、一般式は未解明。

## Passive / Board / Blue の未解決

- Passiveスコアサポートの対象・合成位置
- 赤由来増分の Costume / Board / Passive への配賦
- 青の発動率UP / 発動頻度UPがBoardへどう換算されるか
- Costume / Board / Passive の厳密な0.1%量子化規則
- 衣装カテゴリを独立に持つ5カテゴリ構造への実装更新

## 実験・実装時のルール

- Golden観測値をモデルに合わせない。
- 1ケースだけに合う定数を一般化しない。
- 観測値、そこから一意に計算できる値、仮説を分ける。
- モデルを変える前に既存の全実測コーパスで反証を探す。
- 実ライブのスコア式と表示ユニットスコアを混同しない。
