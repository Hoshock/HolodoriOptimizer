# 表示ユニットスコアの逆解析

ユニット編成画面に表示される「スコアボーナス」と「ユニットスコア」の現在の知識を、**確定 / 強い推定 / 未解明 / 棄却済み**に分ける。実測値そのものは [repro/display-score-20260912.md](./repro/display-score-20260912.md) に置く。

この文書が、表示スコアに関するドキュメント上の正典である。`src/engine/displayScore.ts` や古いボード資料に残る式は実装の現状を示す場合があり、ゲーム内部式の正典ではない。

## 確定していること

### ユニットスコア

```txt
unitScore = ceil(totalPower × (1 + scoreBonus / 100) × 2.03734)
```

多数の実機ケースで 1 点単位まで一致している。総合力とスコアボーナスはこの式へ入る別の値として扱う。

### カテゴリ

現在の実機では次の 5 カテゴリを観測できる。

1. 衣装
2. アクティブ
3. ホロメンボード
4. パッシブ
5. SP

衣装が 0 の過去観測では 4 項目だけだった。【外部情報】サーバー応答も Active / Leader / Passive / SkillTree / Special の独立カテゴリを持つとされる。したがって、現在実装の「タイムライン差分をボード・パッシブへ配賦する」処理をゲーム内部式とみなさない。

### 黄ボード

曲の黄ボーナスを `Y`（例: 10% = 0.10）とすると、実測は表示前の raw 値で次の増分と整合する。

```txt
黄による Board 増分
= Y × (100 + Costume + Active + Passive + Special)
```

総合力、Costume、Active、Passive、Special 自体は黄だけでは変わらない。表示済みの 0.1 刻み値ではなく、カテゴリの量子化前の値から計算する必要がある。

旧実装 `songBoardRaw` は衣装カテゴリを独立に持たなかった時期の構造を引きずっているため、衣装が非 0 の編成ではこの確定事項との差があり得る。

### 赤のパラメータ変更とスコアカテゴリは別

赤ボードの P/T/S 固定値・割合を大きく変更して総合力が変わっても、スコアボーナス 5 カテゴリが変わらない対照実験がある。赤のパラメータ効果を、赤スコアサポートの表示換算へ混ぜない。

## 強い推定

### アクティブ欄

200 秒の共通仮想タイムラインを使うモデルが実測に非常によく一致する。

- 発動候補: `k × interval <= s < k × interval + duration`、`k >= 1`
- 基礎発動確率: 高 55% / 中 46% / 低 37%
- 同時候補時は確率和で正規化する現在モデル
- Active の 0.1% 単位化は切り上げで既存 Golden と一致

発動確率の実数値はゲーム内で直接読めないので【外部情報】も含むが、表示 Active の再現性は高い。

### SP 欄

現在モデルは多くのケースで近いが、発動率 UP を含むケースに残差がある。Active ほど確定度は高くない。

## 赤「全員のスコアサポート効果」

### 実機で確定した性質

- 表示への効きは編成に依存する。
- 同じ赤 +24 でも 2026-09-12 の観測では表示合計差が約 18.6〜20.9 pt に分布する。
- 赤 +24 は Active / SP を変えず、主に Board と Costume、場合によって Passive を動かす。
- R-061 の +3 だけを開いた対照実験では総合力不変で表示合計が +2.7 pt。
- 同一の白上フブキの青ボードを維持したまま、水着フブキ 0凸から恒常フブキ 1凸へカードだけ替えると赤 +24 の効きが約 18.6 → 20.6 pt に変わった。したがって単純な「フブキの青ボード量」が原因ではない。
- 水着ころねを青 0 の恒常マリンへ替えても、ミオ入り編成では赤 +24 が 20.9 → 20.9 pt と変わらなかった。単純な「青が多いほど赤が効く」式ではない。

### 棄却済み

次を一般式として使わない。

- `固定係数 × X`（0.88、0.85 など）
- `X × 基準候補秒 / 200`
  - 旧ケースには合ったが、ミオ + 恒常マリン編成は基準候補秒 149/200 に対し +24 の実測が +20.9 pt で、予測 17.88 pt と大きく外れる
- `X × 表示 Active / 90`
  - ミオ + 恒常マリンでは Active 72.1 から 19.23 pt しか予測せず、実測 20.9 pt
- Costume 表示値をそのまま赤の倍率にする式
  - 恒常マリンを入れた観測で明確に崩れた
- 青込み候補秒・発動確率込み占有率だけで決める単純式
  - 既存の置換実験の方向を説明できない

現行 `redScoreSupportDisplayGain` の候補秒率式は**既知の近似であり、一般式としては反証済み**。実機 Golden を近似式へ合わせて変更してはいけない。

### 現在の本命仮説

水着フブキ 0凸を含む編成だけ赤 +24 の効きが系統的に低い。

- 水着フブキ + 恒常マリン: +18.6
- 恒常フブキ + 恒常マリン: +20.6
- 水着フブキ + 水着ころね: +19.1
- 恒常フブキ + 水着ころね: +20.7

水着フブキはキュート対象のパッシブ・スコアサポートを持ち、実測でも Passive が追加される。このため**赤スコアサポートと既存のパッシブ・スコアサポートの合成位置**が次の有力候補。ただし未確定であり、Active の個別構造など別要因を排除し切っていない。

次の実験は、水着フブキを固定し、そのパッシブ・スコアサポートの対象成立だけを変えられる編成を作る。複数要因を同時に変えた比較を単独差分として扱わない。

## 衣装カテゴリ

水着フワワの衣装スキルのスコアサポートは 0凸でも 25% だが、表示 Costume は 25.0 にはならず、メンバー構成に応じて 13〜17 pt 台へ変化する。したがって Costume は「衣装に書かれたサポート % をそのまま表示するカテゴリ」ではない。

赤 +24 の曲差でも Costume が約 +0.3〜+0.5 動く観測がある。一般式は未解明。

## Passive / Board / Blue の未解決

- Passive のスコアサポートの対象・合成位置
- 赤由来の増分が Board / Costume / Passive にどう分かれるか
- 青の発動率 UP / 発動頻度 UP が表示 Board へどう換算されるか
- Board / Passive / Costume の厳密な 0.1% 量子化規則
- 衣装カテゴリを独立に持つ 5 カテゴリ構造への実装更新

## 実験・実装時のルール

- Golden 観測値をモデルに合わせない。
- 1 ケースだけに合う定数を一般化しない。
- 観測値、そこから一意に計算できる値、仮説を別の列・段落にする。
- モデルを変える前に、既存の全実測コーパスで反証を探す。
- 実ライブのスコア式と表示ユニットスコアの式を混同しない。
