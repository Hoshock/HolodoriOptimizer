## この系列から言えること

1. **アクティブ欄 70.8 と SP 欄 42.8 は 8 点とも不変。** 青ボードはこの 2 欄に効かない（既存の確定事項の追加確認）。
2. **pre-yellow の 3 欄合計の増分（リーダー支援 60% ぶん）は非単調。** 45.7 / 46.4 / **39.3** / 46.2。F2 だけ 15% 落ちる。
3. **F3 は 2026-09-12 の K3 の 5 欄を両リーダーとも完全再現した。** K3 の「転記ミス / historical snapshot の異常 / ケース固有の青入力」という説明は落ちる。K4 は同条件で再測定していないので、この再現を K4 へ広げない。
4. **projective direction は発動頻度の所有者に依存しない。** クロニー側の 衣装 : ボード : パッシブ の正規化シェアは 4 状態とも約 71.8% : 26.5% : 1.7% で、総量が 27% 落ちる F2 でもほぼ同じ。総量 `T` の生成と、`C / B / P` への配分は別レイヤーで扱う。
5. **`周期 ÷ (1 + f/100)` は反証されていない。** 同時候補の正規化 `max(1, Σp)` と組み合わせると、F2 では青込みタイムラインが青なしより**下がる**（支援なし側の raw が負になり、実機の 0 / 0 表示と整合する）。この非単調性を自由係数なしで再現できるのはこの式だけ。
6. **「編成全体の評価値どうしの差」型の `W_blue` は 1 群として棄却。** 実測が要求する `W_blue / H_C` は 4 状態で 0.2208〜0.2215 に共通部分を持つのに、この族（`E_blue(加算) − H_C` など 7 候補）は 0.175〜0.277 とばらつく。`H_C` 自体は F2 で 10% 低いので、比が一定なのは自明ではない。

残っている未解明は `W_blue` の決定式（採用中の member-local 型は F2 を 0.023 低く見積もる）と、SP 欄の発動率 UP 項。
