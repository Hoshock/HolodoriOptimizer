## 量子化の位相

欄ごとの規則を「独立 / アクティブ欄との差」×「切り上げ / 切り捨て / 四捨五入」と累積順序で総当たりし、
16 編成（クロニー 60%）・3 編成（ぺこら 25%）・6 件の みこ baseline を同時に満たすものを探した。
探索は**配分の式に依存しない**（パッシブの取り分 `φ` を 0〜1 で総当たりし、両欄と両立する `φ` の有無だけを見る）。

| 欄         | 位相                                                              | 確度                                               |
| :--------- | :---------------------------------------------------------------- | :------------------------------------------------- |
| アクティブ | `ceil(A)`                                                         | 確定                                               |
| 衣装       | **`ceil(A + 衣装raw) − ceil(A)`**（アクティブ欄との差として切る） | **頑健**（`A` のぶれを許しても差分型しか残らない） |
| パッシブ   | `ceil(パッシブraw)`                                               | 条件つき（`A` を厳密とみなしたときだけ 1 通り）    |

**現行の「欄ごとに独立に切り上げ」は棄却**（パッシブ支援がない 4 件で外れる）。累積順序はどの丸めでも外れる。

コーパス 153 列では差がつかない（衣装欄 21/51 で現行と同点）。コーパスの行は青・赤が入っていて
**raw そのものがまだ合っていない**（どの位相でも最良 27/51）ので、位相の判別材料にはならない。
