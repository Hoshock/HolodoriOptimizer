# 2026-09-15: 衣装欄の量子化の位相（クロニー 60% × 青なし 8 編成）

リーダーを 典獄クロニー（全員のスコアサポート 60%。衣装スキルは開花で変わらない）にし、**青 0・赤 0・黄 0・曲なし**の 5 人編成で **アクティブ欄と衣装欄**を読んだ。`reported`（単発）。

この条件では production の衣装欄 raw は `0.60 × アクティブ欄 raw` ちょうどになるので、残る自由度は**表示 0.1 刻みへ落とす位相だけ**になる。

## 読み取れること

1. **パッシブ支援がない 4 件（K5 / 6 / 7 / 8）は全会一致**。独立に切り上げる現行の規則は 4/4 外し（すべて実機より 0.1 高い）、「アクティブ欄との差として量子化する」形が 4/4 当てる。**現行の位相は棄却**。
2. **1 と 3 は判定に使えない。** 判定は `ceil(1.6 × A)` がどちら側に落ちるかで決まるが、この 2 件は `1.6A` が 0.1 の境界から 0.0005 / 0.0008 しか離れていない（編成を選ぶときに `A` と `0.6A` の境界距離しか見ていなかった設計ミス）。raw が 0.001 動けば答えが反転するので、1 と 3 が逆を向いたことは矛盾ではない。
3. **残る食い違いはパッシブ支援がある編成に限られる。** とくに 2 は、どの位相でも衣装欄 raw が **0.24 足りない**（実機を出すには 40.59 以上が要るがモデルは 40.35）。2 は 4 枚がスコアサポート持ちのパッシブを積んでいる唯一の編成で、モデルのパッシブ欄 raw も 8.76 と他の 3〜4 倍ある。

## 位相候補の機械比較

| 位相                                 | コーパス 153 列 | この 8 件の衣装欄 |
| :----------------------------------- | --------------: | ----------------: |
| 欄ごとに独立に切り上げ（現行）       |              59 |         **2 / 8** |
| 累積（パッシブ → 衣装 → ボード）     |          **61** |             6 / 8 |

どの候補も 2 を外す。**位相を決める前にパッシブ支援の扱いを片付ける必要がある** — 1・2・3 の 5 欄すべて（とくにパッシブ欄）が要る。パッシブ欄も一緒にずれていれば総量 `T` の問題、衣装欄だけなら 3 欄の配分の問題。
