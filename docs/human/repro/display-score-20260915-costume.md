## 読み取れること

1. **パッシブ支援がない 4 件（6 / 7 / 8 / K5）では配賦の自由度がない**（`W_P = 0` で 衣装欄 raw = 総量 `T`）。
   ここで独立に切り上げる現行の規則が 4/4 外れる（すべて実機より 0.1 高い）ので、**位相の問題は配分と切り離して読める**。
2. **編成 1 と 3 は razor thin**。`0.60 × A` が 0.1 の境界から 0.0005 / 0.0008 しか離れていない
   （編成を選ぶときに `A` と `0.6A` の境界距離しか見ていなかった設計ミス）。単独では判定に使えない。
3. **残る食い違いはパッシブ支援がある編成に限られ、衣装欄とパッシブ欄のあいだの移動になっている。**
   総量 `T`・アクティブ欄・ボード欄・SP 欄・合計はすべて合う。

## 位相候補の機械比較（2026-09-15 に決着）

**位相は 1 通りしか残らない。** 欄ごとの規則を「独立 / アクティブ欄との差」×「切り上げ / 切り捨て / 四捨五入」と累積順序で総当たりし、
12 編成（クロニー）の 衣装欄・パッシブ欄と、みこ baseline 6 件のパッシブ欄を同時に満たすものを探すと、残るのは

| 欄         | 位相                                                              |
| :--------- | :---------------------------------------------------------------- |
| アクティブ | `ceil(A)`（既知）                                                 |
| 衣装       | **`ceil(A + 衣装raw) − ceil(A)`**（アクティブ欄との差として切る） |
| パッシブ   | **`ceil(パッシブraw)`**（素の切り上げ）                           |

の 1 通りだけ。この探索は**配分の式に依存しない**（パッシブの取り分 φ = パッシブraw / T を 0〜1 で総当たりし、
両欄と両立する φ が 1 つでもあるかだけを見る）。前提は「総量 `T = 0.60 × A + ΔP`」と「衣装raw + パッシブraw = T」の 2 つで、
どちらも みこ baseline と合計・ユニットスコアで裏づけがある。

- 現行（全欄を独立に切り上げ）は パッシブ支援がない 4 件（6 / 7 / 8 / K5）で外れる。
- 「衣装も差分・パッシブも差分」は 編成 3 と S2 で外れる（`T` が要求量にわずかに足りない）。
- 累積（衣装 → パッシブ / パッシブ → 衣装）はどの丸めでも外れる。

コーパス 153 列では 衣装欄 21/51（現行の独立切り上げと同点）で、差がつかない。ただしコーパスの行は青・赤が入っていて
**raw そのものがまだ合っていない**（どの位相でも最良 27/51）ので、位相の判別材料にはならない。青 0・赤 0 のこの 12 件のほうが強い。

固定は `src/engine/displayScoreCostumeQuantization.test.ts`。

### いちばん効く 1 対比: S2 → S3（奏 を リス へ 1 枚差し替え）

支援を受ける 2 人（ロボ子・ポルカ）が同じなので、「その 2 人が重み全体に占める割合」を直接比べられる。

|                    |             S2 |             S3 | 向き       |
| :----------------- | -------------: | -------------: | :--------- |
| 実機が要求する割合 | 0.4001〜0.4013 | 0.3960〜0.3982 | **下がる** |
| モデルの取り分     |         0.4171 |         0.4431 | **上がる** |

**区間が重ならないまま向きが逆になる。** つまり配分の重みは、production が使っている

要求される重みは取り分より**メンバー間の差が小さい**（一様に近い）が、一様そのものでもない

**残る不定性はメンバーごとの重み `w_i` の形だけ**になった。表示の重みは
`W = Σ (支援% / 100) × w_i`（衣装は全員に同じ %、パッシブは対象だけ）で、
production が使う「競合で正規化した取り分」が `w_i` として間違っている。

締め直した `f`（7 編成）と現行モデルの取り分:

| 編成 | 支援を受ける人                     | 要求 `f`        | モデルの取り分 |
| :--- | :--------------------------------- | :-------------- | -------------: |
| 1    | マリン・レイネ                     | 0.43336–0.44964 |        0.43063 |
| 3    | フレア・ビジュー                   | 0.38000–0.38476 |        0.38493 |
| K6   | フレア・マリン                     | 0.42167–0.43148 |        0.43008 |
| S1   | ロボ子・レイネ                     | 0.41539–0.41942 |        0.41637 |

| S3   | ロボ子・ポルカ                     | 0.39690–0.39818 |        0.44314 |

編成 2 は 24% と 8% の混在なので `f` では書けず、`ρ = W_P / W_C ∈ 0.20930–0.21111`（モデル 0.21715）。

`w_i` を 一様 / スコアUP% / 発動確率 / 正規化なしの寄与 / 発動候補秒 / 候補の均等割り / それらの積 に替えても、
8 件中 0〜2 件しか当たらない。**「メンバーごとに固定の重み」という族自体はまだ生きている**（15 枚 × 8 制約なので
線形計画としては解が存在する）が、制約が足りず形が決まらない。

## 次に要る観測: 6 枚プールで `w` を過剰決定する

`w_i` を特定するには、**支援を受ける 2 人を固定したまま残りを入れ替える対比**（S2 → S3 と同じやり方）を積むしかない。
カードを 6 枚に絞れば未知数は 6（尺度を除いて 5）で、5 人編成は 6 通りあるので**過剰決定**になる。

プール: **ロボ子0 / ポルカ0 / リス0 / 奏0 / スバル0 / アーニャ0**（うち ロボ子・ポルカ・リス がハッピー 2 人へ 8% を供給）。
このうち S2（リスを抜く）と S3（奏を抜く）は取得済み。残りは 4 編成。

| 抜くカード | メンバー 5 人                          | アクティブ |   SP | みこ パッシブ | 現行モデル               | 一様なら   |
| :--------- | :------------------------------------- | ---------: | ---: | ------------: | :----------------------- | :--------- |
| アーニャ   | ロボ子 / ポルカ / リス / 奏 / スバル   |       59.3 | 35.1 |           6.4 | 衣装 35.5 / パッシブ 6.4 | 36.1 / 5.8 |
| スバル     | ロボ子 / ポルカ / リス / 奏 / アーニャ |       64.0 | 37.4 |           6.4 | 衣装 38.3 / パッシブ 6.4 | 38.5 / 6.2 |
| ポルカ     | ロボ子 / リス / 奏 / スバル / アーニャ |       59.1 | 34.4 |           3.9 | 衣装 35.4 / パッシブ 3.9 | 35.5 / 3.8 |
| ロボ子     | ポルカ / リス / 奏 / スバル / アーニャ |       59.3 | 34.4 |           3.8 | 衣装 35.5 / パッシブ 3.8 | 35.5 / 3.8 |

リーダーは **典獄クロニー（60%）**。「抜く = アーニャ / スバル」の 2 編成はキュートが 1 人になるので
ぺこら（キュート 2 人以上）は条件を満たさない。「一様なら」は参考で、一様そのものは既に棄却されている
（どの編成も `w` の 1 本の線形制約を与えるので、差がつかない編成も特定には効く）。

**対象選抜を別途 pin する必要がある。** ハッピーが 3〜4 人いるので「上位 2 人」がどの 2 人かは実機の
`P + T + S` で決まる。みこリーダーでの読み直しを 4 回増やす代わりに、**カード詳細の P / T / S を
ロボ子 / ポルカ / リス / 奏 の 4 枚ぶん**もらえれば全編成の選抜が決まる（編成 1 のときと同じやり方）。
上表の「みこ パッシブ」は `cards.json`（上限側）の順位で選んだ場合の値なので、実機の順位が違えば変わる。
