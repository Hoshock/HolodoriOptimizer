この文書の数値は原則 `reported`。ユニットスコア式と一致したものは `cross-checked` でもあるが、編成・Lv等の再読を意味しない。個別に `rechecked` と書いていない入力は、次の重要実験に使う前に必要に応じて再確認する。

## 共通条件として記録されたもの

特記がない matched pair は次の条件として記録されている。

- リーダー: 水着フワワ 0凸
- メンバー順: 水着みこ 1凸 / A / 水着フワワ 0凸 / 水着おかゆ 5凸 / B
- 赤ボード: R-061 開放後
- 赤スコアサポート: フワワが歌唱者でない時 X=26、歌唱者の時 X=50。曲差+24
- 比較曲: Gamers / FUWAMOCO。両方黄10%
- カテゴリ順: `Costume / Active / Board / Passive / SP`

**注意:** この共通条件は会話中の記録を整理したもの。各行の元画面を再読したわけではない。編成順が式に影響する仮説を検証するときは、元観測の順序を再確認する。

外側の式 `ceil(power × (1 + bonus/100) × 2.03734)` と一致するケースは数値の独立cross-checkとして扱う。
