# 表示スコア逆解析 実機観測コーパス（2026-09-12）

表示ユニットスコアの一般式探索に使う実機 Golden。解釈は [../display-score.md](../display-score.md) に分離し、この文書では入力条件と観測値を優先する。

## 共通条件

特記がない matched pair は次の条件。

- リーダー: 水着フワワ 0凸
- メンバー順: 水着みこ 1凸 / A / 水着フワワ 0凸 / 水着おかゆ 5凸 / B
- 赤ボード: R-061 開放後
- 赤スコアサポート: フワワが歌唱者でない時 X=26、歌唱者の時 X=50。曲差は +24
- 比較曲: Gamers と FUWAMOCO。両方とも黄10%
- カテゴリ順: `Costume / Active / Board / Passive / SP`
- Passive=0のケースは実機上省略されても表では0と書く

ユニットスコアは `ceil(power × (1 + bonus/100) × 2.03734)` と一致する。
