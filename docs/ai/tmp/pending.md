4. **3 欄（衣装 / ボード / パッシブ）の配分の重み — 残るのはメンバーごとの `w_i` だけ**
   - 材料は 青 0・赤 0・黄 0・曲なしの 16 編成（リーダー 典獄クロニー 60%）、うち 3 編成は 恒常ぺこら（25%）でも、
     6 編成は 恒常みこ 0凸（支援 0）でも読んだ。観測は
     [repro/display-score-20260915-costume.md](../../human/repro/display-score-20260915-costume.md)、
     固定は `displayScoreCostumeQuantization.test.ts`。
   - **【確定】総量 `T = 0.60 × A + ΔP` と対象選抜は正しい**（アクティブ欄 16/16、みこ側のパッシブ欄 6/6、
     SP 欄・合計・ユニットスコアも一致）。**カードの Lv はスキルの数値を変えない。**
   - **【確定】衣装欄はアクティブ欄との差として量子化される** `ceil(A + C) − ceil(A)`。現行の独立切り上げは棄却。
     パッシブ欄が 独立-切り上げ か 差分か は分かれない。
   - **【確定】`W_C` はリーダーのスコアサポート % に比例する**（60% → 25% で同じ `f` が通る。予測を先に出しての一致）。
     表示の重みは `W = Σ (支援%/100) × w_i`。
   - **`w_i` が未解明。** production の「競合で正規化した取り分」は 12 編成中 9 で外れる。一様でもない。
     自由係数なしの候補の一致数: 取り分 3 / 発動確率 4 / 一様 4 / スコアUP% 3 / `up × p0` 2。
     棄却済み: 定数倍 `k × ΔP` / メンバーごとの `g(s)` / `ΔP`・`ΔP/A` の単調関数 / 逐次 marginal・単独・Shapley
     （カーネルが静的倍率に厳密線形なので各 source の寄与へ戻る）/ 競合の分母に静的倍率を入れたカーネル。
   - **6 枚プール（ロボ子 / ポルカ / リス / 奏 / スバル / アーニャ）では、カードごとに固定の重みが過剰決定で成立する。**
     決定的なのは リス と スバル（周期 34 秒）で、取り分 0.87 / 0.84 に対し実機は ≥ 1.02 / ≥ 0.98 を要求する。
     表示の重みはタイムライン上の寄与よりずっと平ら。

     （衣装欄が差分型なのは不変）、S2 と S3 の区間は重なる。どちらも取り下げた。
     **今後 `f` を出すときは `A` のぶれを必ず入れる。**

     発動確率が 高 3 枚・中 3 枚、周期が 18 / 21 / 23 / 24 / 34 / 34 秒と偏っているので、
     **低確率のカードと周期が極端なカードを 1〜2 枚足した 7〜8 枚プール**にして、`w_i` が発動確率で決まるのか
     周期で決まるのかを分ける。編成候補は予測が最大に割れる組み合わせを選ぶ。
