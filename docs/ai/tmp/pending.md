## 表示ユニットスコア

3. **赤スコアサポート — 総増分は強い推定、残る主問題はカテゴリ配賦**
   - 旧 `X × 基準候補秒 / 200` は反証済み（production には既知の近似として残る）。
   - 総増分 `ΔRed(X) = X/100 × E_blue`（乗算型の青入りアクティブ期待値）が実機13対照で RMSE ≈ 0.09 pt・最大 ≈ 0.13 pt（`src/engine/displayScoreExperimental.ts`、production 未採用）。加算型は ≈ 0.85 pt、旧式は ≈ 1.0 pt。
   - **次の逆解析対象はこの総増分が Costume / Board / Passive の各サーバーカテゴリへどう配賦されるか**（赤+24で Costume +0.5 / Board +20.4 / Passive 0、+0.4 / +18.6 / +0.1、−0.1 / +21.0 / 0 など）。配賦が決まるまで production の表示計算へ総増分を繋がない。
   - 残差 ≤ 0.2 pt の由来（量子化・青の実効値の再確認）と、青の乗算型が一般仕様かどうかは別課題。
   - 水着フブキとの相関は観測として残すが、特定パッシブを原因とする仮説は撤回済み。次の実験は事前にカードID・開花・role・provenanceを監査し、変更要因を最小化する。
