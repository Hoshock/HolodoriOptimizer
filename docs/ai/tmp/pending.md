9. **ページ最下部の余白が大きく増えることがある（2026-09-02 報告・2026-09-05 再発）**
   iPhone Safari でフッターの下に約 310 CSS px の空白が現れる（2026-09-05 スクリーンショット。「気づいたらこうなっている」ので操作の直後ではない）。空白の高さが iOS キーボードとほぼ同じで、モーダルのスクロールロック（body を position:fixed）中に検索欄でキーボードを出すと Safari がレイアウトビューポートを押し上げて文書の下に空白を足す既知の挙動と一致するため、`useModalChrome.ts` に対策を入れた（html/body の overflow hidden・入力欄の focusout でスクロール 0 に戻す・解除時に blur してから復元、再描画後にも復元）。開発環境に iOS がなく実機未検証 — ユーザーが再発しないか確認する。再発したら「直前に検索欄を使ったか」「どのモーダルを閉じた後か」が切り分けの材料。
