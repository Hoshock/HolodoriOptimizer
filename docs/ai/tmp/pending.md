## 表示ユニットスコア

1. **赤スコアサポートの一般式**
   - 旧 `X × 基準候補秒 / 200` は追加実測で棄却済み。
   - 水着フブキ 0凸を含む編成だけ +24 の効きが約 18.6〜19.1 pt と低く、恒常フブキでは約 20.5〜20.7 pt。
   - 次は水着フブキを固定し、キュート対象のパッシブ・スコアサポート成立だけを変えられる比較を優先する。
   - 正典: `docs/human/display-score.md`、Golden: `docs/human/repro/display-score-20260912.md`。
2. **5 カテゴリの内部式**
   - Costume の算出式。
   - 赤増分の Costume / Board / Passive への配賦。
   - Passive スコアサポートの対象・合成位置。
   - 青の発動率 UP / 発動頻度 UP の Board 換算。
   - Costume / Board / Passive の厳密な 0.1% 量子化。
   - 黄の式は Costume を含む 5 カテゴリ構造へ実装を合わせる必要がある。
3. **SP の残差**
   - 発動率 UP を含むケースで残る ±0.5pt 前後のずれを説明する。

## パラメータ・ボード

4. **赤割合効果の丸め単位**
   - パラメータ合計で 1 回丸める現実装は一部差分で ±2 程度ずれる。メンバー×パラメータ単位の丸め候補は観測が不足。
5. **コネクト効果**
   - 範囲形の網羅性、重複時の合成、割合・‰ の丸め、黄 / 赤 / 緑への適用、5凸時の扱いを実機で確認する。
6. **開花途中の実数値**
   - 未確認カードの `bloomVariants` と、2凸前後から素値を復元するときの ±1〜2 の誤差を追加観測で解消する。
