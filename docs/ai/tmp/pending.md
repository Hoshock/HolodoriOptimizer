## 権利・公開まわり

1. **ガイドライン原文の直接確認(2026-08-31・要人間確認)**
   開発環境のネットワーク制約でカバー社・hololive Dreams 公式サイトへ直接アクセスできず、二次創作ガイドライン・利用規約・配信ガイドラインの要点は検索要約ベース。[docs/human/rights-policy.md](../../human/rights-policy.md) の 3 つの URL を人間が直接確認し、特に「攻略ツール・ファンサイトが二次創作ガイドラインの適用範囲に入るか」を確定させたい。
2. **初期データの出典の妥当性(2026-08-31・要ユーザー確認)**
   ★5 カード・楽曲の初期データは、先行公開ツール Ahoge0510/holodri-optimizer が HTML に内蔵する公開データを**事実情報として**転記して構築した(出典は `src/data/meta.json` に明記。コードは一切流用していない)。カード名・数値・効果は著作物性が弱い事実情報でありリスクは小さいと判断したが、方針としてこれで良いかユーザーの確認を仰ぐ。また今後、ゲーム内表示との抜き取り照合(数枚)を行いたい。

## 設計まわり

   攻略サイト本体がネットワーク制約で閲覧できず、(a) ★3・★4 のカード一覧(カード名・種類数・タイプ — 現状は「1 ホロメン 1 枚」と仮定しホロメン名表示)、(b) ブルーダイヤ販売パックの全ラインナップ(現状は 8,200 個 = 9,800 円の 1 種のみ収録)が未確認。ユーザーがゲーム内ショップ・Game8 の一覧([★4](https://game8.jp/hololive-dreams/800911) / [★3](https://game8.jp/hololive-dreams/800912))を確認して共有してくれれば反映できる。
6. **SP・アクティブ期待値計算の実測パラメータ（2026-09-01）**
   未確認の値: (a) 発動確率「低/中/高」の実数値、(b) SP の曲あたり発動回数、(c) ボード青マスのスキル頻度の効果量・ホロメンあたりのマス数、(d) スコアサポート・SP がライブスコアへ効く式。**当面は仮定値で実装してよい**（2026-09-01 ユーザー回答「4は不要」）。仮定値は定数ファイルに隔離して「試算」と明示し、実測値が判明したら差し替える。

   段階仕様（1凸=アクティブ / 2凸=パラメータ / 3凸=SP / 4凸=パッシブ / 5凸=コネクト）は 2026-09-01 にユーザーが正しいと確認済み。実数値はカード固有で非公開のため、当面は `src/data/bloom.ts` の仮定倍率（パラメータ ×1.05・スキル ×1.1）で割り戻して試算する（2026-09-01 ユーザー指示「推定値で」）。実機で確認できたら差し替えたい値: (a) 各スキルの段階別の実文言（`bloomVariants` へ入力）、(b) 2凸のパラメータ上昇量（%）、(c) 表示中の stats がどの開花段階の値か（現在は開花最大とみなしている）。

9. **ページ最下部の余白が大きく増えることがある（2026-09-02・再現条件待ち）**
   ユーザー報告。開発環境の Chromium ではモーダルの開閉前後でページ高さ・スクロール位置が完全に戻り再現しない。第一仮説は iOS Safari で、モーダル中の本体固定（`useModalChrome` の `position: fixed`）とキーボードの開閉が重なると閉じた後に下へ空白が残る既知の癖。どの操作の後に出るか（モーダル閉 / キーボード使用後 / さがす後 / おかゆモード ON 後）と、iPhone Safari かホーム画面アプリかをユーザーに確認中。キーボード起因なら固定方式を `overflow: hidden` ベースに切り替える。
