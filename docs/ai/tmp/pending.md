## 権利・公開まわり

1. **ガイドライン原文の直接確認(2026-08-31・要人間確認)**
   開発環境のネットワーク制約でカバー社・hololive Dreams 公式サイトへ直接アクセスできず、二次創作ガイドライン・利用規約・配信ガイドラインの要点は検索要約ベース。[docs/human/rights-policy.md](../../human/rights-policy.md) の 3 つの URL を人間が直接確認し、特に「攻略ツール・ファンサイトが二次創作ガイドラインの適用範囲に入るか」を確定させたい。
2. **初期データの出典の妥当性(2026-08-31・要ユーザー確認)**
   ★5 カード・楽曲の初期データは、先行公開ツール Ahoge0510/holodri-optimizer が HTML に内蔵する公開データを**事実情報として**転記して構築した(出典は `src/data/meta.json` に明記。コードは一切流用していない)。カード名・数値・効果は著作物性が弱い事実情報でありリスクは小さいと判断したが、方針としてこれで良いかユーザーの確認を仰ぐ。また今後、ゲーム内表示との抜き取り照合(数枚)を行いたい。

## 設計まわり

6. **SP・アクティブ期待値計算の実測パラメータ（2026-09-01）**
