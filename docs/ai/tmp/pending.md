## 表示ユニットスコア

3. **スコアサポート（赤・リーダー衣装）のカテゴリ配賦**
   - 総増分は赤・リーダー衣装とも `支援/100 × E_blue(乗算)` が強い推定（`docs/human/display-score.md`「現在最有力の一般則候補」「リーダー衣装のスコアサポート」。クロニー 60% の K1〜K4 で RMSE 0.11）。支援 3 種（リーダー衣装 / 赤 / パッシブ）は加算合成 `up × (1 + L + X + P_i)`（K6 と水着フワワ 10 行で乗算合成を棄却）。production は旧候補秒率式を既知の近似として残し、配賦が決まるまで総増分を繋がない。
   - 青なしの negative control K5 / K6 では、パッシブ支援の有無によらずリーダー支援は全量衣装欄（Δボード = Δパッシブ = 0）。L × P 単独の相互作用は 0。配賦異常の起点は青。
   - 編成全体の逐次 marginal 6 順序、秒 × 候補単位の 5 ルール（`displayScoreSourceAttributionExperimental.ts`）、Shapley（青を頻度 / 発動率に分割）はすべて反証。最良は p0Only（衣装 RMSE 1.9、K2 −3.6）と C*（RMSE 1.3、K1 / K3 / K4 ±1.5）で、K2 型（頻度による窓ずれ）と K1 / K3 / K4 型（パッシブ支援あり）を同時に合わせる候補がない。
   - **非 native カテゴリの共通 scale（2026-09-13、現コーパスでは確定扱い）**: 1 つの source だけを変えた matched pair では、native（リーダー衣装 → 衣装 / 赤 → ボード / パッシブ → パッシブ）以外の 2 欄が共通倍率で scale する。表示 0.1 の量子化込みで、2 欄とも情報を持つ 11 件（リーダー K1 / K3 / K4、赤 8 行）すべてで区間が空でなく、反例なし。oracle の分け方はリーダー最大 0.134 / 赤最大 0.059。対照（全部を 1 欄へ、native の取り違え）はいずれも棄却。`displayScoreCategoryRedistributionExperimental.ts`。
   - **残る課題は raw weight の式**。`C = λW_C / B = λW_B / P = λW_P`（λ は合計から決まる）という共通 normalization は上の不変量と整合するが、1 組の matched pair からは同値なので機構としては未確定。既存の衣装候補族 436 個を `W_C` として入れ直す oracle-baseline stage では最良でも 3 欄 RMSE 2.42（成功条件 0.2）。oracle が要求する ΔW_C は K1 18.10 / K2 32.73 / K3 18.56 / K4 18.75、青なしの K6 は 44.30。
   - **source 分離型 projective weight（2026-09-13）**: `(C,B,P) = T × W/ΣW`、`W_C = (L/100)H_C` / `W_B = W_blue + (X/100)H_B` / `W_P = H_P`。gauge 非依存の比は支持される — `H_B/H_C` は E_blue(乗算)/p0Only kernel で RMSE 0.031、`C/(L·P)` は L=25 と L=60 で共通部分が空でない、`B/C` は赤 X に affine（傾き 0.054〜0.056）。`H_P` は静的が最良で、供給側の確率を掛けない gated 版は K6 が棄却。完全予測は primary 32 点で 衣装 0.65 / ボード 0.68 / パッシブ 0.17。`displayScoreProjectiveWeightExperimental.ts`。
   - **残るボトルネックは `W_blue`**。逆算値 K1 24.43 / K2 19.91 / K3 14.27 / K4 19.18 に対し `E_blue(加算) − H_C` は K1 +0.71 / K2 +0.06 / K3 +3.51 / K4 +3.68。残差は 水着フブキ 0凸（`reconstructed-observation`）を含む 8 点に集中し、外すと 3 欄とも 0.21 以下。`W_blue` の式か 水着フブキ 0凸 の入力のどちらかを切り分けるのが次の課題。
   - パッシブ側の raw weight 候補（青の純増分 / 静的パッシブ）は和では λ = 1 と整合（比 1.001〜1.028）だが、欄ごとの λ が 1.8〜2.9 倍ずれるので `W_B` / `W_P` としては棄却。赤側は `ΔX/100 × E_base` が 10 行中 7 行で要求区間の中、3 行で外。
   - パッシブ欄: 総量（ボード + パッシブ）は対象への静的支援で ±0.2 だが、青があるとパッシブ欄は静的値の 40〜60%（gated 値に近い）で残りがボード欄、K6（青なし）は全量パッシブ欄。分割規則は未解明。production の gated 型は総量で 0.6〜1.9 不足（既知の近似）。
   - exploratory 行（恒常みこ Lv 約 20）は総量モデルで約 +1.0 の未説明差。Lv・スキル Lv の再確認まで fit に入れない（恒常みこ 0凸の 4 スキルは `estimated-from-max` のまま）。配賦異常は低開花値の入力訂正（2026-09-12 / 13）では変わらず、入力の推定ミスでは説明できない。
   - 残差 ≤ 0.2 pt の由来と、青の乗算型が一般仕様かどうかは別課題（K2 のリーダー支援なしボード欄 15.3 は乗算型 15.28 に一致し、production の加算型 18.9 と合わない）。
   - 次の観測は同ドキュメント「秒 × 候補単位の配賦ルール」末尾の 1 件（クロニー / 恒常みこリーダー × 恒常そら0 / アキ0 / スバル0 / フレア0 / 水着フブキ0。供給側だけに青がある編成）。
