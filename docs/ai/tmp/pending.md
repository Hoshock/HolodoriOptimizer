4. **3 欄（衣装 / ボード / パッシブ）の配分の重み `W_C` / `W_P`**
   - 材料は 青 0・赤 0・黄 0・曲なしの 12 編成（リーダー = 典獄クロニー 60%）と、同じメンバーでリーダーだけ
     恒常みこ 0凸（支援 0）に替えた baseline 6 件。観測は
     [repro/display-score-20260915-costume.md](../../human/repro/display-score-20260915-costume.md)、固定は
     `displayScoreCostumeQuantization.test.ts`。
   - **【決着】量子化の位相**: 衣装欄は **アクティブ欄との差** `ceil(A + C) − ceil(A)`、パッシブ欄は **素の切り上げ** `ceil(P)`。
     欄ごとの規則（独立 / 差分 × 切り上げ / 切り捨て / 四捨五入）と累積順序を総当たりして、18 個の実機値を
     すべて満たすのはこの 1 通りだけ。**配分の式に依存しない**（取り分 φ を総当たりして両立する φ の有無だけを見る）。
   - **【確定】総量 `T = 0.60 × A + ΔP` は正しい。** アクティブ欄 12/12、みこ側のパッシブ欄 6/6、SP 欄・合計・
     ユニットスコア（編成 2 の 555096）も一致。対象選抜も みこ側のパッシブ欄で決まる（S2 だけ 2 通り残るが結論は不変）。
   - **【確定】カードの Lv はスキルの数値を変えない。** Lv が効くのはパラメータと、それを介した「N人」の対象選抜だけ。
   - **残っているのは配分の重み 1 箇所。** その位相のもとで実機から `ρ = W_P / W_C` を逆算すると、
     現行の `W_P = ΔP` は 8 件中 6 件を外す（1 / 2 / 3 / S2 / S3 / S4）。実機はリーダー支援を足すとパッシブ欄を動かすが、
     production は `W_C = 0.60 × H_C` と `W_P = ΔP` が projective 配分で約分されるため動かない。
   - **棄却済み（自由係数なしで機械比較）**: 定数倍 `k × ΔP`（編成 1 が `k>1`、S3 が `k<0.9`）/ メンバーごとの `g(s)`
     （編成 2 は足りず S4 は多すぎる）/ `ΔP`・`ΔP/A` の単調関数（編成 2 が S3 より 1 に近い）/ 逐次 marginal・単独・Shapley
     （カーネルが静的倍率に厳密線形なので各 source の寄与へ戻る）/ 競合の分母に静的倍率を入れたカーネル /
     取り分を別の量へ替える形（一様・スコアUP%・発動確率・正規化なしの寄与・発動候補秒・周期比）。
   - **いちばん効く反証は S2 → S3**（奏 を リス へ 1 枚差し替え。支援を受ける 2 人は同じ）。
     実機が要求する「その 2 人の重みの割合」は 0.4007 → 0.3971 と**下がる**のに、モデルの取り分は
     0.4171 → 0.4431 と**上がる**。配分の重みは「競合で正規化した取り分」ではない。
   - **次の観測**: 12 件すべてリーダー支援が 60% なので観測量は比 `ρ` だけで、`W_C` と `W_P` を分離できない。
     **同じメンバーで支援 25% のリーダー**（ぺこら 0凸 / フレア 2 / わため 2。条件つきなのでタイプ構成に注意）を
     **S3（ずれ最大）と S1（ずれなし）の 2 編成**で取る。`W_C ∝ 支援 %` なら `ρ` は 2.4 倍になる。
     対象を絞って重みを直接測る編成は、衣装が全カード「全員」・パッシブが全カード「タイプ 2 人」なので作れない。
   - 編成を選ぶときは **`A`・`0.6A`・`1.6A` の 3 つすべて**が 0.1 の境界から離れていることを条件にする
     （2026-09-15 の 編成 1・3 は `1.6A` が境界から 0.0005 しか離れず単独では判定に使えなかった）。
   - コーパス 153 列は判別に使えない。青・赤が入っていて raw 自体がまだ合っておらず、どの位相でも衣装欄は最良 27/51。
   - **production は当面 現行のまま**（位相だけ直しても配分が合わないので、まとめて差し替える）。
   - 項目 3 との循環は向きが変わった: 位相が決まったので、表示値から raw の区間を作る操作は確定した。
