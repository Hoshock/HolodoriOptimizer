## UI の方針（2026-09-09・要ユーザー判断）

13. ~~アイコンの「押せる感じ」の方針~~ **却下で決着（2026-09-10）**
    390px のサンプル画像（案 A 器のみ / 案 B 器 + 薄い浮き / 案 C 押下で沈む、ライト・ダーク）を出したうえで「却下し以下を実装」となり、別件（発動頻度の最適化）へ移った。**この件はこちらから蒸し返さない**。判断の材料として残す事実: ダークモードでは影が地に乗らないので「浮き」は合図にならず、効くのは器（面 + 罫線）のほう。現状の押せる合図は「面のある器 = 押せる / 地なし細線 = 情報」で、器のないアイコン（お気に入りの星）は例外のまま。
