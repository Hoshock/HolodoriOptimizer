# 未整理のルール候補 (induction 記録先)

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- 選択枠・プレースホルダは、空・充填・選択解除のどの状態でも枠の寸法が 1px も変わってはならない(レイアウトシフト禁止)。想定 glob: `src/**/*.{vue,css}`(2026-08-31 UI フィードバック「絶対に枠の大きさに差分が出てはいけない。きもちわるい」)
- 機能的な意味を持たない装飾・記号(例: 選択済みカードのチェックマーク)を付けない。状態は枠・色など既存の視覚要素で示す。想定 glob: `src/**/*.{vue,css}`(2026-08-31「チェックマークに意味はないので削除」)

- 同種のバッジ・ラベルは幅を固定し、文字はバッジ内で中央揃えにする。並ぶ要素は縦・横の線(グリッド)を揃える — 可変幅の名前の後ろにバッジを置いて開始位置がずれる、などを許さない。想定 glob: `src/**/*.{vue,css}`(2026-08-31「バッジ幅を合わせたい」「縦の線揃ってない」「縦と横の線が揃っていない。デザインの基本がなってない」)
- 冗長な文字情報を置かない: 見出しやバッジの背景色で伝わることをテキストで繰り返さない(例: 枠名「リーダー」、タイプ名「ピュア」の文字表記)。プレースホルダの空状態は中央の 1 行指示のみにする。想定 glob: `src/**/*.{vue,css}`(2026-08-31「余計な文字が多すぎる」「文字列は不要」)
- スキルの表記順は常に SP → アクティブ → パッシブ。(2026-08-31、モーダル内の順序違いを指摘)
- バッジ+複数行テキストの行では、バッジが列として全行ぶんの高さを占有し、折り返したテキストがバッジの下に食い込んではならない(2 カラム構成にする)。想定 glob: `src/**/*.{vue,css}`(2026-08-31「折り返しの文字列がバッジの下まで食い込むのが不快」)
- iOS Safari は数字列を電話番号と誤検出して青いリンクにするため、`<meta name="format-detection" content="telephone=no">` を必ず入れる。想定 glob: `index.html`(2026-08-31「計算結果の文字色が青」の原因)

## Cases

- 2026-08-31 UI: リーダー選択はボタンではなく「見出し→説明文→メンバー枠と同形のプレースホルダ」の並びに統一せよとの指摘。読み取れる好み: 同種の操作(カード選択)は見た目も操作も同形に揃える。
- 2026-08-31 UI: 一覧(結果リスト)に数値の 1 行詳細を並べるのは不要、詳細はタップ→モーダルで表・グラフ・文章として見やすく出せとの指摘。読み取れる好み: 一覧は識別に必要な最小限、詳細は明示的な操作の先に置く。
- 2026-08-31 仕様: 探索件数 topN はデフォルト 5・上限 100。カードの数値・スキル効果はレベルと開花(かいか)で変わるため、表示にはその前提(どの Lv/開花段階の値か)を明示する。
- 2026-08-31 UI 第 6 弾: ピッカーのタイルは普段枠線なし・選択時のみ太枠。タイルは 1 行 1 枚でスキル情報(リーダー時=衣装、メンバー/除外時=SP・アクティブ・パッシブ)を表示し、合計値の数字は出さない。「持っていないカードを除外する」→「カードを除外する」。結果の固定バッジは名前のすぐ右(右端すぎない)。手順の説明文(リーダー・メンバー選択の下の文章、結果のタップ案内・試算値注記)は削除し、試算値の話は脚注(フッタ)に集約。見出しは「メンバーを選ぶ (おまかせでもOK)」。読み取れる好み: 説明文で補うのではなく UI 自体に情報を語らせ、本文コピーは最小に。
- 2026-08-31 UI: スキル本文のような日英混在テキストは `word-break: break-all` で自然な位置で改行させる(「55%UP(」等の英数字トークンの手前で早折れして不自然な改行になるのを防ぐ)。詳細モーダルは問題なし=適用済み扱い。
- 2026-08-31 UI 第 5 弾: 選択画面(ピッカー)のカードもタイプ名テキストでなく背景色で表す。結果一覧はタイプバッジを廃してタレント名の文字色(タイプ濃色)で判別、各メンバーは名前+カード名の 2 行、固定バッジは左側で 2 行ぶんを占有。読み取れる好み: 同じ情報表現(タイプ=色)を全画面で貫く。
- 2026-08-31 UI 第 4 弾: 充填済みカード枠はタイプ色の淡背景で表現し、名前を大きく左上・カード名をその下に小さく。リーダー枠に数値は不要、スロットの合計値も不要。結果一覧の 4 位以降の順位は白背景+枠線の円。グラフは表で表現できている情報に重ねて置かない(意味のないグラフ禁止)。読み取れる好み: 情報は 1 回だけ・最小限で、視覚(色・大きさ)に語らせる。
