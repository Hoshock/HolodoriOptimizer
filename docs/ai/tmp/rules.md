# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- **ゲームの仕様（ボードのマス配置・接続線・マスと効果の対応・値）は実機確認だけを確定とする**（2026-09-07 ユーザー指示、緑ボードの引き継ぎ）。公開の攻略情報や他ツールの解釈は仮説と確認箇所の絞り込みにだけ使い、確認前の内容を「確定」と書かない。位置・効果・接続線は別々に検証する（青では他の解釈をそのまま写した位置と効果の対応が一部違っていた）。想定 glob: `.claude/skills/parameter-calculation/**`、`src/data/*Board.ts`、`docs/human/game-spec.md`
- **解析由来のデータは参考程度にとどめ、必ず実機で確認する**（2026-09-07 ユーザー指示「解析由来のデータだけは参考程度で、実機で確認必ずする」）。仮説と確認箇所の絞り込みに使うのは可、リポジトリに書くのは実機で確認できた項目だけ（未確認は「未確認」と明記）。ADR-002 の「依存しない」とは矛盾しない（データの出典にはしない）。想定 glob: 上と同じ

- **表・一覧の行は固定順で全項目を常に出す**（2026-09-07 ユーザー指摘「選ぶ順によって上から並ぶ順が変わるのきもい。固定順で全てあらかじめ出しておくこと」— 緑ボードの効果表で、解放した報酬系だけを解放順に出していた）。選択順・解放順で行が増減したり並びが変わったりしない。値がないときは +0 などの空値で行を残す。想定 glob: `src/**/*.vue`

## Cases

- 2026-09-07 緑ボードの引き継ぎメモは、情報源の優先順位に解析由来のマスターデータを置いていた（実機 > リポジトリ内の実機確認済み > マスターデータ > 攻略サイト）。ADR-002 は解析ダンプ由来の情報に依存しないと決めているため、リポジトリには仮説としても書かず、仮説メモはリポジトリ外に置いた。→ 同日ユーザー判断「参考程度で、実機で必ず確認」で解消（上の Rules に吸収）。ADR-002 の改訂は不要と判断（出典にはしないため）
- 2026-09-07 緑ボードの実機確認を「各マスの文言を中心から辿った順に」「所属向けマスの個数・位置・値を 3 名で」と依頼したところ「何を確認したいのかがよくわかってない」。実機確認の依頼は、開く画面・見る（タップする）場所・答えてほしい形（番号つきの図と、番号 → 文言の表）まで具体的に書き、抽象的な項目名だけで頼まない
- 2026-09-07 緑ボードのマス記号を「所」「報」で出したところ「所ではなくグループのグ、報酬は酬」。ゲーム内表示にない記号を新しく作るときは、ユーザーに候補を先に見せる（読みの 1 文字目や意味の中心の字が好まれた）
