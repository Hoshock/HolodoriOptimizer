- 2026-10-08 / リソースの画面: 「キューブとかの入力ダサいからいい感じの UI にして」— 色の見出し + 設定行 × 8 を、色ごとのカード（色の淡い地・キューブのアイコン・大きな値）の 2 列へ。読み取れる好み: 同じ形の行を縦に何度も繰り返す入力は、まとまり（色）ごとのカードにして一目で見渡せるようにする。
- 2026-10-08 / 計算の高速化の提案: 案 A（評価を軽くする）を出したところ「A は具体的になにが変わるんだ」、次に「覚えておくというのはどういうこと？」と続けて聞かれた。読み取れる好み: 提案は、ユーザーから見て何が変わるか（画面・結果・待ち時間）を先に言い、中身の変更は「いまの手順 → 変えたあとの手順」の具体例で示す。内部の言葉（覚えておく・キャッシュ・分担）は、どこに・いつまで・何をもとに覚えるかまで言い換える。
