# 未整理のルール候補 (induction 記録先)

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- ヘッダなどの常時表示領域は、タブ・モード切替で寸法(高さ)が変わってはならない。切替内容に依存するもの(手順リスト等)をヘッダに置かない(想定 glob: `src/**/*.{vue,css}`)— 2026-08-31 第 8 弾「ヘッダの手順は不要。タブ切替でヘッダの高さが変わって気持ち悪い」
- パネル内の主要操作ボタンは secondary(白背景)も含めて全幅・中央揃えにする。primary との階層は背景色(濃色/白)で分ける(想定 glob: `src/**/*.{vue,css}`)— 2026-08-31 第 8 弾「カードを除外するは中央揃えに。ベスト編成を探すと同様。ただし背景は白色」
- スキルの発動状態はテキストバッジ(「反映中」「条件未達」「未反映」)ではなく、発動=通常表示/不発動=行のグレーアウトで表す。「未反映」の状態は UI に設けない — データ側を 100% 構造化して状態自体をなくす(想定 glob: `src/**/*.{vue,css}`)— 2026-08-31 第 9 弾

## Cases

- 2026-08-31 / 機能追加(所持カードモード)の指示時 / 「見た目に関しては既存を尊重すること」— 新機能を追加するときは新しいデザインを持ち込まず、既存コンポーネント・トークン・デザイン言語(タブならピッカーのセグメンテッドコントロール等)を踏襲する、という好みが読み取れる(想定 glob: `src/**/*.{vue,css}`)
