# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- **ボード効果の割合はゲーム内どおり小数第 1 位まで（+4.0%、+20.0%、+0.5%）で、全色で揃える。整数の「+4%」「+20%」を混在させない**（2026-09-08「小数第一位で .0% までつけること。他の色のボード効果も表記揺れしてるので直す」— 赤の効果候補表で指摘。青の発動率 / 発動頻度・黄のホロワーク報酬が整数表記だった。実装は `formatBoardPercent` / `formatBoardPermil`（`src/data/boardGraph.ts`）。想定 glob: `src/components/BoardSheet.vue`, `src/data/*Board.ts`, `.claude/skills/parameter-calculation/**`）

## Cases

- 2026-09-08 赤ボード（BoardSheet）: 「大マスが隣り合う時接続線が狭すぎる」→ 大マスが隣り合うステータス系エリアだけ間隔を 34 → 40px にし（「それ以外は他の色の線の長さと一緒でいい」）、はみ出す面は SVG ごと縮める。読み取れる好み: 部品同士の間の線・余白は「あることが見える」幅を確保する（1〜2px の隙間は不可）。想定 glob: `src/components/BoardSheet.vue`
- 2026-09-08 赤ボードの 3 エリア: 「切替に別トグルを用意したくない。スマートな UI を。スワイプ切替は嫌。名前も左上右にして」→ セグメントを撤去し、枝が画面の外へ続く位置に出口（◀左 / ▲上 / 右▶）を描いてタップで移動。読み取れる好み: 画面内の部分表示の切替は、内容の空間的な続きを示す要素で行い、独立した切替部品を増やさない。名前は意味（ライフ / ステータス）でなく物理的な位置（左 / 上 / 右）。スワイプは横送りのカルーセル専用。追記: エリアを移ったらスクロールを一番上へ、「すべて解放 / 解除」は表示中のエリア単位（2026-09-08）。注釈に「リーダー自身には効かない」のような当然の否定は書かない。想定 glob: `src/components/*.vue`
- 2026-09-08 表の折り返し: 「表の中で全員のセンスが 2 行になってるところとか、効果名が 2 行になってるのを直す」「結果の表で後があるせいで 2 行になるので後削除」→ 値セルと行見出しは nowrap、長い効果名は短く（歌唱者条件の〜）、結果詳細の列見出しは「〜後」を外す。読み取れる好み: 表のセルは 1 行。収まらなければ文言を削る（文字を小さくするより先に）。想定 glob: `src/components/*.vue`
