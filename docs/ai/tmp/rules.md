# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- アカウントの状態（持っているカードと開花段階・ホロメンボード・お気に入りユニット）は Step 0「アカウント」にまとめ、そこでだけ変更する。入口は横並びの 3 ボタン「ホロメン / メンバー / ユニット」で件数は出さない（「枚数表示とかいらん」— ヘッダの件数削除と同種 2 回目）。探索の条件（さがす対象・除外・枠・曲・しぼりこみ）と混ぜない。ホロメンボードはカードでなくホロメンに属するので入口もホロメン一覧から（2026-09-06 ユーザー指示「アカウントの情報を入れる場所をステップ 0 にまとめよう」「開花ピッカーもステップ 0 でしか選択できないように」。カードタイル上のボード入口は却下）。想定 glob: `src/components/*.vue`
- 計算の前提になる値を変更できない画面（メンバーピッカー）では、値をアイコンだけで見せる（開花アイコンのみ、± なし — 2026-09-06）。想定 glob: `src/components/*.vue`

## Cases

- 2026-09-06・ホロメンピッカー: 「ソートオプションは記憶したい。閉じると五十音順に戻る」→ いったん localStorage に保存したが「画面更新したときにはソート順はリセットでいい」で取り消し。並び順も絞り込みと同じく、モーダルを閉じても保持・再読み込みでリセット（ui-design.md「絞り込みは保持」の既存規則がそのまま並び順にも当たる — 保存層は増やさない）
- 2026-09-06・青ボード UI: マス内の記号は「全」→「All」→「A」、割合マスの「P%」→「P」に 2 段階で削られた。読み取れる好み: 記号は英字 1 文字まで、種類の差（割合か固定か）は文字でなく大きさ・形で表す（想定 glob: `src/**/*.{vue,css}`）
- 2026-09-06・青ボード UI: ユーザーの ASCII 図から座標を写して描いたら、上下が逆・5 マス塊の左右が逆だった（実機を見たユーザーが気づいた）。読み取れる教訓: 空間配置の仕様を図から写すときは、実装前に向きの基準（上下・左右・どちらから見るか）を一言確認する。コネクトマスは「点線の円」でなく実機どおり「丸角の四角」、マスを繋ぐ線は縦横とも同じ長さ（正方格子）— 実機の形の再現を求める
- 2026-09-05・開花ステッパー: 「± を連打すると iPhone でズームされる。この連打ではズームされないように」→ 対策はダブルタップズームの抑止（`touch-action: manipulation`）で、ボタン全般に適用した。読み取れる好み: 連打・トグル操作でブラウザ既定のジェスチャ（ズーム・選択）が割り込むのは不具合として扱う（想定 glob: `src/**/*.{vue,css}` — ui-design.md 実装ノートの iOS Safari 項の隣）
