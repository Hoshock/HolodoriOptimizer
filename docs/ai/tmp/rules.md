# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- 一覧（カードピッカーのリーダー・メンバー）はあいうえお順（読み）で並べる。同じホロメンのカードはカード名（サブタイトル）の読みであいうえお順。文字コード順（英字→カナ→かな→漢字）は不可（2026-09-05 ユーザー指示。想定 glob: `src/components/**`, `src/ui/**`）。
- 読みは `holomen.json` / `cards.json` の `reading` にひらがなで手入力し、並び順・検索にだけ使う（表示しない）。英字はカタカナ読みをひらがなにする。長音「ー」は比較時に直前の母音へ正規化（想定 glob: `src/data/**`）。

- 一覧の部品（カードタイルなど）の高さは内容量で変えない — 1 行でも 3 行でも同じ高さ。複数行の文章は最大行数（効果テキストは 3 行）ぶんの固定高にそろえ、短い文は余白で埋める。複数行の文章を動かす（縦送り）のは不可（「きもすぎる」）。動かしてよいのは 1 行固定の曲名・アーティストの横スクロールだけ（2026-09-05 ユーザー指示。想定 glob: `src/components/**`）。
- 固定高で行数を増やすときは行方向の余白（行間・行同士の隙間・名前との間）を詰めて、部品全体を伸ばしすぎない（2026-09-05 ユーザー指示「少し行方向の余白を減らせ」。想定 glob: `src/components/**`）。
- はみ出しの判定は部品が置かれた場所ごとに実測する。ピッカー（シート）とメイン画面では幅が違うので、同じ文言でも一方だけ動くことがある（2026-09-05 ユーザー注意。想定 glob: `src/components/**`）。

## Cases

- 2026-09-05 カードタイルの効果テキスト: 2 行クランプで末尾が「…」になるカード（戌神ころね「密林を舞うワイルドサマー！」の衣装スキル 52 字）をユーザーが指摘。3 行まで伸ばす案は「高さが変わるのは嫌」、2 行固定高で縦に送る案は「きもすぎる」と差し戻し → 全カードを 3 行ぶんの固定高にし、行間 18→16px・行の隙間 4→2px・名前の行間も詰めて高さの増分を抑えた。読み取れる好み: 効果の原文は切らずに読めること、部品の高さは揃えること、複数行の文章は動かさないこと。
- 2026-09-05 曲ピッカー・Step 5 の曲名・アーティストがはみ出す場合は、ユーザー指示で「ゆっくりスクロールするアニメーション」にし、収まっているときは動かさない（省略記号の静止表示ではなく全文が読めること）。効果テキストとは別の解決（1 行の固定高を守るため）。同日、往復（alternate）で実装したところ「そうじゃない。スクロールし切ったら速度上げて先頭に巻き戻し」と差し戻し → 先頭停止 → ゆっくり末尾へ → 末尾停止 → 速く先頭へ巻き戻し、の一方向ループに変更。読み取れる好み: 文章は常に先頭から読める向きで流れること（逆走で読ませない）。
