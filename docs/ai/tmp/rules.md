# ルール候補

## Rules

- 状況を説明する文（「〜は 2 枚とも使っています。どこから外して持ってきますか？」の類）を UI に足さない。数字や構造（残り 0・選んだ行が広がる）で伝わるなら文は置かず、読み上げ用の aria-label に回す（2026-10-10「不要な文章はなるべく書かないこと」。`ui-design.md`「冗長な文字情報を置かない」の同種。glob 候補: `src/components/**`）。

## Cases

- 2026-10-10 ボードのコネクト効果の入力（`ConnectSheet`）: 右から出るサイドバーは「ここだけサイドバーにゅっと出てくるのも変」で中央のモーダルへ。さらにその上に倍率・警告の小さなダイアログを重ねる形は「モーダルの上にモーダルってキモい」。読み取れる好み: 出方を画面ごとに変えない / 中央のダイアログを重ねず、1 つの器の中で切り替える（glob 候補: `src/components/**`）。
