# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- **保存するのは入力だけで、そこから計算できる数値は保存しない** — 表示するときに最新の登録状態で計算し直す（2026-09-09 ユーザー指示「数値は登録した時点ではなく表示した時点で最新の情報で計算した値にする」。お気に入りユニットはカード ID の組み合わせだけを持ち、開いたときに現在の開花・ボード・メモリー・強化ボーナス・曲で評価する）。想定 glob: `src/storage/**/*`、`src/components/*.vue`
- **取り消しのきかない登録操作（上書き・解除）は確認モーダルを挟む**（2026-09-09 お気に入りユニットで上書き・解除の 2 箇所を同時に指示）。確認は全画面シートではなく中央の小さなカード（`ConfirmDialog.vue`。キャンセルは白・実行は `--action` の 2 ボタン）。想定 glob: `src/components/*.vue`

## Cases

- 2026-09-09 お気に入りユニットの入口: **結果パネルの右上の角にかかる星**（表示中の 1 件に効く）。未登録は輪郭だけ、登録済みは金色の面 + 登録番号で、押すと未登録なら 1〜10 の番号選び（2 行 5 列の星。登録済みの番号は色を変える）、登録済みなら解除の確認になる。読み取れる好み: 状態と 2 つの操作（登録・解除）を 1 つの記号に集約し、番号は視覚的なグリッドで選ばせる（一覧やドロップダウンにしない）。
