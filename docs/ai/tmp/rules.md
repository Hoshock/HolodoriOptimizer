# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- **派生カテゴリの値は表示済みの丸め値ではなく、表示に丸める前の raw 中間値から計算する**（想定 glob: `src/engine/displayScore*.ts`、`src/engine/optimize.ts`）。2026-09-11 の黄ボード: 黄 × (100 + アクティブ + パッシブ + SP) を表示済みの 77.0 / 2.3 / 46.0 から求めると 9.86% で丸め境界が合わず、raw から求めて最後に量子化すると 8 点そろった。ユーザー指示「必ず可能な限り既存の表示前 raw 値を使って計算すること」。
- **1 つの実機確定を、別の効果や別の未確定項目まで「解決済み」に広げない**（想定 glob: `src/engine/**`、`docs/**`）。黄がボード欄に入ると確定しても、イベントスコアボーナスの位置・ボード欄 / パッシブ欄の算出式・青の換算・赤の一般式・実ライブスコア・SP タイムラインは未確定のまま書く（2026-09-11 ユーザー指示「黄の今回の実測からこれらまで『解決済み』にしない」）。

（2026-09-10 の棚卸し 31 回目で `skills-convention` スキルへ 1 件昇格: **リポジトリ外の LLM に URL で渡すスキルは、行数を犠牲にしても 1 ファイルで完結させる**（段階開示の 150 行目標の例外）。30 回目で `ui-design.md` へ 1 件（スワイプで隠れた操作を出す UI を使わない）、29 回目で 2 件（外部へ渡す指示はスキルを指すポインタだけ / キーボードを出させない入力にはワンボタンの代替）、26 回目ぶんは `storage-compat.md` と `ui-parts.md` へ統合済み）
