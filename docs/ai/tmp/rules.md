# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- ユーザーがブラウザ（localStorage）に登録したデータは、機能追加・データ更新で読めなくならないようにする（2026-09-02 ユーザー指示）。具体的には: 保存形式を変えるときは旧形式を読む移行を書きテストで固定する（`src/storage/`）、未知の ID は捨てずに書き戻す、公開済みのカード・ホロメン ID は改名・削除しない（`src/data/published-ids.json` で凍結）。想定 glob: `src/storage/**`, `src/data/**`, `src/composables/**`

## Cases

- 2026-09-02 / おかゆモードの案内: 前提が満たされないときはエラー表示でなく「方針」をボタンのラベルで示す（所持ピッカーのボタンを「おかゆんを選んでください」に差し替え、リーダー・メンバー・実行は disabled）。読み取れる好み: 入力を止めるときは理由をラベル・disabled で構造的に伝え、赤いエラーメッセージを出さない。想定 glob: `src/components/**`
- 2026-09-02 / お遊び機能の入口: ページ最下部の一番右にアイコンだけを置きタップで発動。URL パラメータは作らず、状態は保存しない（再読み込みで解除）。読み取れる好み: 遊び要素は本線のフローに混ぜず、説明文も付けない。想定 glob: `src/App.vue`, `src/composables/**`
- 2026-09-01 / SEO・文言: ゲーム名の表記は「ホロドリ」を第一にする（ユーザー判断:「検索はホロドリが多いと思う」。正式名称 hololive Dreams は補足の括弧書きで）。権利ポリシーの「ホロライブ/hololive をツール名に冠さない」とも整合。同日、表示名を「ホロドリ最適化ツール」から「ホロドリ編成お助けツール」へ改名（SEO: 検索キーワード「編成」を名前に含める。ユーザー発案・確定）。想定 glob: `index.html`, `README.md`, `src/**`
- 2026-09-01 / CardPicker・SongPicker: モーダルを開いた瞬間に検索入力へ自動フォーカスしていたのを、シート自体（`tabindex="-1"`）へのフォーカスに変更。モバイルではキーボードが勝手に出て邪魔というフィードバック。読み取れる好み: テキスト入力への自動フォーカス禁止（キーボードはユーザーが入力欄をタップしたときだけ出す）。想定 glob: `src/components/**`（ui-design.md への統合候補）
