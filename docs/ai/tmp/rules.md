# 未整理のルール候補（induction 記録先）

housekeep 時に必ず昇格・整理される。書き方は induction スキルを参照。

## Rules

- 外部情報（コミュニティのマスターデータ・通信仕様の解析）は、実機画面では原理的に確認できない項目に限り 【外部情報】 と明示して記録してよい（「確定」とは書かない）。そのとき「効果の種別と値が分かること」と「ゲームの計算式がその値をどう換算するか」を必ず分けて書き、ダンプ由来の識別子・ファイル名・数値データそのものはリポジトリに持ち込まない（2026-09-09「『masterにこういうeffect typeがある』ことと『Score Bonus評価時にどう換算されるか』は分けて扱う」）。→ 2026-09-09 に `.claude/rules/game-facts.md` の 1 つ目の項へ反映済み（棚卸しで文面を確認する）
- 結果詳細のような入れ子の数値表示では、区分（総合力・スコアボーナス）の値を見出し直下の主数値として置き、表は内訳の行だけにする。表の最後の合計行・行頭の `+`・環に入らない括弧補足（入力した % 、赤ボードの内訳）はすべて置かない。区分の主数値は結果の主数値より一段小さく（22px / 700）、区分同士は同寸法（2026-09-09「その内訳表（最後の総合力の1行はいらない、また+はいらない、メモリーと強化ボーナスの括弧％も不要、ホロメンロードの赤の括弧も不要）」「スコアボーナスの数字(総合力の数字と同じフォントサイズ)」）。想定 glob: `src/components/Result*.vue`。→ 2026-09-09 に `.claude/rules/ui-parts.md`「数値の表」へ反映済み（棚卸しで文面を確認する）
