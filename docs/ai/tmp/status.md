### 読めること

- **確定（総合力）**: 歌唱者条件の P/T/S +10% は**ホロメンボード効果**に入り（+12,251）、その増分は**メンバー強化ボーナスの基準にも入る**（+367）。メンバーパラメータ・衣装・パッシブ・メモリーは不変。総合力 +12,618 はメンバー別表示値の差（+2,669 / +2,669 / +2,420 / +2,423 / +2,437）の合計と一致
- **既知のずれ（総合力）**: 現行モデル（パラメータ別の素値合計 × % を切り上げ）の OFF → ON の増分は +12,253（+2）。素値の ±1 の不確かさでは埋まらない。単位 × 丸め × 合算の 24 通りでは「メンバー × パラメータごとに四捨五入、23% で 1 回」だけが 09-08 の 41,190・メンバー別表示値とこの差分をすべて満たすが、幅が広い候補で根拠が 1 差分なので採用せず known diff として固定（`src/engine/power.ts` 冒頭）。単純に ceil(122,533 × 10%) = 12,254 と比べてはいけない（差は f(23%) − f(13%)）
- **確定（スコアボーナス）**: 歌唱者条件（スコアサポート +24）は アクティブ / SP を変えず、**ボード +20.9・パッシブ +0.2・合計 +21.1**（A → B、C → D とも）。現行モデルの「赤スコアサポートの増分は全部ボード欄、パッシブ欄は不変」は否定された。合計の増分も現行の (1 + X/100) 倍（基準 ≈ 92.4 で +22.2）より小さく、X 1 ポイントあたり 0.879（2026-09-08 の 0 → 28.1 では 0.868）。基準の正体（アクティブ候補のいる秒の割合 0.875 などが候補）とボード / パッシブの分け方（パッシブ側は X に対して頭打ち: +0.9 → +0.2）は 2 点では決まらず**未解明**（pending 12）
- **確定（黄）**: 黄 10% は赤 OFF / ON の両方で**ボード +22.7・合計 +22.7**、他 3 欄と総合力は不変（A → C、B → D）。黄の増分 黄 × (100 + アクティブ + パッシブ + SP) を raw で足す現行実装（`songBoardRaw`）はどちらの赤状態でも支持され、黄と赤歌唱者条件の表示上の効果は 0.1% の精度で加法分離する（交差する倍率は観測されない）。表示済みの 226.1 から計算すると +22.6 で届かないので、raw の 100 + アクティブ + パッシブ + SP は 226.0 を超えている（パッシブの raw は 3.05 以上）。ボード欄の量子化規則（切り上げ / 四捨五入）はこの 4 点でもどちらとも整合し、決まらない
- **確定（ユニットスコア）**: 4 点とも ceil(総合力 × (1 + 表示合計/100) × 2.03734) で 1 点単位に一致
- **現行モデルの値（青ボードは 09-08 の実効値）**: A 164.4%（1,664,278）/ B 186.5%（1,877,039）/ C 186.8%（1,805,276）/ D 209.0%（2,024,450）。ボード欄 39.6 / 61.7 / 62.0 / 84.2、パッシブ欄 4 点とも 1.8。アクティブ / SP は 4 点とも一致
