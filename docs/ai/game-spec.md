# ホロドリ ゲーム仕様メモ

実機観測などで裏付けられた変わりにくい仕様の概観。証拠状態は [evidence-policy.md](./evidence-policy.md)、カード出所は [card-data-provenance.md](./card-data-provenance.md)、表示スコア詳細は [display-score.md](./display-score.md)。

## ユニット

- リーダー1人とメンバー5人は別枠。
- **リーダーカードから試算に入るのは衣装スキルと、そのホロメンの赤ホロメンボードだけ**（ユーザー指示）。リーダーカードのP/T/S・開花段階・パッシブ・アクティブ・SPはどこにも入らない。衣装スキルの内容は開花段階で変わらない（2026-09-15 ユーザー実機確認）ので、リーダーの開花段階は値を動かさない。
- 赤ホロメンボードはリーダーにしたホロメンのものがメンバー5人へ効く。歌唱者条件などの発動判定もそのホロメン基準で、カードではなくホロメンの状態で決まる。
- 総合力はメンバー5人から作る。衣装スキルの発動条件もメンバー5人だけを数える（リーダー自身は数えない）。
- count人を選ぶ確認済み効果は、対象集合の素値P+T+Sが高い順から選ぶ。
- スキル文の「〜が2人以上で」は**発動条件**、「〜2人の」は**効果の対象人数**で、別のもの。カードデータも前者だけを `condition` として構造化する（アーニャ・メルフィッサのパッシブ「holoroが2人以上で自身の全パラメータが33%UP」は `condition: affiliationCount min 2` で holoro が1人なら不発。アイラニ・イオフィフティーンの「ピュアタイプ2人のテクニックが41%UP」は `condition: always` + 対象 `type: pure, count: 2` なので、ピュアの人数によらず発動する — 変わるのは効果の当たる人数）。発動の可否を数えるときに対象人数を条件と読み替えない。

## カードと開花

カードは ★5 と ★4 を持つ（★3 は実カードのデータなし。仮想ガチャの結果だけ）。レベル上限は **★5 が Lv80、★4 が Lv70**（★4 は外部マスタ由来・実機未確認 — [ADR-022](../adr/022-star4-cards-fixed-only.md)）。★4 はホロメン 54 人に 1 枚ずつ。

★5の確認済み強化段階:

| 段階 | 主な強化    |
| :--- | :---------- |
| 1凸  | Active      |
| 2凸  | 全パラ+10%  |
| 3凸  | SP          |
| 4凸  | Passive     |
| 5凸  | Connect関連 |

`cards.json` トップレベルは最大開花側として扱う取り込みレコードで、全件実機確認済みという意味ではない。途中開花の出所の区別、記録のない段階（「未確認」）の扱い、マスターのスキル level 番号と凸段階の関係は [card-data-provenance.md](./card-data-provenance.md) が正典。

衣装スキルはリーダーカード、パッシブはメンバーカードの効果として扱う。カード仕様を議論するときはroleを混同しない。

## カード詳細P/T/S

カード本体Lv・開花、青・緑、所属向けパラメータ等が反映される。赤、メモリーのユニットパラメータ、メンバー強化、編成条件衣装/パッシブはカード詳細P/T/Sに直接入らない。

## ホロメンボード

- 青: メンバー本人のP/T/S、Active発動率/頻度
- 緑: アカウント全体のP/T/S・所属効果
- 黄: 楽曲スコアボーナス・ホロワーク報酬。曲ボーナス上限10%
- 赤: リーダー時にメンバー5人へP/T/S、歌唱者条件、スコアサポート等

解放済みのマスは**外して振り直せ、外すと素材は全部戻ってくる**（振り直しは 2026-09-13 に実機で確認、全額が戻ることは 2026-10-04 ユーザー報告）。

赤のパラメータ効果と赤スコアサポートの表示換算は別問題（[display-score.md](./display-score.md)）。

### ホロメンランクとボードPt（外部マスタ由来・実機未確認）

出所は HolodoriDB の公開 master 差分（コミット `e83a4eb03baf974c434eb0ddfa1cd1d2385dad11`）で、`reported` / `rechecked` に昇格させない。

- ボードを開けるには、各ホロメンの**ホロメンボードPt** に加えて**色ごとのキューブ・コアキューブ**が要り、マスごとに消費量が違う（2026-10-04 ユーザー報告）。マス別の消費量は同じ master の `SkillTreeNode.json` consumptions から取った表（`src/data/boardMaterials.ts`。赤 63 マス cube 6065 / core 600・青 31 マス 1870 / 160・黄 31 マス 1870 / 160・緑 25 マス 3020 / 150。コネクトマスは 0 / 0）で、ボードPt からは導けない。
- ツールが制約にするのはボードPt と、アカウントの「リソース」に登録した余りのキューブ・コアキューブだけ（未登録は ∞ = 制限なし。0 は余りが 0 個）。資材を使うのは最適化（組み直しプランと結果の「組み直すと」）のホロメンボードの段だけで、いまのボードへ投入済みの資材 + 余り = 再配分できる総量を全ホロメンで共有する。手動でボードを開ける操作は制限しない。ピース・クリスタル・ホロゴールドは制約にせず、Dream Rank は常に 30 以上と仮定してマスの Dream Rank 条件は無視する。
- ホロメンランクは 1〜50。そのランクまでの累積ボードPt（ランク 1 = 0、5 = 9、10 = 26、20 = 83、30 = 161、50 = 361）を 4 色のボード全体で共有する。ランク 50 でも全マス（453 Pt）は取れない。**ツールではランクの登録が任意で、未登録は制限なし**。表は `src/data/boardPoints.ts`。
- 通常マスの必要Pt は 1〜6（赤 63 マス 212 Pt・青 31 マス 86 Pt・黄 31 マス 86 Pt・緑 25 マス 66 Pt。合計 150 マス 450 Pt）。**緑は G-025（座標 (1, -10)、3 Pt、スプラッシュボールの獲得報酬量 +0.5%。G-024 の右隣）まで 25 マス**。
- **コネクトマス**: 中心（S-001）は 0 Pt で最初から解放済み。赤 / 青 / 黄のコネクト（S-002 / S-003 / S-004）は**通常マスと同じく明示的に解放が必要で 1 Pt**。直前のマスまで開けてもコネクト自身は勝手に開かず、解放するまで先へ進めず効果も置けない。コネクトの**解放状態と効果の配置は別**（解放済みで配置なしは普通にある）。解放マス数は「解放済みの通常マス + 解放済みのコネクト」で、中心は数えない（最大 153）。
- 自動で途中経路を開くときは追加Pt が最小の経路（マス数ではない）。コネクトを閉じるとその先のマスも閉じる。
- **コネクト効果はカード固有**（同じホロメンでも ★5 の 2 枚と ★4 で違う。範囲の形 17 種 × Lv1 / Lv2 の ‰ の 20 種のどれか）。カード 1 枚でコネクト 1 枚、Lv は開花段階で決まる（0〜4凸 = Lv1、5凸 = Lv2 — 暫定、[ADR-008](../adr/008-connect-effect-provisional-model.md)）。全 138 枚の対応は外部マスタ由来で実機未確認（`src/data/cardConnect.ts`、[ADR-023](../adr/023-connect-inventory-from-owned-cards.md)）。

## 総合力

ユニット編成画面は6項目の加算として扱う。

1. メンバーパラメータ
2. 衣装スキル
3. ホロメンボード
4. パッシブ
5. メモリー
6. メンバー強化

各項目は素値基準で独立算出し、連鎖乗算しない。

## 表示ユニットスコア

外側の式・観測できる 5 カテゴリ（`Costume / Active / Board / Passive / SP`）・内部式は [display-score.md](./display-score.md) が正典。

## 楽曲・イベント

所属名だけで歌唱者を解けない曲は `songSingers.ts` の明示データを使う。イベントのメンバー対象とホロメン対象は別。イベントスコアボーナスの表示ユニットスコア内での適用位置は未確認。

**曲の長さは表示ユニットスコアに入らない**（2026-09-16 ユーザー報告。ユーザーが実機で繰り返し検証したとの報告で、個別の観測記録は残っていないので `reported`）。曲を選んで変わるのは 黄ボードの楽曲スコアボーナス（曲ごとの固定 %。ボード欄へ）・赤ボードの歌唱者条件・イベントスコアボーナスの 3 つだけで、アクティブ欄 / SP 欄の評価区間は曲によらない（[display-score.md](./display-score.md) の共通仮想タイムライン 200 秒はこれと整合する）。曲長が効くのはライブ側の試算（発動頻度の最適化）だけ。

## ガチャと課金

仮想ガチャの根拠。2026-08-31 時点の攻略サイトの情報を検索の要約経由で確かめたもので、ゲーム内の実測での裏取りはしていない（未確認の残りは `tmp/pending.md` 14）。

- 通貨はダイヤ 2 種。レッドダイヤ（配布などで入手する無償）とブルーダイヤ（購入する有償、所持上限 1,000,000）。両方持っているときはレッドダイヤが先に減る。ほかにガチャチケットがある。
- 通常のガチャは 1 回 250 個・10 連 2,500 個（どちらのダイヤでも可）。1 日 1 回 90 個の割引単発と、スタートダッシュガチャ（10 連で ★5 が 1 枚確定）はブルーダイヤ専用。
- 提供割合（通常）は ★5 = 5% / ★4 = 10% / ★3 = 85%。10 連の 10 枚目は ★4 以上が確定（内訳 ★5 5% / ★4 95%）。
- ピックアップは、新カードのピックアップが対象 1 枚 1.0000%（その他の ★5 は各 0.0508%）。選択式のイベントガチャの例では、本命 1.0000% + 残り 4 人が各 0.2500%。初心者応援ガチャ（開始 7 日間）は好きな ★5 を 3 人選んで各 0.6666%（対象はいつでも変えられる）。
- 天井は、ガチャ Pt 200 回ぶん（ダイヤ 50,000 個）でピックアップ対象と交換。Pt はガチャごとで引き継げず、開催が終わると未使用の Pt はホロステッカーに変わる。
- ショップの通常価格のパックで確認できたのは「ブルーダイヤ×8,200 = 9,800 円」（1 個あたり約 1.19 円。大きいパックほど単価が安い）。回数限定の「リリース記念!お得なダイヤ」（480 円のパックが単価最安）もあるが、全パックの個数・価格の一覧は未確認。月額はホロパスポート 480 円（報酬 2 倍・ブースト上限 2 倍・ブルーダイヤ 360 付与）と、ホロメン別のメンバーシップ 290 円/月。
- 仮想ガチャの ★3 / ★4 は、ホロメン単位の結果として表示する（1 ホロメン 1 枚と仮定）。★4 は [ADR-022](../adr/022-star4-cards-fixed-only.md) で正式なカードとして収録したが、仮想ガチャの結果とは混ぜない。★3 の実カードのデータは持たない。
- リリース記念のログインボーナスで配られたダイヤは合計 2,500 個（仮想ウォレットの初期値の根拠）。
