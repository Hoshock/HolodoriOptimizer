# SP 欄の発動率 UP 40% の切り分け（2026-09-13）

SP 欄の「スキル発動率 UP」項の閉じた形を決めるために取った 1 点の実機観測。証拠状態は `reported + cross-checked`（総合力とユニットスコアの報告があり、外側の式 `ceil(総合力 × (1 + 合計/100) × 2.03734)` が 1 点単位で一致する）。

アカウントの状態は [20260913-account-snapshot.md](./20260913-account-snapshot.md)（**現在の snapshot**）。過去の F0〜F3 / K1〜K7 / 2026-09-08 の 20 ケースへこの snapshot を遡及適用しない。

正典の解釈は [../display-score.md](../display-score.md)「SP」、式の検証は `src/engine/displayScoreSpecialColumn.test.ts`。

## 設計（何を切り分けたか）

2026-09-13 の朝までに観測できていた発動率 UP つき SP は `(効果時間, 支援%, 発動率 UP%)` が `(12, 100, 35)` と `(11, 130, 50)` の 2 通りしかなく、3 つの依存を分離できなかった。そこで **`(12, 100, 40)` を 1 本だけ ON/OFF する対照**を作った。

比較のもとは 2026-09-12 の対照「+24 水着ノエル0 / 水着ころね2」（[display-score-20260912.md](./display-score-20260912.md)）で、メンバーの 水着フワワ 0凸 を 恒常マリン 1凸 に替えた。

- 水着フワワ 0凸 と 恒常マリン 1凸 の SP は**どちらも `効果時間 12 秒 / スコアサポート 100% / 発動率 UP 35%（常時）`** で同じ。
- 白銀ノエル 0凸 の SP は `12 秒 / 100% / 発動率 UP 40%`、条件は **3期生が 2 人以上**。
- 水着フワワ は advent、恒常マリン は 3期生。したがって入替で **白銀ノエル の 40% 項だけが 不成立 → 成立** に変わり、35% 項 2 本・おかゆの 50% 項・ころねの 35% 項・静的なスコアサポート総量はそのまま残る。

## SP 欄の内訳

```
SP 欄 = 表示アクティブ欄 × Σ_i (効果時間_i / 120) × (支援_i / 100) × (1 + 発動率 UP_i / 200)
```

| メンバー       | カード              | 効果時間 | 支援 % | 発動率 UP % | 条件                | 成立                   |             係数 |
| :------------- | :------------------ | -------: | -----: | ----------: | :------------------ | :--------------------- | ---------------: |
| 水着みこ 1凸   | `sakura-miko-02`    |     11 s |    120 |           — | —                   | —                      |         0.110000 |
| 水着ノエル 0凸 | `shirogane-noel-02` |     12 s |    100 |          40 | 3期生が 2 人以上    | 成立（ノエル・マリン） |         0.120000 |
| 恒常マリン 1凸 | `houshou-marine-01` |     12 s |    100 |          35 | 常時                | 成立                   |         0.117500 |
| 水着おかゆ 5凸 | `nekomata-okayu-02` |     11 s |    130 |          50 | ゲーマーズ 2 人以上 | 成立（おかゆ・ころね） |     0.148958333… |
| 水着ころね 2凸 | `inugami-korone-02` |     12 s |    100 |          35 | 常時                | 成立                   |         0.117500 |
| **合計**       |                     |          |        |             |                     |                        | **0.613958333…** |

`77.6 × 0.613958333… = 47.643166…` → 0.1% 単位で切り上げて **47.7**（実機と一致）。

入替前の「+24 水着ノエル0 / 水着ころね2」（実機 アクティブ 74.8 / SP 44.5）では 白銀ノエル の 40% が不成立で係数の合計は `0.593958333…`、`74.8 × 0.593958333… = 44.428…` → 切り上げ **44.5**（実機と一致）。**係数の差はちょうど `0.02 = (12/120) × (100/100) × (40/200)`** で、白銀ノエル 1 本ぶんの発動率 UP 項に一致する。

この 1 点が入ったことで、発動率 UP の値が `35 / 40 / 50 / 55%` の 4 通りになり、分母 `200` が一意に決まった（`src/engine/displayScoreSpecialColumn.test.ts`）。
