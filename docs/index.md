# ドキュメントインデックス

HolodoriOptimizer のドキュメントの一覧。どこに置くかの判定は CLAUDE.md の「ドキュメントの分担」に従う。docs/ は存在理由で adr / ai / human の3つに分かれ、tmp/ はバケットではなく各バケット内の一時置き場。

## リポジトリルート (docs/ 外)

docs/ の分類対象外だが、入口として先に挙げる。

| ドキュメント              | 概要                                                           | いつ読むか                     |
| :------------------------ | :------------------------------------------------------------- | :----------------------------- |
| [README.md](../README.md) | エントリーポイント。ツール概要・免責・開発状況                 | 最初に                         |
| [CLAUDE.md](../CLAUDE.md) | リポジトリ全体の編集ルール・技術スタック・ドキュメントの分担表 | 毎セッション自動で読み込まれる |

## エージェント向け (ai/)

| ドキュメント                             | 概要                             | いつ読むか                                     |
| :--------------------------------------- | :------------------------------- | :--------------------------------------------- |
| [ai/rules/index.md](./ai/rules/index.md) | エージェント向け恒久ルールの索引 | ルールを探すとき、ルールの置き場所に迷ったとき |

パス単位で適用されるルールは `.claude/rules/` にあり、該当ファイルを読むと自動で読み込まれる。棚卸しは housekeep スキル、フィードバックの記録は induction スキル(いずれも `.claude/skills/`)。

### 揮発性 (ai/tmp/)

以下は予約ドキュメント(存在しないときも行を残す)。すべて解消イベントを持ち、tmp/ に住み着かせない — 残す価値のある内容は棚卸し(housekeep)で恒久の置き場へ昇格し、タスク完了時のクローズで tmp/ ごと削除される。

| ドキュメント                               | 概要                                                                 | いつ読むか                                   |
| :----------------------------------------- | :------------------------------------------------------------------- | :------------------------------------------- |
| [ai/tmp/plan.md](./ai/tmp/plan.md)         | 進行中タスクの目的・背景・フェーズ別の作業項目(タスク進行中のみ存在) | まとまった作業の計画・決定事項を確認するとき |
| [ai/tmp/progress.md](./ai/tmp/progress.md) | 進行中タスクのステータス表と時系列ログ(タスク進行中のみ存在)         | 進捗を確認・更新するとき                     |
| [ai/tmp/pending.md](./ai/tmp/pending.md)   | 判断に迷う事項・後回しにした事項(タスク外でも発生しうる)             | 既知の保留事項に触れる前、後回しを決めるとき |
| [ai/tmp/rules.md](./ai/tmp/rules.md)       | induction が記録する未査定のルール候補と事例(タスク外でも発生しうる) | フィードバックの記録時、housekeep での昇格時 |

### 揮発性 (human/tmp/)

日付つきの時点スナップショット(`YYYYMMDD-<topic>.md`)。ai/tmp/ と違って解消イベントを待つものではなく、tmp 風の置き場は陳腐化シグナル。昇格・削除の規則は適用されず、削除は人間の判断で行う(棚卸し対象外)。
